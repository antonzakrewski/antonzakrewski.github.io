contravariant hom functor as exact functor and injective object

Proposition

Let $\mathcal{A}$ be an abelian category, $I \in \mathrm{Ob}(\mathcal{A})$ an object

\begin{align*} \mathrm{Hom}_{\mathcal{A}}(I,-) \end{align*}

the contravariant hom-functor

TFAE:

  1. $\mathrm{Hom}_{\mathcal{C}}(I,-)$ is an exact
  2. $I$ is an injective object

Proof

corollary of:

  • injective object and contravariant hom dualizing monomorphism to epimorphism
  • contravariant hom functor as left exact functor
  • half exact functor preserving epimorphisms as right exact functor

where monomorphisms in $\mathcal{A}$ are epimorphisms in $\mathcal{A}^{\mathrm{op}}$
