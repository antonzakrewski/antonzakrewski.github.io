cogenerating set

Definition

Let $\mathcal{C}$ be a category. Then a set of objects $S \subseteq \mathrm{Ob}(\mathcal{C})$ is said to be a cogenerating set, if

\begin{align*} \prod_{s \in S} \mathrm{Hom}(-,s) \end{align*}

is faithful

i.e. for two different morphisms $f,g: X \rightarrow Y$ there exists a morphism $h: Y \rightarrow s$ for some $s \in S$ such that

\begin{align*} h \circ f \neq h \circ g \end{align*}
