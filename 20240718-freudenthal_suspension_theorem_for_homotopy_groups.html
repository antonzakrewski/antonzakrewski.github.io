freudenthal suspension map for homotopy groups

Proposition

Let $(X,x)$ be a well pointed space.

Then there exists an induced morphism

\begin{align*} s: \pi_n(X,x) \rightarrow \pi_{n+1}(\Sigma X, x) \end{align*}

for the reduced suspension $\Sigma$

Proof

set theoretically

Let

\begin{align*} \alpha: (I^n , \partial I) \rightarrow (X,x) \end{align*}

Then define

\begin{align*} s \alpha: I^n \times [0,1] \rightarrow X \times [0,1] \rightarrow \Sigma X \end{align*}

This is a map of pairs

\begin{align*} (s \alpha: (I^{n+1}, \partial I^{n+1}) \rightarrow (\Sigma X, x) \end{align*}

topological

For the unit map (cf. reduced suspension based loop adjunction) 

\begin{displaymath}
\begin{tikzcd}
\pi_n(X,x) \arrow[]{rd}{s} \arrow[]{r}{u_x}& \pi_n(\Omega \sigma X,x) \\
& \pi_{n+1}(\SigmaX, x) \arrow[swap]{u}{\cong} \arrow[]{u}{\partial}\\
\end{tikzcd}
\end{displaymath}

commutes, where $\partial$ is the boundary map of the long exact sequence of a serre fibration (cf. long exact sequence of a serre fibration) for

\begin{align*} \mathrm{ev}_1: P_{x}\Sigma X \rightarrow \Sigma X \end{align*}

where $P_x$ is the pointed path space

Since $P_x$ is contractible, pointed path space as contractible space, it follows that the boundary map is an isomorphism

commutes

Consider $\alpha: (I^n, \partial I^n) \rightarrow (X,x)$ be a generic element. Then the lifting problem

determines $\partial [s \alpha]$

Now note that

\begin{align*} I^n \times [0,1] \rightarrow& P_x X \\ (t,s) \mapsto& [u \mapsto [\alpha(t), su]] \end{align*}

solves the lifting problewa

Note that after renaming coordinates, this is the map above
