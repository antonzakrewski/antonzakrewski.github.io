conservative, reduced functor detects terminal object

Proposition

Let $\mathcal{C}, \mathcal{D}$ be categories which admit a terminal object and $\mathcal{F}: \mathcal{C} \rightarrow \mathcal{D}$ a conservative, reduced functor. Then $\mathcal{F}$ detects the terminal object

Proof

Let $c$ be an object with $\mathcal{F}(c) \simeq *$. Then let $c \rightarrow *$ be the terminal morphism, which becomes an equivalence upon applying $\mathcal{F}(-)$. In particular, the map $c \rightarrow *$ is an equivalence, since $\mathcal{F}$ is conservative.
