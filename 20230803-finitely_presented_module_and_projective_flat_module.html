finitely generated module and projective / flat and finitely presented module over a commutative ring

Proposition

Let \(R\) be a ring and $F$ a finitely generated module TFAE:

  1. $F$ is flat and finitely presented
  2. $F$ is a projective module

Proof

1) $\implies$ 2)

Observe that by Lazard's theorem, $F$ is a filtered colimit of finitely generated, free modules. Moreover, $F$ is by assumption compact (cf. compact object in RMod as finitely presented module). Hence it is a retract of some $R^k$ (cf. compact object as filtered colimit and retract)

2) $\implies$ 1)

recall that projective modules are flat modules so it remains to show that $F$ is finitely presented module This follows from 1-sfp objects in RMod Alternatively: Use that $F$ is a retract of $R^k$ for some $k$.

  • compact object closed under retracts.
