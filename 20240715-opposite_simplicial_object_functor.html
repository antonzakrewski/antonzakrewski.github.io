opposite simplicial object functor

Definition / Proposition

Let $\mathcal{C}$ be a category, $\mathrm{s}\mathcal{C}$ the category of simplicial objects, then the opposite simplicial object functor

\begin{align*} ()^\mathrm{op}: \mathrm{sSet} \rightarrow \mathrm{sSet} \end{align*}

is defined as precomposition with the opposite linear order endofunctor of the simplex category

Proof

Note that

\begin{align*} \mathrm{rev}^2 = \mathrm{id} \end{align*}

hence it is an automorphism
