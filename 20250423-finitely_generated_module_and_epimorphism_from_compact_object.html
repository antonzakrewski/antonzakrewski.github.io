finitely generated module and epimorphism from compact object

Proposition

Let $R$ be a ring and $M$ an \(R\)-module.

TFAE:

  1. $M$ is a finitely generated module
  2. there exists a finitely presented module $N$ and an epimorphism $N \twoheadrightarrow M$
  3. there exists a compact object $N$ and an epimorphism $N \twoheadrightarrow M$

Proof

1) $\implies$ 2)

2) $\equiv 3)

3) $\implies$ 1)

compact object in RMod as finitely presented module where a quotient of a finitely generated module is again finitely generated
