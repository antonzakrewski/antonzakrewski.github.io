additive functor from Cat Vect as exact functor

Proposition

Let $\mathcal{A}$ be an abelian category, $\mathrm{Vec}_K$ the Category Vect_K for a field $K$. Then each additive functor

\begin{align*} \mathcal{F}: \mathrm{Vec}_K \rightarrow \mathcal{A} \end{align*}

is an exact functor

Proof

follows as each is projective object (cf. vector space as projective module), therefore by the Splitting Lemma each short exact sequence is split exact
