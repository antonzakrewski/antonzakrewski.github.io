fully faithful adjoint and bousfield localization

Proposition

Let $\mathcal{F} \dashv \mathcal{G}$ an adjunction for $\mathcal{F}: \mathcal{C} \rightarrow \mathcal{D}, \mathcal{G}: \mathcal{D} \rightarrow \mathcal{C}$ TFAE:

  1. $\mathcal{F}$ is a dwyer-kan localization for the collection of unit morphism
  2. $\mathcal{G}$ is fully faithful

analogously TFAE:

  1. $\mathcal{G}$ is a dwyer-kan localization
  2. $\mathcal{F}$ is fully faithful

Proof

a)

Recall that a unit transformation is an equivalence if and only if the left adjoint is fully faithful, analagously for the counit and left adjoint. (cf. fully faithful left adjoint and unit as isomorphism)

1) $\implies$ 2)

It suffices to show that the counit transformation of $\mathcal{F} \dashv \mathcal{G}$ is an equivalence. We know that the unit transformation of $\mathcal{G}^* \dashv \mathcal{F}^*$ is an equivalence, since $\mathcal{F}^*$ is fully faithful, as $\mathcal{G}$ is a dwyer-kan localization.

Here the unit transformation in $\mathrm{Fun}(\mathcal{D}, \mathcal{E})$ is given on an object $\mathcal{H}: \mathcal{D} \rightarrow \mathcal{E}$ by precomposition with the counit, so in particular we may let $\mathcal{E} = \mathcal{D}$ and test against the identity functor to observe that the the counit transformation of $\mathcal{F} \dashv \mathcal{G}$ is an equivalence.

2) $\implies$ 1)

Observe that precomposition with an adjoint is an adjoint, so we have $\mathcal{G}^* \dashv \mathcal{F}^*$ on $\mathrm{Fun}(-, \mathcal{E})$ for arbitrary $\mathcal{E}$. Now in particular, the unit of this adjunction is given by whiskering with the counit of $\mathcal{F} \dashv \mathcal{G}$, which implies that the unit of $\mathcal{G}^* \dash \mathcal{F}^*$ is an equivalence hence $\mathcal{G}^*$ is fully faithful.

We claim that it identifies with the full subcategory containing functors $\mathcal{H}: \mathcal{C} \rightarrow \mathcal{E}$ which invert the objectwise counit morphisms $\epsilon(c)$: So suppose we have a functor $\mathcal{H}: \mathcal{C} \rightarrow \mathcal{E}$ which preserves inverts the individual unit morphism, then precomposition with the unit transformation $(\mathcal{F} \mathcal{G})^*\mathcal{H} \Rightarrow \mathcal{H}$ is an equivalence where $(\mathcal{F} \mathcal{G})^*\mathcal{H} \simeq \mathcal{F}^*( \mathcal{H} \mathcal{G})$ lies in the essential image.

Suppose that we have a functor in the essential image, i.e. $\mathcal{H} \simeq \mathcal{F}^*\mathcal{H}'$, then it suffices to show that $\mathcal{F}$ inverts the unit morphism, i.e. $\mathcal{F}(\mathrm{id}) \Rightarrow \mathcal{F} \mathcal{G} \mathcal{F}$ is an equivalence. It suffices to show that it is an equivalence after applying $\mathcal{G}$, since $\mathcal{G}$ is fully faithful and hence conservative functor. but $\mathcal{G}\mathcal{F} \Rightarrow \mathcal{GFGF}$ identifies with a section of an equivalence in the triangle identities.

b)

Remark

If one wants to use the $\mathrm{Hom}()$ characterization, then one can apply the groupoid core, which preserves fully faithful functors.
