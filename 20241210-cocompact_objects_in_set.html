cocompact objects in Set

Proposition

Let $\kappa$ be a regular cardinal, then the only kappa cocompact object in category set is given by the singleton.

Proof

$\{*\}$ is cocompact

follows from

  • terminal object as cocompact object
  • for $\mathrm{Set}^{\mathrm{op}}$

$\emptyset$ is not cocompact

Let $X$ be a well ordered set with cardinality (at least) $\kappa$ and no upper bound. Then consider

\begin{align*} \bigcap_{x \in X} (x,\infty) \end{align*}

This gives a a cofiltered diagram (even sequential for $\kappa = \omega$)

for $x > x'$

But the limit is given by the $\emptyset$.

Here we have

\begin{align*} \mathrm{Hom}(\emptyset, \emptyset) =& \{\mathrm{id}\} \\ \mathrm{Hom}((x,\infty), \emptyset) =& \emptyset \\ \end{align*}

Set with $\vert X \vert > 1$ is not cocompact

w.l.o.g. we may assume that $X = \{1,2\}$ since any subset in Set is given by a <>

Then consider

\begin{align*} \prod_{\lambda < \kappa} \{1,2\} \end{align*}

which is a \(kappa\)-filtered limit of \(\kappa\)-small products $\prod \{1,2\}$.

Then consider the map

\begin{align*} \mathrm{indicate}: \prod_{\lambda < \kappa} \{1,2\} \rightarrow& \{1,2\} \\ (a_i) \mapsto& \begin{cases} 1 & \mbox{if } a_j = 1 \textrm{ for some }j \\ 0 & \mbox{else } \\ \end{cases} \end{align*}
