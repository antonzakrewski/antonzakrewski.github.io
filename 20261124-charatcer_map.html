character map

Definition

Let $G$ be a finite group Then the map

\begin{align*} \pi_0((\mathrm{Mod}_{k[G]}^{\mathrm{f.d.})^{\simeq})) \rightarrow \mathrm{Cl}(G, k) [V] \mapsto \chi_{V} \end{align*}

extends to a map $R_k(G) \rightarrow \mathrm{Cl}(G, K)$.

Moreover, this is a map of rings, where $\mathrm{CL}(G,k) \subseteq \mathrm{Fun}(G,k)$ with the pointwise multiplication.

remark

$\mathrm{CL}(G,K)$ does only not determine the iso class of a f.g. rep. in characteristic zero Hence it is injective if and only if $\mathrm{char}(K) = 0$.

Moreover, being a map of rings implies

\begin{align*} \chi_{V \otimes W}(x) = \chi_{V}(x) \cdot \chi_{W}(x) \end{align*}
