forgetful functor from top to set

Definition

Given category Top and category set the forgetful functor is defined as

\begin{align*} \mathrm{Forget}: \mathrm{Top} \rightarrow& \mathrm{Set} \\ (X, \mathcal{T}) \mapsto& X \\ f \mapsto& f \end{align*}

sending a continuous map to the underlying set theoretic map.
