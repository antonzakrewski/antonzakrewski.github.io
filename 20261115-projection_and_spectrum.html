projection and spectrum

Proposition

Let $p \in A$ be a self-adjoint element in a C star algebra. TFAE:

  1. $p$ is a projection,
  2. $\sigma_{A}(p) \subseteq \{0,1\}$.

Proof

1) $\implies$ 2)

we have $\sigma_{A}(0) = \{0\}$ and hence $(x^2 - x)(\sigma_{A}(p)) = \{0\}$. the only numbers, which satisfy the relation are $0,1$ therefore $\sigma_{A}(p) \subseteq \{0,1\}$.

2) $\implies$ 1)

we need to show that $p^2 = p$. So consider $x^2 - x$ and apply function calculus: Then

\begin{align*} (x^2 - x)(p) = \{0\} \end{align*}
