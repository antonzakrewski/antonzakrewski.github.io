kappa accessible category

Definition

Let $\kappa$ be a regular cardinal, $\mathcal{C}$ a locally small category. Then $\mathcal{C}$ is said to be $\kappa$ accessible, if

  1. $\kappa$ admits kappa filtered colimits
  2. there exists a set of kappa small object such that each object $C \in \mathcal{C}$ is a \(\kappa\)-filtered colimit
