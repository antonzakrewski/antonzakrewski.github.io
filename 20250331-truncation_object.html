n-truncation object

Definition

Let $\mathcal{C}$ be an infinity category, $x \in \mathcal{C}$ an object and $n \in \{-2,...,\}$ Then an truncation object of $x$ is a n-truncated object $\tau_{\leq n}(x)$ given with a morphism

\begin{align*} x \rightarrow \tau_{\leq n}(x) \end{align*}

such that

\begin{align*} \mathrm{map}_{\mathcal{C}}(-,x) \rightarrow \mathrm{map}_{\mathcal{C}}(-,\tau_{\leq n}(x)) \end{align*}

is pointwise n-connected morphism of anima
