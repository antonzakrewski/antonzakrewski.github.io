lim-lim1 vanishes for surjective maps

Proposition

Let $A_{n+1} \rightarrow A_n \rightarrow A_{n-1}$ be a sequential system, where each map is surjective Then the $\mathrm{lim} \mathrm{lim}^1$ terms vanish.

Proof

Using the definition of $\mathrm{lim} \mathrm{lim}^1(A_n)$ as cokernel (cf. lim-lim1 for abelian groups via cokernel) it suffices to show that the map

\begin{align*} \prod_{n \leq 0} A_n \xrightarrow{\mathrm{id}_n - f_{n-1}} \prod_{n \leq 0} A_n \end{align*}

is surjective.

Note that (at least after cofinal/coinitial replacement - which we have already implicitly assumed) the filtered object may be indexed by the negative numbers.
