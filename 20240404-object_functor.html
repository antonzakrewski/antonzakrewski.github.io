object functor

Definition

Let $\mathrm{Cat}$ be the Category Cat, then the object functor is defined as functor

\begin{align*} \mathrm{Ob}(-): \mathrm{Cat} \rightarrow& \mathrm{Set} \\ \mathcal{C} \mapsto& \mathrm{Ob}(\mathcal{C}) (\mathcal{F}: \mathcal{C} \rightarrow \mathcal{D}) \mapsto& (\mathcal{F}: X \mapsto \mathcal{F}(X)) \end{align*}
