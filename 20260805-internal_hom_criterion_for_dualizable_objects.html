Proposition

Let $\mathcal{C}$ be a closed symmetric monoidal category and $X$ an object TFAE:

  1. $X$ is a dualizable object
  2. the canonical maps $\underline{\mathrm{Hom}}(X,\mathbb{S}) \otimes Y \rightarrow \underline{\mathrm{Hom}}(X, Y), \underline{\mathrm{Hom}}(X^{\vee},\mathbb{S}) \otimes Y \rightarrow \underline{\mathrm{Hom}}(X^{\vee}, Y)$ adjoint to $\underline{\mathrm{Hom}}(X,\mathbb{1}) \otimes X \otimes Y \xrightarrow{\mathrm{ev}} Y, \underline{\mathrm{Hom}}(X^{\vee},\mathbb{1}) \otimes X^{\vee} \otimes Y \xrightarrow{\mathrm{ev}} Y$ are equivalences for all $Y$
  3. there exist equivalences $\underline{\mathrm{Hom}}(X,\mathbb{S}) \otimes Y \rightarrow \underline{\mathrm{Hom}}(X, Y), \underline{\mathrm{Hom}}(X^{\vee},\mathbb{S}) \otimes Y \rightarrow \underline{\mathrm{Hom}}(X^{\vee}, Y)$.

Proof

1) $\implies$ 2)

follows from internal hom out of a dualizable object

2) $\implies$ 3)

2) $\implies$ 1)

we need to show that there exists an equivalence

\begin{align*} \mathrm{Hom}_{\mathcal{C}}( X \otimes -, -) \simeq& \mathrm{Hom}_{\mathcal{C}}(-, \underline{\mathrm{Hom}}(X,-)) \\ \simeq& \mathrm{Hom}_{\mathcal{C}}(-, \underline{\mathrm{Hom}}(X,\mathbb{S}) \otimes -) \end{align*}

which implies that $X \otimes - \dashv \underline{\mathrm{Hom}}(X, \mathbb{S}) \otimes -$.
