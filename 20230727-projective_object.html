projective object

Definition

Let $\mathcal{C}$ be a category and $P \in \mathcal{C}$. Then $P$ is said to be projective, if $\mathrm{Hom}_{\mathcal{C}}(P,-)$ preserves simplicial colimits

Definition

Let $\mathcal{C}$ be a category and $P \in \mathrm{Ob}(\mathcal{C})$. Then $P$ is a projective object if it has the left lifting property against epimorphisms
