distance (graph)

Definition

Let $G = (V,E)$ be a Graph.

Then for vertices $v,v'$ the distance is defined as

\begin{align*} \mathrm{dist}(v,v') = \mathrm{min}_{g(\mathrm{num}(g)) \end{align*}

where $g$ is a graph geodesic

note, that if for $v,v'$ there does not exist a path, the distance is defined as

\begin{align*} \mathrm{dist}(v,v') = \infty \end{align*}
