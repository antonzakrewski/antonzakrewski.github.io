forgetful functor from top* to set*

Definition

Given category Top* and category set*, the forgetful functor is defined as

\begin{align*} \mathrm{Forget}: \mathrm{Top}_* \rightarrow& \mathrm{Set}_* \\ (X,x) \mapsto& X \\ f \mapsto& f \end{align*}

sending a continuous based map to the underlying set theoretic map.

Note that the basepoint is preserved
