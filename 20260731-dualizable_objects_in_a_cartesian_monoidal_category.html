dualizable objects in a cartesian monoidal category

Proposition

The only dualizable object in cartesian monoidal category is the terminal object resp. the monoidal unit.

Proof

Let $x \in \mathcal{C}$ be dualizable and let $c \in \mathcal{C}$ be arbitrary. Then it suffices to show that $\mathrm{Hom}_{\mathcal{C}}(c,x)$ is contractible. But the functor

\begin{align*} \mathrm{Hom}_{\mathcal{C}}(c,-): \mathcal{C} \rightarrow \mathrm{An} \end{align*}

preserves limits / products, hence it is a symmetric monoidal functor with respect to the cartesian monoidal structures. Hence $\mathrm{Hom}_{\mathcal{C}}(c,x)$ is a dualizable object in the category of Anima (with respect to the cartesian monoidal structure, cf. monoidal functor preserves dualizable objects). But dualizable anima is a point shows that $\mathrm{Hom}_{\mathcal{C}}(c,x)$ is contractible.
