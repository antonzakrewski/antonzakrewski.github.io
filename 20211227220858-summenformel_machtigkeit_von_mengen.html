Summenformel (Mächtigkeit von Mengen)

Satz

Seien $X$,$Y$ endliche Mengen, dann gilt für Mächtigkeit der Vereinigung

\begin{align*} \vert X \cup Y \vert = \vert X \vert + \vert Y \vert - \vert X \cap Y \vert \end{align*}

Beweis

\begin{align*} X \cup Y =& (X \setminus Y) \sqcup (Y \setminus X) \sqcup (X \cap Y) \\ % \emptyset =& (X \setminus Y) \cap (Y \setminus X) \cap (X \cap Y) \\ % \vert X \cup Y \vert =& \vert X \setminus Y \vert + \vert Y \setminus X \vert + \vert X \cap Y \vert \\ \vert X \vert =& \vert X \setminus Y \vert + \vert X \cap Y \vert \\ \vert Y \vert =& \vert Y \setminus X \vert + \vert Y \cap X \vert \\ \vert X \cup Y \vert =& \vert X \setminus Y \vert + \vert Y \setminus X \vert + \vert X \cap Y \vert = \\ =& \vert X \vert + \vert Y \setminus X \vert \\ =& \vert X \vert + \vert Y \vert - \vert X \cap Y \vert \end{align*}
