bidual is equivalent for a dualizable object

Proposition

Let $\mathcal{C}^{\otimes}$ be a symmetric monoidal category and $X$ a dualizable object. Then $X$ is canonically equivalent to $(X^{\vee})^{\vee}$.

Proof

follows from:

  • dual object of a dualizable object is unique up to unique equivalence
  • dual of dualizable object is dualizable
