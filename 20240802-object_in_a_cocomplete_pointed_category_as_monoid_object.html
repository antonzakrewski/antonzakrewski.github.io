object in a cocomplete category as monoid object

Proposition

Let $\mathcal{C}$ be a category with finite coproducts. Then an object $C \in \mathcal{C}$ is a monoid object with respect to

  1. the codiagonal morphism $\nabla: C \coprod C \rightarrow C$ as composition
  2. the initial morphism $\emptyset \rightarrow C$ as unit
