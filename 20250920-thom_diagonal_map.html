thom diagonal map

Definition

Let $B \rightarrow \mathrm{BG}$ be a stable oriented spherical fibration. Then the thom diagonal map is defined as

\begin{align*} \Delta: \mathrm{M}(\xi) \rightarrow \mathbb{S}[B] \otimes \mathrm{M}(\xi) \end{align*}

using

\begin{align*} \mathrm{M}(\xi) \simeq& \mathrm{colim}_B \xi \rightarrow \mathrm{colim}_{B \times B} \mathcal{F} \circ \mathrm{pr}_2 \simeq B\otimes \mathrm{colim}_B \mathcal{F} \simeq B \otimes M(\xi) \end{align*}

where we use

  1. thom spectrum is colimit
  2. constant colimit in spectra is tensor product
  3. precomposition with a functor induces map on colimits
