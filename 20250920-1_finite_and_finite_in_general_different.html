1-finite and finite category in general different

Proposition

Let $\mathcal{C}$ be a 1-category. Then

  1. if $\mathcal{C}$ is 1-finite 1-category, then it is in general not a finite category in $\mathrm{Cat}_{(\infty,1)}$
  2. if $\mathcal{C}$ is a finite category, then it is in general not 1-finite

Proof

1)

Consider $BC_2$ which contains 1 object and 2 morphisms, hence a 1-finite category. But it is not a finite category

Its geometric realization is given by $\mathbb{R}\mathbb{P}^{\infty}$ which is not finite dimensional CW-complex (e.g. consider Z/2 homology of the real projective space).

see:

  • finite simplicial set and finite CW complex

2)

consider $B \mathbb{Z}$. It is a finite category because e.g. it is represented by $S^1 \cong \partial \Delta^2$ (cf. finite simplicial set and finite CW complex) or because it is the pushout

see:

  • coproduct as pushout from an initial object

But it is not 1-finite because it contains infinitely many morphisms (namely represented by the integers).
