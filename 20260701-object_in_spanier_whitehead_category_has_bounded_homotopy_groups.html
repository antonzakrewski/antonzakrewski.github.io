object in spanier whitehead category has bounded homotopy groups

Proposition

Let $X \in \mathrm{SW}$ be an object in the spanier whitehead category, then there exists an $n \in \mathbb{Z}$ such that

\begin{align*} \pi_{n'}(X) = 0 \end{align*}

for $n' < n$.

Proof

using isomorphism classes of objects in a filtered colimit shows that there exists an $n \in \mathbb{Z}$ such that $X$ comes from the $n$-th component. Then for

\begin{align*} \mathrm{Hom}_{\mathrm{SW}}(\mathbb{S}^{n'}, X) \simeq \mathrm{colim}_{m \in \mathbb{N}} \mathrm{Hom}_{\mathrm{An}_*}(S^{m}, \Sigma^{n-n' +m} X) \end{align*}
