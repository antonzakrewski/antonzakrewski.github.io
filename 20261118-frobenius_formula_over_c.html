frobenius formula over C

Proposition

Pick a representative $x_{\sigma} \in G$ for every right coset $\sigma \in H \ G$ Let $H \subseteq G$ be a subgroup of a finite group Let $V$ be an \(H\)-representation. Let $\chi_{\mathrm{Ind}}$ be the character of $\mathrm{Ind}_{H}^G(V)$.

Then

\begin{align*} \chi(g) = \sum_{\sigma \vert x_{\sigma} g x_{\sigma}^{-1} \in H } \chi_{V}(x_{\sigma} g x_{\sigma}^{-1}) \end{align*}

Proof

First note that $\chi$ is characterized via the relation

\begin{align*} \langle \chi_{\mathrm{Ind}}, \psi\rangle = \langle \chi_{V}, \psi_{H}\rangle \end{align*}

for any character class function $\psi: G \rightarrow \mathbb{C}$. This is true because $\mathbb{C}$ is algebraically closed field (cf. ) and orthogonality of simple characters.

Take $\chi_{V}$ extend it to a function $F$ by zero outside of $H$.

Note $F$ is not generally a class function. We make it a class function via "averaging" procedure.

\begin{align*} p_{G}: \mathbb{C}^G \rightarrow& \mathrm{Cl}(G, \mathbb{C}) \\ F \mapsto& (x \mapsto \frac{1}{\vert G \vert} \sum_{g \in G} F(g x g^{-1})) \end{align*}

Note that$P_gF$ is a class function, since conjugating is equivalent to reindexing the sum.

Moreover

\begin{align*} \langle P_{G}F, \psi\rangle = \langle F, \psi\rangle = \frac{1}{\vert G \vert} \sum_{g \in G} F(g) \overline{\psi(g)} \end{align*}

where we use again that we may pull out the sum and reindex.

In particular, if $F$ is a class function, then $P_gF = F$.

Finally, let $\theta = [G : H] P_G F$.

Then

\begin{align*} \langle \theta, \psi\rangle =& [G:h] \langle P_G F, \psi\rangle \\ =& [G:H] \langle F, \psi\rangle \\ =& [G: H] \frac{1}{\vert G \vert} \sum_{g \in G} F(g) \overline{\psi(g)} \\ =& \frac{1}{\vert H \vert} \sum_{h \in H} \chi_{V}(h) \overline{\psi_{V}(h) } \\ =& \langle \chi_{V}, \psi_{\vert H} \rangle \end{align*}

So $\chi = [G : H] P_{G} F$. Now we compute that

\begin{align*} [G : H] P_G F(g) =& \frac{1}{\vert H \vert } \sum_{x \in G} F(x g x^{-1}) \\ =& \frac{1}{\vert H \vert} \sum_{x \in G, xgx^{-1} \in H} \chi_{V}(x gx^-1) \\ =& \sum_{x_{\sigma}, x_{\sigma} g x_{\sigma^{-1} \in H} \chi_{V} (x_{\sigma} g x_{\sigma}^{-1}) \end{align*}

here the equalities are:

  1. first is definition of $P_G$, the
  2. second is cancellation of $F$ where it is extension by zero
  3. third is grouping the cosets together
