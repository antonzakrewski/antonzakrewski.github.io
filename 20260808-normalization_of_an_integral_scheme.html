normalization of an integral scheme

Definition / Proposition

Let $X$ be an integral scheme. Then the normalization of $X$ is a s morphism $X^{\nu} \rightarrow X$ such that

  1. $X^{\nu}$ is a normal integral scheme
  2. $X^{\nu} \rightarrow X$ is an integral morphism of schemes
  3. $X^{\vee} \rightarrow X$ induces an isomorphism on function field of an integral scheme

Proof

Using the assumption that $X^{\nu} \rightarrow X$ is an integral morphisms, so in paritcular affine, we have to construct a quasi-coherent algebra $A$ over $X$. To construct it, recall that quasi-coherent object over a scheme is limit over affine open immersions i.e.

\begin{align*} \mathrm{CAlg}_{X} \simeq \lim_{\mathrm{Spec}(R) \hookrightarrow X, \textrm{ open immersion }} \mathrm{CAlg}_{R} \end{align*}

we define the quasi-coherent algebra by hand using some cocycle condition: For $u: \mathrm{Spec}(R) \hookrightarrow X$, with $R \neq 0$, we have that $R$ is an Integral domain with fraction field $K = \kappa(\eta)$. Therefore we define

\begin{align*} A(u) = \begin{cases} 0 & \mbox{if } R = 0 \\ \textrm{ integral closure of } R \textrm{ in } K \end{cases} \end{align*}
