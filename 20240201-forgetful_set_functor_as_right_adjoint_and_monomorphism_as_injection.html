forgetful set functor as right adjoint and monomorphism as injection

Proposition

Let $\mathcal{C}$ be a concrete category and $\mathrm{Set}: \mathcal{C} \rightarrow \mathrm{Set}$ the underlying-set functor.

Suppose $\mathrm{Set}$ is a right adjoint, then an monomorphism $f \in \mathrm{Mor}(\mathcal{C})$ is set-theoretically an injection

Proof

corollary of:

  • right adjoint preserves monomorphisms
  • monomorphism in set as injective map
