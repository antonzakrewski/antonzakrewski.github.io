nullset of a manifold

Definition

Let $M$ be a smooth manifold. Then a null set of $M$ is a subset $A \subseteq M$ such that for any chart $\varphi: \mathbb{R}^n \rightarrow M$ the preimage

\begin{align*} \varphi^{-1}[A] \subseteq M \end{align*}

is a null set
