image of the spec functor as vanishing set of the kernel

Proposition

Let $A,B$ be commutative rings, $\varphis A \rightarrow B$ a ring-homomorphism with kernel $I \subseteq A$. Then the closure of the image of the Spec functor is the Vanishing set of the kernel

\begin{align*} \overline{\mathrm{im}(\mathrm{Spec}(\varphi))} = V(I) \end{align*}

Proof
