holomorphic function as analytic function

Proposition

Let $\Omega \subseteq \mathbb{C}$ be open and $f: \Omega \rightarrow \mathbb{C}$ be holomorphic Then $f$ is an analytic function with

\begin{align*} f(z) = \sum_{n=0i^{\infty} \frac{f^{(n)}(z_0)}{n!} (z - z_0)^n \end{align*}

for $\vert z - z_0 \vert < \mathrm{dist}(z_0, \partial \Omega)$

Proof

Fix $z,z_0 \in \Omega$ with $\vert z - z_0 \vert < \mathrm{dist}(z_0, \partial \Omega)$ and choose $\vert z - z_0 \vert < r < \mathrm{dist}(z_0, \partial \Omega)$. Then write

\begin{align*} f(z) = \frac{1}{2\pi \mathrm{i}} \int_{C_r(z_0)} \frac{f(\zeta)}{\zeta - z} \mathrm{d} \zeta \end{align*}
