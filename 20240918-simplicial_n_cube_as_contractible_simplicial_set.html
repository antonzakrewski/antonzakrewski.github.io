simplicial n-cube as contractible simplicial set

Proposition

Let $n \in \mathbb{N}_0$, then the simplicial n-cube is a contractible simplicial set.

Proof

follows from:

  • simplicial n-cube as nerve
  • nerve of a category with initial object as contractible simplicial set

where

\begin{align*} [1]^n \end{align*}

admits $\{0,...,0\}$ as initial object.
