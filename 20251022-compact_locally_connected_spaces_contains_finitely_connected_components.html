compact, weakly locally connected spaces contains finitely connected components

Proposition

Let $X$ be a weakly locally connected space and compact space. Then $X$ contains only finitely many connected components

Proof

using weakly locally connected space is a coproduct of connected components we may write $M = \coprod_{x \in \pi_0(M)} M_x$ where $M_x$ denotes the connected component of $M_x$. Now $M_x$ is an open cover of $M$, so only finitely many have to suffice. But $M_x$ are pairwise disjoint, so there can only exist finitely many.
