Existenz einer eindeutigen Topologie zu einem Umgebungssystem

Satz

Sei $X$ eine Menge, so dass für jedes $x$ eine Menge $\mathcal{U}(x) \subseteq \mathcal{P}(X)$ existiert, so dass die Bedingungen für ein Umgebungssystem erfüllt sind, so existiert eine eindeutige Topologie auf $X$, so dass $\mathcal{U}(x)$ ein Umgebungssystem für $x \in X$ ist.
