equivalence in the limit category

Proposition

Let $I: \mathcal{I} \rightarrow \mathcal{C}$ be a diagram in category Cat, $\lim \mathcal{C}_i$ the limit category. Then under the description of the Hom anima $\mathrm{Hom}_{\lim \mathcal{C}_i}((x_i), (y_i)) \simeq \lim \mathrm{Hom}_{\mathcal{C}_i}(x_i,y_i)$, a morphism $(f_i): (x_i) \rightarrow (y_i)$ in $\lim \mathcal{C}_i$ is an equivalence if and only if each $f_i$ is an equivalence.

recall that a morphsim $\Delta^1 \rightarrow \mathcal{C}$ is an equivalence if and only if the diagram
