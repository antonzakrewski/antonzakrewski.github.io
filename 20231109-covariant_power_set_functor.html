covariant power set functor

Definition

given category set, the covariant power set functor is defined as functor

\begin{align*} \mathcal{P}: \mathrm{Set} \rightarrow& \mathrm{Set} \\ A \mapsto& \mathcal{P}(A) \\ (f: A \rightarrow B) \mapsto& \begin{cases} f': \mathcal{P}(A) \rightarrow \mathcal{P}(B) \\ C \mapsto& f[C] \end{cases} \end{align*}
