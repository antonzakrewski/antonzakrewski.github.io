primary ideal in a PID

Proposition

Let $A$ be a principal ideal domain Then the set of primary ideals is given by

\begin{align*} \{(0)\} \cup \{(p^n) \vert n \in \mathbb{N}^+\} \end{align*}

Proof

Let $\mathfrak{q}$ be a primary ideal, then $\sqrt{\mathfrak{p}} = (p)$ is a principal prime ideal. Therefore $p \in A$ is a prime or $0$

Note that $\mathfrak{q} = q$ for some element $q \in A$ as $A$ is a pid. Then it follows that $q \sim p^n$ are associated, as otherwise there would exist a different prime element $p'$ in the factorization showing that $\sqrt{\mathfrak{q}} \supseteq p' \cdot p$
