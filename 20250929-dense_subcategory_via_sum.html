dense subcategory via sum

Proposition

Let $\mathcal{C}_0 \subseteq \mathcal{C}$ be a stable subcategory TFAE:

  1. $\mathcal{C}_0 \subseteq \mathcal{C}$ is a dense stable subcategory
  2. for each object $x \in \mathcal{C}$ there exists an $x' \in \mathcal{C}$ such that $x \oplus x' \in \mathcal{C}_0$

Proof

1) $\implies$ 2)

2) $\implies$ 1)

note that idempotent completion functor preserves fully faithful functors.

Hence it consider the map $x \oplus x' \rightarrow x x \oplus x'
