projectivity is a zariski local property

Proposition

Being a projective module is a zariski-local property.

Proof

follows as a module $M$ is projective if and only if $\mathrm{Hom}_{\mathrm{Mod}_R}(M,-)$ preserves $\Delta^{\mathrm{op}}$ shaped colimits and each extension of scalars preserves colimits, since it is a left adjoint.
