vanishing set and radical

Proposition

Let $A$ be a commutative ring and $\mathrm{Spec}(A)$ the Zariski spectrum equipped with the Zariski topology. Suppose $\mathfrak{a}$ is an ideal, then it holds for the Vanishing set

\begin{align*} V(\mathfrak{a}) = V(\sqrt{\mathfrak{a}}) \end{align*}

Proof

a)

corollary of:

  • Vanishing set and order reversing

b)

corollary of:

  • radical of an ideal as intersection of prime ideals

Suppose $\mathfrak{p} \in V(\mathfrak{a})$, then it also holds $\sqrt{\mathfrak{a}} \subseteq \mathfrak{p}$ and hence $\mathfrak{p} \in V(\sqrt{\mathfrak{a}})$
