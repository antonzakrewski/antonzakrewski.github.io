n-truncated object in a stable category is zero object

Proposition

let $\mathcal{C}$ be a stable category and $X$ an n-truncated object. Then $X\simeq 0$

Proof

Let $y \in \mathcal{C}$ be arbitrary, then we have to show that

\begin{align*} \mathrm{map}_{\mathcal{C}}(y,x) \end{align*}

is contractible

For that we use that the mapping anima of a stable category lifts to spectra so in particular we get mapping anima and suspension/loop space for a pointed category

\begin{align*} \mathrm{map}_{\mathcal{C}}(y, \Omega^n x) \simeq \Omega^n \mathrm{map}_{\mathcal{C}}(y,x) \end{align*}

by assumption $\mathrm{map}_{\mathcal{C}}(y,x)$ is n-truncated (for all $y \in \mathcal{C}}$!), so in particular $\Omega^n \mathrm{map}_{\mathcal{C}}(y,x)$ is given by the point (since it is not empty, as $\mathcal{C}$ is pointed).

Hence $\Omega^n x$ is the terminal object and since loop space functor is an equivalence in a stable category (and thus preserves terminal objects) we get that $x$ was already the terminal object resp. the zero object.
