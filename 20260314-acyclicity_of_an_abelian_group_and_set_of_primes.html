acyclicity of an abelian group and set of primes

Proposition

Let $A$ be an abelian group. Then there exists a set of primes $P$ such that

  1. $A \simeq \mathbb{Z}[P^{-1}]$

or

  1. $A \simeq \bigoplus_{p \in P} \mathbb{F}_p$

Proof

a) if $A$ is torsion free, then let $P$ be the set of primes, which act invertibly on $A$. Then we claim that $A \sim \mathbb{Z}[P^{-1}]$, as both are torsion free and a prime $p$ acts on $\mathbb{Z}[P^{-1}]$ invertibly if and only if it lies in $P$ and hence it acts invertibly on $\mathbb{Z}[P^{-1}]$ iff it acts invertibly on $A$.

b) if $A$ is torsion, then let $P$ be the set of primes, such that $p$ does not act invertibly on $A$. Then neither $A$ nor $\bigoplus_{p \in P} \mathbb{F}_p$ are torsion-free. Moreover, $p$ acts invertibly on $\bigoplus_{p \in P} \mathbb{F}_p$ if and only if $p \not\in P$ and hence if and only if it acts invertibly on $A$.
