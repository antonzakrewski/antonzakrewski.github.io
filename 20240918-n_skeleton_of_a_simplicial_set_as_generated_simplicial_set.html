n-skeleton of a simplicial set as generated simplicial set

Proposition

Let $X$ be a simplicial set, $\mathrm{sk}_n(X)$ be the \(n\)-skeleton. Then

\begin{align*} \mathrm{Sk}_n(X) \end{align*}

is up to isomorphism given by the smallest sub simplicial set containing $X_0,...,X_n$

Proof

By definition a morphism $\mathrm{Sk}_n(X) \rightarrow Y$ corresponds to maps

\begin{align*} X_0 \rightarrow& Y_0 \\ \ddots& \\ X_n \rightarrow Y_n \end{align*}

compatible with degeneracy and face maps.

But the sub simplicial set $S$ generated by $X_0,...,X_n$ precisely satisfies this universal property, as each element $x \in S_k$ for $k > n$ is by assumption degenerate simplex, hence by maps between simplicial sets and non degenerate simplices is defined by some smaller simplex.
