Proposition

Proof

Note that $L(p,n)$ is conencted, so $H_0(L(p,n)) = \mathbb{Z}$ Using pi_1 of a lens space & first hurewicz we get $H_1(L(p,n)) = \mathbb{Z}/p \mathbb{Z}$ Furthermore $L(p,n)$ is orientable (cf. manifold with pi_1 without index 2 subgroup as orientable manifold). So we will now use poincare duality & the universal coefficient Theorem for cohomology:

Then by poincare duality $H^n(L(p,n)) = \mathbb{Z}, H^{n-1}(L(p,n)) = \mathbb{Z}/p \mathbb{Z}$. This implies that $H_{n-2}(L(p,n)) = \mathbb{Z}/p \mathbb{Z} \oplus \mathbb{Z}^r$. Furthermore $H^1(L(p,n)) \cong \mathrm{Hom}(\mathbb{Z}/p \mathbb{Z}, \mathbb{Z})= 0$ which shows that $H_{n-1}(L(p,n)) = 0$
