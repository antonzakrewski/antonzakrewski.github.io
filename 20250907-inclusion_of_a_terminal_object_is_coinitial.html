inclusion of a terminal object is coinitial

Proposition

Let $\mathcal{C}, \mathcal{D}$ be categories and $\mathcal{F}: \mathcal{C} \rightarrow \mathcal{D}$ an fully faithful functor where $\mathcal{D}$ contains a terminal object which already lies in $\mathcal{C}$. Then the functor $\mathcal{F}$ is coinitial

Proof

using coinitial functors satisfy two out of three we may reduce this to to the case $\mathcal{C} = \{*\}$

where this is the inclusion of the terminal object

now using quillens theorem A for coinitial functors we need to show that the coslice $\{*\}_{d/}$ is weakly contractible for each $d \in \mathcal{D}$.
