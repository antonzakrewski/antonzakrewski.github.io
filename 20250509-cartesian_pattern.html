cartesian pattern

Definition

A cartesian patterin is an algebraic pattern with a morphism of algebraic patterns

\begin{align*} \vert - \vert: \mathcal{O} \rightarrow \mathrm{Fin}_* \end{align*}

which satisfies an appropriate version of the segal condition, i.e. for any $O \in \mathcal{O}$ the induced map

\begin{align*} \mathcal{O}_{O/}^{\mathrm{el}} \rightarrow (\mathrm{Fin}_*)^{\mathrm{el}}_{\vert O \vert/} = \{p_1,...,p_n\} \end{align*}

is an equivalence

note that a morphism between algebraic patterns preserves elementary objects and inert morphisms
