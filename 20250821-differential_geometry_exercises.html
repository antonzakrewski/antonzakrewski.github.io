Task

Consider the following equivalence relation on S1: We set 1 ∼ i, −1 ∼ −i and z ∼ z for z̸ ∈ {±1, ±i}, i.e. every equivalence class contains exactly two elements. Show that M/ ∼ is not Hausdorff.

Solution

We claim that there do not exist disjoint neighbourhoods of $[1]$ and $[-1]$. So let $U_1, U_{-1} \subseteq S^1/\sim$ be neighbourhoods. Then using the explicit description of quotient topology we get that $p^{-1}[U_1], p^{-1}[U_{-1}]$ are open subsets and therefore contain \(\epsilon\)-balls around $1,\mathrm{i}$ and $-1, -\mathrm{i}$. So in particular there exist $\varepsilon', \varepsilon'' > 0$ with $e^{\mathrm{i} x} \subseteq p^{-1}[U_1]$ for $x \in B_{\varepsilon'}(\frac{\pi}{2} \mathrm{i})$ resp. $e^{\mathrm{i} x} \subseteq p^{-1}[U_{-1}]$ for $x \in B_{\varepsilon''}(\frac{3\pi}{2} \mathrm{i})$. So w.l.o.g. assume $\varepsilon' = \varepsilon''$ (e.g. by taking $\mathrm{min}(\varepsilon', \varepsilon'')$, because we then identify $\mathrm{e}^{\frac{3\pi}{2} \mathrm{i} + 0.5\varepsilon}$ with $\mathrm{e}^{\frac{\pi}{2} \mathrm{i} + 0.5 \varepsilon}$
