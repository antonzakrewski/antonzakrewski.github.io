countable modules is a serre subcategory

Proposition

Let \(R\) be a ring and $\mathrm{RMod}$ the category RMod. The category of countable modules is a serre subcategory.

Proof

follows as any subobject / quotient object / extension of countable modules is again countable:

  • any extension $0 \rightarrow A \rightarrow B \rightarrow C \rightarrow 0$is - as a set - given by $A \times C$.
