lp sequence is a null sequence

Proposition

Let $(x_n)$ be a sequence in <lp> for $p \in [1,\infty)$. Then $x_n$ is a null sequence

Proof

observe that $\sqrt[p]{\sum_{n=1}^n \vert x_n \vert^{p} }$ converges, so inparticular so does $\sum_{n=1}^\infty \vert x_n \vert^p$ (as $\sqrt[p]{-}$ is sequentially continuous). hence $\sum_{n=m}^\infty \vert x_n \vert^p$ converges to $0$ for $m \rightarrow \infty$. In particular, $\vert x_n \vert^p$ is a null sequence, hence so is $x_n = \sqrt[p]{\vert x_n \vert^p} \rightarrow 0$.
