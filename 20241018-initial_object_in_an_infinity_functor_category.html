initial object in an infinity functor category

Proposition

Let $\mathcal{C}$ be an infinity category, $K$ a simplicial set and $f: K \rightarrow \mathcal{C}$ a morphism of simplicial sets Assume that for each $x \in k_0$ the object $\mathcal{F}(x)$ is an initial object

Then $f \in \mathrm{Fun}(K, \mathcal{C})_1$ is a terminal object (cf. infinity functor category)
