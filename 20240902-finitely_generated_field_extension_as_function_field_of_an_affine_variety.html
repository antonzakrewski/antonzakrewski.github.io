finitely generated field extension as function field of an affine variety

Proposition

Let $k \hookrightarrow K$ be a finitely generated field extension. Then there exists an affine variety $X$ such that the function field is isomorphic to $K$

\begin{align*} K \cong k(X) \end{align*}

Proof

Let $K = k(x_1,...,x_n)$. Then set $B = k[x_1,...,x_n] \hookrightarrow k(x_1,...,x_n)$ as K-subalgebra Then $k[x_1,...,x_n]$ is a finitely generated Algebra and Integral domain (cf. subring of an integral domain)

Then by coordinate ring functor essentially surjective there exists an algebraic set (even affine variety) $X$ with $B \cong \mathcal{O}(X)$.

Then $X$ suffices, as

\begin{align*} k(X) = \mathrm{Quot}(\mathcal{O}(X)) \end{align*}
