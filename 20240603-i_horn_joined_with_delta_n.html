i-horn joined with delta n

Proposition

Let $\Delta^n$ be the represented simplicial set, $\partial \Delta^m$ the i-horn Then the join is given by

\begin{align*} \Lambda_{j}^n \star \Delta^m =& \Delta^{n + m + 1} \setminus \{ \textrm{vertices containing } (0,...,j-1,j+1,...n)\} \\ \Delta^m \star \Lambda_j^n =& \Delta^{n + m + 1} \setminus \{ \textrm{vertices containing } (m + 1,...,m+j,m+j+2,...,m+n+1) \} \end{align*}

Proof

heuristic

$\partial \Delta^n$ does not contain vertices containing $(1,...,j-1,j+1,n)$. Therefore any vertex containing $(1,...,j-1,j+1,n)$ can not be constructed in

\begin{align*} \coprod (\Lambda_j^n)[n] \times (\Delta^m)[j] = (\partial \Delta^n \star \Delta^m)[n + j] \end{align*}

Each other vertex can be identified with $(\textrm{sides in }\partial \Delta^n) \times (\textrm{sides in } \Delta^m)$
