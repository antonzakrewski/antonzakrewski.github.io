set of functions g-set functor

Definition

Let $G$ be a group, $\mathrm{G-Set}$ the Category of G-Sets and $\mathrm{Set}$ the category set Then the set of functions functor is defined as functor

\begin{align*} \mathrm{G-Fun}: \mathrm{Set} \rightarrow& \mathrm{G-Set} \\ A \mapsto& \mathrm{Hom}_{\mathrm{Set}}(G,A) \\ (f: A \rightarrow B) \mapsto& \left(f^{\rightarrow}: \mathrm{Hom}_{\mathrm{Set}}(G,A) \rightarrow \mathrm{Hom}_{\mathrm{Set}}(G,B) \right) \end{align*}
