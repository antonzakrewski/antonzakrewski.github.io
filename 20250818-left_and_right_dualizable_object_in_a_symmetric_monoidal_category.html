left and right dualizable object in a symmetric monoidal category

Proposition

Let $\mathcal{C}, \otimes, \mathbbm{1}$ be a symmetric monoidal category and $X$ a right dualizable object with $\mathrm{ev}^r: X^{\vee} \otimes X \rightarrow \mathbbm{1}$ and $\mathrm{coev}^r: \mathbbm{1} \rightarrow X \otimes X^{\vee}$ Then $X$ is also a left dualizable object with

  1. $\mathrm{ev}^l: X \otimes X^{\vee} \simeq X^{\vee} \otimes X \rightarrow \mathbbm{1}$
  2. $\mathrm{coev}^r: \mathbbm{1} \rightarrow X \otimes X^{\vee} \simeq X^{\vee} \otimes X$

Proof
