infinity projective object

Definition

Let $\mathcal{C}$ be an infinity category with geometric realizations. Then an object $P \in \mathcal{C}$ is said to be projective, if the <mappingspacefunctor>

\begin{align*} \mathrm{map}_{\mathcal{C}}(P,-): \mathcal{C} \rightarrow \mathrm{An} \end{align*}

preserves geometric realizations.
