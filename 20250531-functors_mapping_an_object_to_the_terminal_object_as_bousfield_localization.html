functors mapping an object to the terminal object as S-local objects for a presentable category

Proposition

Let $\mathcal{D}$ be presentable and $\mathrm{Fun}(I, \mathcal{D})$ the functor category for some infinity category $\mathcal{C}$ Let $M \subseteq \mathcal{C}_0$ be a subset.

Then the full subcategory

\begin{align*} \mathrm{Fun}^{M}(\mathcal{C}, \mathcal{D}) \end{align*}

of functors $\mathcal{F}$ with $\mathcal{F}(m) = *$ is the subcategory of S-local objects for some $S$

actual proof

By definition an element $\mathcal{F} \in \mathrm{Fun}(I,\mathcal{C})$ lies in $\mathrm{Fun}^{M}(I, \mathcal{D}) if and only if

\begin{align*} \mathcal{F}(m) \rightarrow * \end{align*}

is an equivalence for all $m$, so fix an $m\in M$

By evaluation for a presentable categories admits left adjoint / evaluation for a presentable category admits right adjoint the infinity evaluation functor

\begin{align*} \mathrm{ev}_(m): \mathrm{Fun}(\mathcal{C},\mathcal{D}) \rightarrow \mathcal{D} \end{align*}

admits an infinity left adjoint

\begin{align*} \mathcal{L}_{m}: \mathcal{D} \rightarrow \mathrm{Fun}(\mathcal{C},\mathcal{D}) \end{align*}

Furthermore

\begin{align*} \mathrm{map}_{\mathcal{D}}(-,*) \simeq * \end{align*}

Using weak infinity yoneda lemma it suffices to show that

\begin{align*} \mathrm{Map}_{\mathcal{D}}(D,\mathcal{F}(c_i)) \rightarrow \mathrm{Map}_{\mathcal{D}}(D,*) \end{align*}

by accessible category and set of compact generators it suffices to show that for $D \in \mathcal{D}^{\kappa}$ for the essentially small subcategory of kappa compact objects

Now using the adjunctions we get

\begin{align*} \mathrm{Map}_{\mathcal{D}}(D,\mathcal{F}(m)) \simeq& \mathrm{Map}_{\mathrm{Fun}(N(\mathcal{C},\mathcal{D})}(\mathcal{L}_{m}(D),\mathcal{F}) \\ \mathrm{Map}_{\mathcal{D}}(D, *) \simeq& \mathrm{Map}_{\mathrm{Fun}(N(\mathcal{C},\mathcal{D})}(\mathrm{const}(\emptyset), M)\\ \cong& * \end{align*}

where $\mathrm{const}(\emptyset)$ is of course the initial object in the functor category. Here it suffices to check against

\begin{align*} \mathrm{const}(\emptyset) \rightarrow \mathcal{L}_{m}(D) \end{align*}

since if this is an equivanlence, then we get the chain of equivalences

for a jointly conservative set of objects $D$
