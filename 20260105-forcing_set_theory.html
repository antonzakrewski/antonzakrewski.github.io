forcing (set theory)

Some impressions

This is rather informal (and possibly noncorrect/misleading) understanding

  • ZFC is rather agnostic about whether some set exists
    • only some operations (power set, unions, etc.) and the empty set is required
  • for continuums hypothesis:
    • want to understand cardinalities
    • cardinalities can be thought of as equivalence classes of sets up to bijection
    • but bijections are maps and hence also some form of sets
    • now forcing allows us to add sets in a controlled way
      • some of these sets could be for example new bijections
      • this changes our cardinalities
