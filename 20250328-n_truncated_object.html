n-truncated object

Definition

Let $\mathcal{C}$ be an infinity category Then an object $x$ is said to be $n$ truncated, if

\begin{align*} \mathrm{Hom}_{\mathcal{C}}(y,x) \end{align*}

is an n-truncated anima for all $y \in \mathcal{C}$

Remark

Define truncatedness via the yoneda embedding $\mathcal{C} \rightarrow \mathcal{P}(\mathcal{C})$.
