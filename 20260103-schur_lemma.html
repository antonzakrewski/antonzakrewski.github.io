schur lemma

Proposition

Let $\mathcal{A}$ be an abelian category and $f: V_1 \rightarrow V_2$ a nonzero morphism Then

  1. if $V_1$ is a simple object, then $f$ is a monomorphism
  2. if $V_2$ is a simple object, then $f$ is an epimorphism
  3. if both are simple objects, then $f$ is an isomorphism

Proof

1)

observe that $\mathrm{ker}(f) \hookrightarrow V_1$ is a subobject, which is not equal to $V_1$ (since $f$ is nonzero). hence it must be the zero object or $f$ must be a monomorphism.

2)

observe that $V_2 \twoheadrightarrow \mathrm{coker}(f)$ is a quotient object, which is not equal to $V_1$ (since $f$ is nonzero). hence it must be the zero object or $f$ must be an epimorphism.
