1 categorical segal object as monoid object

Proposition

Let $\mathcal{C}$ be a \(1\)-category with (sufficiently many) finite products and $N(\mathcal{C})$ the nerve Then a segal object

\begin{align*} X: N(\Delta^{\mathrm{op}}) \rightarrow N(\mathcal{C}) \end{align*}

with $X_0 \simeq *$ is precisely given by a monoid object for the (analogue) cartesian monoidal structure

Proof

\begin{align*} X: \Delta^{\mathrm{op}} \rightarrow \mathcal{C} \end{align*}
