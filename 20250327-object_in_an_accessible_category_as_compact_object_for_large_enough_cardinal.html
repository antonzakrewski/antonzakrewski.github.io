object in an accessible category is a compact object for large enough cardinal

Proposition

Let $\mathcal{C}$ be an kappa accessible infinity category. Then each object $x \in \mathcal{C}$ is kappa' compact for $\kappa'$ large enough.

Proof

Note that

\begin{align*} \mathcal{C} \simeq \mathrm{Ind}_{\kappa}(\mathcal{C}^{\kappa}) \end{align*}

Then an ind object is a filtered colimit $x is a colimit for some 1 filtered diagram $K \rightarrow \mathrm{Ind}_{\kappa}(\mathcal{C}^{\kappa})$. Then $K$ is \(\kappa'\)-small for some large enough $\kappa'$.

In particular it is a \(\kappa'\)-small colimit of $\kappa'$ compact (even \(\kappa\)-compact for $\kappa \leq \kappa'$) objects, hence $\kappa'$ compact (cf. kappa small colimit of kappa compact objects).
