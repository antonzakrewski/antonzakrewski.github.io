initial object in an infinity category is an empty colimit

Proposition

Let $\mathcal{C}$ be an infinity category, $x \in \mathcal{C}_0$ an object TFAE:

  1. $x$ is an initial object
  2. $x$ is a colimit for the initial morphism $\emptyset \rightarrow \mathcal{C}$ of the initial simplicial set

Proof
