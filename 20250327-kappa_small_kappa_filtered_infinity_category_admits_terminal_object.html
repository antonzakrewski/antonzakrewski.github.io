essentially kappa small, kappa filtered infinity category admits terminal object

Proposition

Let $\kappa$ be a regular cardinal, $\mathcal{C}$ a essentially kappa small simplicial set kappa filtered infinity category. Then $\mathcal{C}$ admits a terminal object.

Proof

w.l.o.g. assume that $\mathcal{C}$ is \(\kappa\)-small, since terminal objects are preserved under joyal equivalences.

Consider the identity functor

\begin{align*} \mathcal{C} \rightarrow \mathcal{C} \end{align*}

Then there exists an extension

\begin{align*} \mathcal{C}^{\triangle} \rightarrow \mathcal{C} \end{align*}

since $\mathcal{C}$ is \(\kappa\) small.
