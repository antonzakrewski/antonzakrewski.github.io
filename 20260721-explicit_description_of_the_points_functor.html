explicit description of the points functor

Proposition

Let $P$ be a partially ordered set Then a map of sets $f: P \rightarrow \{\emptyset \rightarrow *\}$ is determined by the subset $f^{-1}[*] \subseteq P$ and it is a morphism of locales $1 \rightarrow X$ if and only if the following holds:

  1. $f^{-1}[*]$ is upwards closed
  2. if $f^{-1}[*]$ is nonempty, then $x \land y = x \coprod y \in f^{-1}[*]$ whenever $x$ and/or $y$ in $f^{-1}[*]$
  3. whenever $\coprod_{i \in I} x_i \in f^{-1}[*]$, then there exists an $i \in I$ with $x_i \in f^{-1}[*]$
