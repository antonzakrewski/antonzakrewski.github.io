local property of a scheme

Definition

A property $P$ of schemes is local if the following holds

  1. If $X$ has the property $P$ and $U \subseteq X$ is an open subfunctor, then $U$ has the property $P$
  2. If $(U_i \subseteq X$)$ is an <open cover> of $X$ and each $U_i$ has poreprty $P$, then $X$ has property $P$.
