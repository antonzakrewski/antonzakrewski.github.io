infinity category admits extension for inner horn with arbitrary products

Proposition

Let $\Lambda_j^n \rightarrow \Delta^n$ be an inner horn inclusion, $\mathcal{C}$ an quasicategory and $X$ any simplicial set Then each extension problem 

\begin{displaymath}
\begin{tikzcd}
\Lambda_j^n \times X \arrow[]{r}{} \arrow[]{d}{} & \mathcal{C} \
\Delta^n X \arrow[dashed]{ru}{}& 
\end{tikzcd}
\end{displaymath}

admits a solution

Proof

corollary of

  1. bijection of extension problems for an adjunction
  2. category sSet as cartesian closed category
  3. inner hom into a quasicategory as quasicategory

where 

\begin{displaymath}
\begin{tikzcd}
\Lambda_j^n \arrow[]{r}{} \arrow[]{d}{}& \mathrm{Fun}(X, \mathcal{C})
\Delta^n \arrow[dashed]{ru}{}& 
\end{tikzcd}
\end{displaymath}

admits a solution
