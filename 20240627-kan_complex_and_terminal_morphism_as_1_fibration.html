kan complex and terminal morphism is a left/right/kan fibration

Proposition

Let $\mathrm{sSet}$ be the category sSet and $K \in \mathrm{Ob}( \mathrm{sSet})$ a simplicial set

TFAE:

  1. $K$ is a Kan complex
  2. $K \rightarrow \Delta^0$ is a kan fibration
  3. $K \rightarrow \Delta^0$ is a left fibration
  4. $K \rightarrow \Delta^0$ is a right fibration

Proof

  • extension property and LLP against terminal morphism
  • left fibration into an infinity groupoid as kan fibration
  • right fibration into an infinity groupoid as kan fibration
  • 0-simplex as kan complex / 0-simplex as only infinity groupoid
