minimal exact structure of an additive category

Definition / Proposition

Let $\mathcal{C}$ be a stable infinity category, then the minimal exact structure is defined as exact structure containing maps homotopic to

  1. $A \rightarrow A \oplus B$ as injections
  2. $A \oplus B \rightarrow B$ as projections

Proof

$0 \hookrightarrow A$ is injection.

Follows from

\begin{align*} 0 \hookrightarrow A \oplus 0 \simeq A \end{align*}

$A \twoheadrightarrow B$ is projection

Follows from

\begin{align*} A \oplus 0 \twoheadrightarrow 0 \end{align*}
