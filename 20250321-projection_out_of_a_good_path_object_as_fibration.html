projection out of a good path object for a fibrant object as fibration

Proposition

Let $(\mathcal{C}, \mathcal{W}, \mathrm{Cof}, \mathrm{Fib})$ be a model category Then the map

\begin{align*} Y^I \rightarrow Y \end{align*}

for a good path object $Y^I$ and a fibrant object is a fibration
