spectrum object

Definition

Let $\mathcal{C}$ be a finitely cocomplete infinity category. Then a spectrum object is an object in the category of Spectra for an infinity category

\begin{align*} \mathcal{F} \in \mathrm{Exc}_*(\mathrm{Spc}_*^{\mathrm{fin}}, \mathcal{C}) \end{align*}

where $\mathrm{Spc}_*^{\mathrm{fin}} = (*)^{\mathrm{fin}} \subseteq \mathcal{P}(*)$
