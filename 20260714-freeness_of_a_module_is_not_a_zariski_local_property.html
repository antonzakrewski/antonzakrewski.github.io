freeness of a module is not a zariski-local property

Proposition

Being a free module is not a zariski-local property of modules.

Proof

Consider $R = \mathbb{Z}/6 \mathbb{Z} \simeq \mathbb{Z}/2 \mathbb{Z} \times \mathbb{Z}/3 \mathbb{Z}$, the elements $(1,0)$ and $(0,1)$ which generate the ideal. Now let $M = \mathbb{Z}/2 \mathbb{Z} \oplus 0$, which is not a free module (e.g. for cardinality reasons).

Moreover, $R_{(1,0)} \cong 0 \times \mathbb{Z}/3 \mathbb{Z}, R_{(0,1)} = \mathbb{Z}/2 \mathbb{Z} \times 0$ and $M_{(1,0)} \cong 0, M_{(0,1)} \cong \mathbb{Z}/2 \mathbb{Z}$ shows that being free is not a zariski local property.
