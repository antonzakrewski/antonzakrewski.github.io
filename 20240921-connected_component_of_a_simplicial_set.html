connected component of a simplicial set

Definition

Let $X$ be a simplicial set. Then a connceted component of $X$ is a maximal connected simplicial subset

Note that a connected component of $x \in X_0$ is given by

\begin{align*} [x]_0 = \{y \vert \exists 1-\textrm{simplex connecting} x,y \} \end{align*}

and $[x]_n$ as set of simplices $\sigma$, such that each vertex lies in $[x]_0$.
