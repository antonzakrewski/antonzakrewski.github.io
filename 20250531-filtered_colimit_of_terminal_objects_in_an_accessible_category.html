kappa filtered colimit of terminal objects in a presentable category

Proposition

Let $\mathcal{C}$ be an kappa accessible infinity category with terminal object. Then the \(\kappa\)-filtered colimit of terminal objects is again the terminal object.

Proof

consider accessible category and set of compact generators i.e. a collection $S$ (even set) of compact objects which detect equivalences Then for arbitrary $s \in S$

\begin{align*} \mathrm{map}_{\mathcal{C}}(s,\mathrm{colim}_{I} * ) \cong& \mathrm{colim}_{I} \mathrm{map}_{\mathcal{C}}(s, * ) \\ \cong& \mathrm{colim}_{I} * \\ \cong& * \end{align*}

where we have used that $s$ is compact and an explicit colimit computation (cf. colimit of a point in Anima + filtered simplicial set as weakly contractible)
