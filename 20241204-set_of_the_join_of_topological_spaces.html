set of the join of topological spaces

Definition

Let $X_i$ be topological spaces for $i \in I$. Then the join is defined as set

\begin{align*} \star_I X_i \coloneqq \{(t_i,x_i) \in \prod [0,1] \widehat{\times} X_i \vert t_i = 0 \text{ for almost all} i \in I, \sum_{i \in I} t_} = 1\}/\sim \end{align*}

where

\begin{align*} X_1 \widehat{\times} X_2 = \begin{cases} X_1 \times X_2 & \mbox{if } X_1,X_2 \neq \emptyset \\ \{*\} & \mbox{else } \\ \end{cases} \end{align*}
