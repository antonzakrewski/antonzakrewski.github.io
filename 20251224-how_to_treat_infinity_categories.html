I think it is similar to set theory. I couldn't define a set as a mathematical object:

My understanding of a Set is, that it is a mathematical object, which behaves like a Set (which is defined by the ZFC axioms).

Now when I started doing math, I had some Intuition for what a set is, but for example there (surely) was a moment, where I had to learn that $\{1,1\} = \{1\}$ are the same sets.

Furthermore, I would argue that one typically has a gut feeling, which set theoretic manipulations are fishy without knowing for example the axiom of regularity.
