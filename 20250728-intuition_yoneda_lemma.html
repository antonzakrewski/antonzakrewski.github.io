intuition: (1,1)-yoneda lemma

Intuiton natural transformation from contravariant hom functor as element

Let $\mathcal{C}$ be a (1,1)-Category, $c \in \mathcal{C}$ an object and $\mathcal{F}: \mathcal{C}^{\mathrm{op}} \rightarrow \mathrm{Set}$ a functor . Then we want to show that there exists a isomorphism (resp. Bijection)

\begin{align*} \mathrm{Hom}_{\mathcal{P}(\mathcal{C})}(\mathrm{Hom}_{\mathcal{C}}(-,c), \mathcal{F}(-)) \rightarrow \mathcal{F}(c) \end{align*}

Now let $\eta \in \mathrm{Hom}_{\mathcal{P}(\mathcal{C})}(\mathrm{Hom}_{\mathcal{C}}(-,c), \mathcal{F}(-))$ be a natural transformation. Then we have a map to $\mathcal{F}(c)$ namely $\eta(c): \mathrm{Hom}_{\mathcal{P}(\mathcal{C})}(\mathrm{Hom}_{\mathcal{C}}(c,c), \mathcal{F}(c))$ so it suffices to give an element in $\mathrm{Hom}_{\mathcal{C}}(c,c)$. Here we only have one possible choice: $\mathrm{id} \in \mathrm{Hom}_{\mathcal{C}}(c,c)$

So define

\begin{align*} \Psi: \mathrm{Hom}_{\mathcal{P}(\mathcal{C})}(\mathrm{Hom}_{\mathcal{C}}(-,c), \mathcal{F}(-)) \rightarrow& \mathcal{F}(c) \eta \mapsto& \eta(c)(\mathrm{id}) \end{align*}

It remains to show that this map is a bijection, so lets try to construct an inverse map: we want construct a mpa

\begin{align*} \Psi^{-1}: \mathcal{F}(c) \rightarrow& \mathrm{Hom}_{\mathcal{P}(\mathcal{C})}(\mathrm{Hom}_{\mathcal{C}}(-,c), \mathcal{F}(-)) \\ x \mapsto& \eta_x \end{align*}

for $x \in \mathcal{F}(c)$ we have to set

\begin{align*} \eta_x(c)(\mathrm{id}) = x \end{align*}

if the map is supposed to have any chance of being an inverse.

Now let $f \in \mathrm{Hom}_{\mathcal{C}}(d,c)$ be any element. Then we get

\begin{align*} f =& \mathrm{id} \circ f \\ =& f^*(\mathrm{id}) \end{align*}

and if $\eta_x(-)$ is supposed to be a natural transformation, then

has to commute.

so in particular

This also implies that any natural transformation $\eta: \mathrm{Hom}_{\mathcal{C}}(-,c) \rightarrow \mathcal{F}(-)$ is determined by its $x$, namely $\eta(c)(\mathrm{id})$

Now it remains to show that $\eta_x(-)$ is a welldefined natural transformation for $x \in \mathcal{F}(c)$
