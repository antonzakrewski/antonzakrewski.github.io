object

Definition

Let $\mathcal{C}$ be an infinity category Then an object is an element $c \in \mathcal{C}_0$

1-categorical Definition

A category $\mathcal{C}$ contains a collection of objects.

By abuse of notation, one often writes

\begin{align*} X \in \mathcal{C} \end{align*}

to denote

\begin{align*} X \in \mathrm{Ob}(\mathcal{C}) \end{align*}
