product of kan complexes as kan complex

Proposition

Let $K_i$ be Kan complexes, then so is their product $\prod K_i$

Proof

using

  • kan complex and terminal morphism as kan fibration
  • set with right lifting property as cosaturated set

hence closed under products where product with the terminal object canonically iso, showing that

\begin{align*} \prod K_i \rightarrow * \end{align*}

is a kan fibration
