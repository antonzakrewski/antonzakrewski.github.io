morphism in PrL lies in PrL kappa for some kappa

Proposition

Let $\mathcal{F}: \mathcal{C} \rightarrow \mathcal{D}$ be a morphism in PrL Then there exists some $\kappa$ such that $\mathcal{F}$ lies in PrL kappa

Proof

Recall that $\mathrm{Pr}^L_{\kappa} \subseteq \mathrm{Pr}^L_{\lambda}$ for $\kappa < \lambda$PrL kappa is a subcategory of PrL kappa' observe that there exists some $\kappa$ such that $\mathcal{C}, \mathcal{d}$ are $\kappa$ presentable.

Now there exists only a set of equivalence class of $\kappa$ compact objects in $\mathrm{Pr}^L_{\kappa}$.

Then any object in $\mathcal{D}$ is $\kappa$ compact for some $\kappa'$ (cf. object in an accessible category as compact object for large enough cardinal).

Hence taking an upper bound of all $\kappa'$ such that $\mathcal{F}(c)$ is $\kappa'$ compact for $c$ a $\kappa$ compact object suffices.
