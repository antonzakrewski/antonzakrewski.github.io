projective object as sifted colimit and retract

Proposition

Let $\mathcal{C}$ be a category $c \in \mathcal{C}$ a projective object. Assume that $c$ is an sifted colimit

\begin{align*} c = \mathrm{colim} s_i \end{align*}

for some $s_i$

Then $c$ is a retract of some $s_j$

Proof

observe that

\begin{align*} \mathrm{Hom}_{\mathcal{C}}(c, \mathrm{colim} s_i) \simeq \mathrm{colim} \mathrm{Hom}_{\mathcal{C}}(c, s_i) \end{align*}

and then apply the left adjoint pi_0, which gives (left adjoint preserves colimits)

\begin{align*} \pi_0(\mathrm{Hom}_{\mathcal{C}}(c, \mathrm{colim} s_i)) \simeq \mathrm{colim} \pi_0\mathrm{Hom}_{\mathcal{C}}(c, s_i)) \end{align*}

in the category set

Hence we find that the identity morphism is -- under this isomorphism - represented by a morphism $c \rightarrow s_i$ and moreover
