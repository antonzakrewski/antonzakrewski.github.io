mapping spectrum functor into a coconnective object maps connective to coconnective objects

Proposition

Let $\mathcal{C}$ be a stable infinity category equipped with a t-structure and $M$ an \(n\)-coconnective object (i.e. in $\mathcal{C}_{\leq n})$. Then the mapping spectrum functor

\begin{align*} \mathrm{Hom}_{\mathcal{C}}(-,M) \end{align*}

maps $m$ connective objects to $m-n-1$ coconnective objects.
