2) $\implies$ 1)

Note that a finite set is a finite coproduct of the singletons $\{*\}$ By finite colimit of compact objects as compact object it suffices to show that $\{*\}$ is a compact object: As

\begin{align*} \mathrm{Hom}_{\mathrm{Set}}(*, -) \simeq \mathrm{id} \end{align*}

are naturally isomorphic, it follows that $*$ is compact (cf. natural isomorphism and preserved colimit)
