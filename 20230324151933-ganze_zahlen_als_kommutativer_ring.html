Ganze Zahlen als kommutativer Ring

Satz

Die Ganze Zahlen mit der Verknüpfung:

\begin{align*} (a,b) + (a',b') =& (a + a',b + b') \\ (a,b) \cdot (a',b') =& (aa' + bb', ab' + a'b) \end{align*}

ein kommutativer Ring

Beweis

welldefined

Sei $(a,b) \sim (a',b')$ und $(c,d) \sim (c',d')$ so folgt:

Addition

Es gilt damit

\begin{align*} a + b' =& a' + b \\ c + d' =& c' + d \end{align*}

Addition der beiden Seiten ergibt

\begin{align*} a + b' + c + d' =& a' + b + c' + d \\ (a + c) + (b' + d') =& (a' + c') + (b + d) \end{align*}

Es folgt aus der Addition

\begin{align*} (a,b) + (c,d) =& (a + c, b + d) \\ (a',b') + (c',d') =& (a' + c', b' + d') \end{align*}

Insgesamt folgt dadurch $(a + c, b + d) \sim (a' + c', b' + d')$, was zu zeigen war

Kommutativ

folgt aus den Natürliche Zahlen als kommutativer Halbring:

\begin{align*} (a,b) + (a',b') =& (a + a', b + b') \\ =& (a' + a, b' + b) \\ =& (a',b') + (a,b) \end{align*}

neutrales Element

$(a,a)$ ist das evidente neutrale Element:

\begin{align*} (a, a) + (a',b') =& (a + a', a + b') \\ (a + a') + b' =& a' + (a + b') \end{align*}

inverses element

$(b,a)$ ist das evidente inverse Element für $(a,b)$

\begin{align*} (b,a) + (a,b) = (b + a, a + b) \end{align*}
