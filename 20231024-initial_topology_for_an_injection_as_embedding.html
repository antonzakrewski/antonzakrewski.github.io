initial topology for a single injection as embedding

Proposition

Let $(X, \mathcal{T}_X)$ be a topological space, $Y$ a set and

\begin{align*} f: Y \rightarrowtail X \end{align*}

an injection. For the topological space $(Y, \mathcal{T}_Y)$ with the initial topology, the map

\begin{align*} f: (Y, \mathcal{T}_Y) \rightarrow (X, \mathcal{T}_X) \end{align*}

is an topological embedding
