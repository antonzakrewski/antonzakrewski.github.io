Bernoullische Ungleichung

Satz

\begin{align*} (1 + x)^n \geq 1 + nx \quad n \in \mathbb{N}, x \geq -1 \end{align*}

Mit gleichheit g.d.w. $n = 0$ oder $n = 1$ oder $x = 0$

Beweis

  • durch vollständige Induktion

Induktionsanfang

\begin{align*} (1 + x)^0 = 1 = 1 + 0 \cdot x\\ (1 + x)^1 = 1 + x = 1 + 1 \cdot x \end{align*}

Induktionsschritt

\begin{align*} (1 + x)^{n+1} =& (1 + x) \cdot (1+x)^n \\ =& (1 + x)^n + (x)(1+x)^n \\ 1 + (n+1)x =& 1 + nx + x \\ (1 + x)^n \geq 1 + nx \\ (x)(1+x)^n > x % (x)(1+x)^n =& \begin{cases} % \binom{ & \mbox{if } x > 0 \\ % \sum_{k=0}^n \binom{n}{k} 1 & \mbox{if } x = 0 \\ % & \mbox{if } -1 \geq x < 0 \\ \end{cases} \end{align*}

für $x = 0$

\begin{align*} (0)(1 + 0)^n = 0 = x \end{align*}

für $x > 0$

\begin{align*} (x) (1 + x)^n =& \sum_{k=0}^n \binom{n}{k} 1^{n-k} y^k \\ =& x \cdot (1 + (...)) \\ =& x + x \cdot (...) \end{align*}
  • weil:
\begin{align*} x > 0 \Rightarrow x \cdot x > 0 \end{align*}
  • siehe: Anordnungsaxiome
\begin{align*} \Rightarrow x \cdot (...) > 0 \end{align*}

für $-1 \leq x < 0$

\begin{align*} (1 + x) \geq& 0 \\ (1 + x)^n \geq& 0 \\ (1 + x)^n \leq& 1 \\ % wie formal zu beweisen ? 1 \cdot x \leq (1 + x)^n \cdot x \end{align*}
