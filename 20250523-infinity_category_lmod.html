LMod Operad

Definition

The infinity operad $\mathbb{L}\mathrm{mod}$ is defined as 1-category containing

  1. objects $( \langle n\rangle, S)$ where $\langle n\rangle \in \mathrm{Fin}_*$ and $S \subseteq <n>^{\circ}$
  2. morphisms $( \langle n\rangle, S) \rightarrow (\langle m\rangle, S')$ are morphisms $\alpha: <n> \rightarrow <m>$ in $\mathrm{Fin}_*$ such that a) $\alpha(S \coprod *) \subseteq S' \coprod *$ b) for $s' \in S'$ $\alpha^{-1}(s') \cap S$ contains exactly one element which is also maximal in $\alpha^{-1}(s')$ with respect to the induced linear order of $\langle n\rangle^{\circ} = 1 \leq ... \leq n$

Then the map

\begin{align*} \mathbb{L}\mathrm{mod} \rightarrow \mathrm{Fin}_* \end{align*}

is defined as forgetful map

Remark: underlying category

The underlying category contains precisely two elements:

  1. $( \langle 1\rangle, \emptyset) \eqqcolon a$ - think of it as an element in the algebra
  2. $( \langle 1\rangle, <1>^{\circ}) \eqqcolon b$ - think of it as an element in the module

Hom

Note that

\begin{align*} \mathrm{Hom}_{\mathbb{L}\mathrm{mod}}^{\mathrm{act}}((b_1,..,b_n,a) = \begin{cases} \{\mathrm{total orders of } \langle n\rangle\} & \mbox{if } b_i = a \forall i \\ \emptyset & \mbox{else } \\ \end{cases} \mathrm{Hom}_{\mathbb{L}\mathrm{mod}}^{\mathrm{act}}((b_1,..,b_n,m) = \begin{cases} \{\mathrm{total orders of } \langle n\rangle \mathrm{ with maximal element i}\} & \mbox{if } b_i = m \forall i \\ \emptyset & \mbox{if } \mathrm{ not exactly one } b_i = m \\ \end{cases} \end{align*}
