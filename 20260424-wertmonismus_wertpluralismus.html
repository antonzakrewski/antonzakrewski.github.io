Wertmonismus / Wertpluralismus

Definition

Eine Wertmonistische Position behauptet, dass alle Werte auf einen einzigen Wert reduziert werden kann. Eine wertpluralistische Position bestreitet den Wertmonismus und führt dagegen an, dass es viele, nicht ineinander reduzierbare Werte gibt.

Beispiel

Bentham vertritt eine Wertmonistische Position, Präferenzutilitarismus ist auch Wertmonistisch (auch wenn die Präferenzen Konkret sehr wertpluralistisch sein können) . Moderner wäre jedoch eine Wertpluralistische Position, wonach es beispielsweise eine "objective List" an Werten gäbe.
