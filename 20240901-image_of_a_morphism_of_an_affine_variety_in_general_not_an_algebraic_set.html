image of a morphism of an affine variety in general not an algebraic set

Proposition

Let $K$ be a field, $X,Y$ algebraic sets and $f: X \rightarrow Y$ a morphism of affine algebraic sets. Then the set theoretic image is in general not an algebraic set

Proof

Let X = Z( X_1 \cdot X_2 = 1) \subseteq $\mathbb{A}_K^2$ and $Y = \mathbb{A}_K^1$ Then the map

\begin{align*} f: X \rightarrow& Y \\ (x_1,x_2) \mapsto& x_1 \end{align*}

is a morphism, but $\mathrm{im}(f) = \mathbb{A}_K^1 \setminus \{0\}$ is not an algebraic set (cf. simple affine line has cofinite topology)
