object with trivial homotopy objects in a complete t-structure

Proposition

Let $\mathcal{C}$ be a stable infinity category equipped with a complete t-structure and $X$ in $\mathcal{C}$ an object. TFAE:

  1. $X$ is the zero object
  2. $\pi_*(X)$ vanishes

Proof

1) $\implies$ 2)

clear

2) $\implies$ 1)

Observe that $\pi_*(X) \cong \pi_*(\tau_{\geq m}(X))$ for $* \geq m$ and similarly for $\tau_{\leq m}(X)$. Therefore $\pi_*(\tau_{\geq m}(X)) \cong \pi_*(\tau_{\leq m})(X) \cong 0$ all vanish.

Now consider the fiber sequence

\begin{align*} \tau_{\geq m} X \rightarrow X \rightarrow \tau_{\leq m-1} X \end{align*}

Then both outer terms vanish (cf. trivial bounded below object in a left-complete t-structure, trivial bounded above object in a right-complete t-structure), so $X$ is an extension of $0$ and $0$, i.e., trivial.
