limit containing the empty category is empty

Proposition

Let $\mathcal{C}_{-}: \mathcal{I} \rightarrow \mathrm{Cat}$ be a diagram, such that there exists an object $i \in \mathcal{I}$ with $C_{i} = \emptyset$. Then $\lim_{\mathcal{I}} \mathcal{C}_{i} = \emptyset$.

Proof

follows as $\emptyset$ is a strictly initial object, i.e. there exists a projection $\lim_{I} \mathcal{C}_i \rightarrow \emptyset$ which implies that $\lim_{\mathcal{I}} \mathcal{C}_i$ must be the empty category.
