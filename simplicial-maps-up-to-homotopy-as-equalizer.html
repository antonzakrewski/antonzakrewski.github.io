simplicial maps up to homotopy as coequalizer

Proposition

Let $X,Y$ be simplicial sets. Then the set of simplicial maps $X \rightarrow Y$ up to the equivalence relation generated by simplicial homotopy is a coequalizer

where $\iota_0,\iota_1: X \rightarrow X \times \Delta^1$ are the inclusions

Proof

note that by colimit in set two morphisms $f,g: X \rightarrow Y$ are identified precisely if there exists a zigzag $f \sim h_1$, $h_1 \sim h_2$ ... $h_n \sim g$ where $f_1 \sim h_1$ is given precisely if there exists an element $H: X \times \Delta^1 \rightarrow Y$ with $H \circ \iota_0 = f, H \circ \iota_1 = h_1$. This is precisely a homotopy
