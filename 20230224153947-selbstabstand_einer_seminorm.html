Selbstabstand einer Seminorm

Satz

Sei $(M, \| \cdot \|)$ ein semimetrischer Raum, dann gilt

\begin{align*} \| x - x \| = 0 \end{align*}

Beweis

es gilt:

\begin{align*} x - x = 0 = 0 \cdot 0 \end{align*}

und aus der absoluten Homogenität einer Norm folgt:

\begin{align*} \| x - x \| =& \| 0 \cdot 0 \| \\ =& \vert 0 \vert \cdot \| 0 \| \\ =& 0 \end{align*}
