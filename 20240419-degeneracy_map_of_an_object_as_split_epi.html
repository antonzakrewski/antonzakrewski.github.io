degeneracy map of an object as split mono

Proposition

Let $\mathcal{C}$ be a category and $X: \Delta^{\mathrm{op}} \rightarrow \mathcal{C}$ a simplicial object and $\sigma: X_{k} \rightarrow X_{k-n}$ a degeneracy map. Then $\sigma$ is a split mono

Proof
