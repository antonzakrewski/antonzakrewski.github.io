Proposition

Let $A$ be a Banach Algebra which satisfies the c star identity. Then there exists an isometric, star homomorphism

\begin{align*} \pi: A \rightarrow B(H) \end{align*}

where $H$ is a Hilbert space.

Moroever,

\begin{align*} \mathrm{span}(\pi(A) H) = H \end{align*}

so the representation is non-degenerate.

In particular, $\pi$ is injective and $A$ ican be identified with a closed subalgebra.

\begin{align*} A \rightarrow A \oplus \mathbb{C} \end{align*}

where we need to show that this map is an isometric inclusion and the RHS still is a banach algebra with c star identity.

which induces a norma on $A^u$ just by $\| x \| = \| L_x \|_{B(A)}$.

\begin{align*} L_{(a,\lambda)} = 0 \end{align*}

This shows that $L(A^u)$ is closed (argue: why $A^u$ is complete).

This shows $\| L_x \| = \| L_{x^*} \|$, which shows the c star identity.
