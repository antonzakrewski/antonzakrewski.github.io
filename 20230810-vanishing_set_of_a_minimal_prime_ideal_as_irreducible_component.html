vanishing set of a minimal prime ideal as irreducible component

Proposition

Let $A$ be a commutative ring and $\mathrm{Spec}(A)$ the Zariski spectrum equipped with the Zariski topology. Suppose $\mathfrak{p}$ is a minimal prime ideal, then the Vanishing set $V(\mathfrak{p})$ is an irreducible component.

Proof

There exists an bijection between prime ideals and irreducible closed subsets. since $\mathfrak{p}$ is minimal, it follows, that $V(\mathfrak{p})$ is maximal and hence an irreducible component.
