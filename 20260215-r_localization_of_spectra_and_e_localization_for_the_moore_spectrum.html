E-localization on bounded below spectra for the moore spectrum of a subring of the integers and homology equivalence

Proposition

Let $R \subseteq \mathbb{Q}$ be a subring. Then the E-localization of a spectra at the moore spectrum $M(R,k)$ is on bounded below spectra equivalently given by the S-local objects for $R$ homology.

Proof

warning: some rambling We need to show that a map $f: X \rightarrow Y$ between spectra is an E-equivalence for a spectrum for $E = M(R,k)$ if and only if it is an equivalence on $R$ homology. Note that essentially by construction $\mathbb{Z} \otimes_{\mathbb{S}} M(R,k) = \mathbb{Z}[k]$.

If $f$ is an E-equivalence, i.e. $f \otimes_{\mathbb{S}} M(R,k)$ is an equivalence, then in particular the map $f \otimes_{\mathbb{S}} M(R,k) \otimes_{\mathbb{S}} \mathbb{Z} \simeq f \otimes_{\mathbb{S}} R$ is an equivalence, hence $f$ is an R-homology equivalence.

If $f$ is an R-homology equivalence, then since $- \otimes_{\mathbb{S}} -$ is additive in both variables we get

\begin{align*} M(R,k) \otimes_{\mathbb{S}} R \simeq& (\mathrm{colim} \mathbb{S}[k] \xrightarrow{\cdot p} \mathbb{S}[k] ) \otimes_{\mathbb{S}} (\mathrm{colim} \mathbb{Z}) \\ \simeq& (\mathrm{colim}_p \mathbb{S}) \otimes_{\mathbb{S}} \mathbb{Z} \end{align*}

so this claim follows from homology whitehead for bounded below spectra :

the map

\begin{align*} (M(R,k)) \otimes_{\mathbb{S}} \mathbb{Z} \rightarrow (M(R,k)) \otimes_{\mathbb{S}} R \end{align*}

is an equivalence
