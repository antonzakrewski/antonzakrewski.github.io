split endomorphism for a finitely generated module is an isomorphism

Proposition

Let $M$ be a Noetherian module over a commutative ring $R$. Suppose $\varphi: M \rightarrow M$ is a split or split mono Then $\varphi$ is already an isomorphism

Proof

a) split epi

  • surjective endomorphism for a finitely generated module as isomorphism

b) split mono

pass to the corresponding split epi $\varphi^{-1}$. It is an isomorphism. Hence so is any one-sided inverse of $\varphi^{-1}$.
