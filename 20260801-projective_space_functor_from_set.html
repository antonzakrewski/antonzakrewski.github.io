projective space functor from Set and surjections

Definition

Let $\mathrm{Set}^{\mathrm{epi}}$ be the (non-full) subcategory of category set containing surjections Then there exists a functor

\begin{align*} \mathbb{P}_k^{-}: \mathrm{Set}^{\mathrm{epi}} \rightarrow \mathrm{Fun}(\mathrm{CAlg}_{k}, \mathrm{Set}) \end{align*}
