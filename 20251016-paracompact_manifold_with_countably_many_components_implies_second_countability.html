paracompact manifold with countably many components implies second countability

Proposition

Let $X$ be a topological manifold with the assumption, that it is paracompact and has countably many connected components. Then it is also secondcountable

Proof

connected component admits second countable basis

Assume that $X$ is connected.

We will show that $X$ is covered by countably many euclidean spaces (which in particular are second countable) to conclude that $X$ is second countable (cf. countable open cover by second countable subspaces) Let $\mathcal{U}$ be the open cover which we will inductively define via $\mathcal{U} = \bigcup_{n \in \mathbb{N}} \mathcal{U}_n$. We want to show that $\mathcal{U}$ will cover $X$ and that each $\mathcal{U}_n$ is countable.

Choose an open cover by euclidean spaces $U_i$ and a locally finite refinement $O_i$. Then choose a point $x_0 \in X$ (w.l.o.g. $X \neq \emptyset$) and a neighbourhood $U_x$ which intersects only finitely many $O_i$ and set $\mathcal{U}_0 = \{U_x\}$. Now for each point $x_{1,j} \in O_i$ for $i \in \{1,...,n\}$ choose a neighbourhood $U_{x_{1,j}}$ where each $U_{x_{1,j}}$ intersects only finitely many $O_{l}$. Then using euclidean space is countably compact we note that countably many from $U_{x_{1,j}}$ suffice for each $O_i$ (here we only have finitely many $O_i$). Thus set $\mathcal{U}_1 = \{U_{x_{1,j}}\}$ where we only need countably many.

Each of $U_{x_{1,j}}$ intersects only finitely man $O_i$, so repeat this process and define $\mathcal{U}_2,....$ analagoously.

we claim that $\mathcal{U} = \bicgup \mathcal{U}_n$ covers $X$. Since $X$ is connected, it suffices to show that the complement of $V \coloneqq \bigcup_{U \in \mathcal{U}} U$ is open (since $x_0 \in V$ is nonempty). So let $x \not\in V$, then there exists an $O_x$ from the locally finite refinement with $x \in O_x$. then it follows that $O_x \subseteq X \setminus V$ as otherwise we would have covered $O_X$ in some step before.
