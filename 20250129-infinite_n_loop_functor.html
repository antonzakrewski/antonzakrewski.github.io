infinite - n loop functor out of spectrum objects

Definition

Let $\mathcal{C}$ be a finitely cocomplete infinity category which admits terminal objects Then the infinity loop functor is defined as

\begin{align*} \Omega^{\infty - n }: \mathrm{Sp}(\mathcal{C}) \rightarrow \mathcal{C} \end{align*}

given by composition

\begin{align*} [n] \circ \Omega^{\infty} \end{align*}

with the shift endofunctor.
