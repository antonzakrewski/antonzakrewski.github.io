set with right lifting property

Definition

Let $\mathcal{C}$ be a category, $S \subseteq \mathrm{Mor}(\mathcal{C})$ a subcollection Then

\begin{align*} \chi_{R}(S) \end{align*}

is defined as subcollection of morphism $f: X \rightarrow Y$ such that

admits a solution for all $s: A \rightarrow B \in S$
