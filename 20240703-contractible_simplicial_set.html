contractible simplicial set

Definition

Let $\mathrm{sSet}$ be the category sSet, $X$ a simplicial set Then $X$ is said to be contraictible, if the terminal morphism

\begin{align*} 1: X \rightarrow \Delta^0 \end{align*}

is a simplicial homotopy equivalence.

Alternatively: the terminal morphism is an equivalence in Anima
