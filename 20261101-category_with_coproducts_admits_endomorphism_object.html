category with coproducts admits endomorphism with homotopy groups in maximal degree

Proposition

Let $\mathcal{C}$ be a category with finite coproducts such that there exist $X,Y \in \mathcal{C}$ with $\pi_n(\mathrm{Hom}_{\mathcal{C}}(X,Y)) \neq 0, \emptyset$. Then $\pi_n(\mathrm{Hom}_{\mathcal{C}}(Z,Z)) \neq 0$ for $Z = X \coprod Y$, in particular

Proof

choose an element $f: X \rightarrow Y$ - which exists, since otherwise $\pi_n(\mathrm{Hom}_{\mathcal{C}}(X,Y)) = \emptyset$. Then we have $\mathrm{Hom}_{\mathcal{C}}(Z,Z) \cong \mathrm{Hom}_{\mathcal{C}}(X,X \coprod Y) \times \mathrm{Hom}_{\mathcal{C}}(Y,X \coprod Y)$ where the RHS is nonempty, as the coprojection is an element. So it suffices to show that $\mathrm{Hom}_{\mathcal{C}}(X, X \coprod Y)$ has nontrivial $\pi_n$ (cf. homotopy group functor preserves products).

Here we can see that $Y$ is a retract of $X \coprod Y$ for the coprojection and the map $(f,\mathrm{id}): X \coprod Y \rightarrow Y$. Hence $\mathrm{Hom}_{\mathcal{C}}(X, X \coprod Y)$ has $\mathrm{Hom}_{\mathcal{C}}(X,Y)$ as a retract or $\pi_n(\mathrm{Hom}_{\mathcal{C}}(X,Y))$ is a retract of $\pi_n($\mathrm{Hom}_{\mathcal{C}}(X, X \coprod Y)$ which implies the claim.
