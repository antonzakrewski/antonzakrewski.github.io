epimorphism in category top

Proposition

Let $f: X \rightarrow Y$ be a continuous map. TFAE:

  1. $f$ is an epimorphism in category Top
  2. $f$ is a surjection

Proof

1) $\implies$ 2)

follosw from:

  • forgetful functor from Top to Set as left adjoint
  • left adjoint preserves epimorphisms
  • epimorphism in set as surjective map

2) $\implies$ 1)

faithful functor reflects epimorphisms for the set functor
