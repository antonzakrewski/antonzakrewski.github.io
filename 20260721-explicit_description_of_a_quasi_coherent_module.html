explicit description of a quasi-coherent module

Definition / Proposition

Let $X$ be an algebraic functor, then a quasi-coherent module consists of the following data:

  1. for every $x: \mathrm{Spec}(R) \rightarrow X$ an \(R\)-module $M(x)$
  2. for every commutative triangle 
\begin{displaymath}
\begin{tikzcd}
\mathrm{Spec}(S) \arrow[]{d}{\varphi} \arrow[]{rd}{y}& \\
& X \\
\mathrm{Spec}(R) \arrow[]{ru}{x}& 
\end{tikzcd}
\end{displaymath}

an \(S\)-linear isomorphism $\varphi^{*}(M(x)) \simeq M(y)$ where $\varphi^*$ is extension of scalars of the underlying rings.
