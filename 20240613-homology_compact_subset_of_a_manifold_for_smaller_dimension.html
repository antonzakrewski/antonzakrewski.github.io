locoal homology at a compact subset of a manifold of smaller dimension

Proposition

Let \(M\) be an \(n\)-dimensional manifold and $K \subseteq X$ compact. Then for an abelian group $A$ the singular homology is given

\begin{align*} H_k(X; X \setminus K,M) = 0 \end{align*}

Proof

using compact subset of a locally euclidean space coverable by finitely many locally euclidean compact subspaces Proof by induction

induction basis

If $K = K_1$ is contained in a single chart $U_{\alpha}$ excision of homology for

\begin{align*} (U_{\alpha}, K \setminus (X \setminus U_{\alpha})) \hookrightarrow (X,K) \end{align*}

implies

\begin{align*} H_k(X, X \setminus K;R) \cong& H_k(U_{\alpha}, X \setminus K;R) \\ \cong& H_k( \mathbb{R}^n, \mathbb{R}^n \setminus \varphi_{\alpha}(K);R) \end{align*}

therefore using relative homology for a euclidean space with higher dimension this evaluates as zero object

induction step

Let $A = \bigcup_{i=1}^r K_i$, then it remains to show this for $A \cup K_{r+1}$.

Note that $A \cap K_{r+1}$ is contained in a single chart. Then mayer vietoris for singular homology results in the long exact sequence 

\begin{displaymath}
\begin{tikzcd}
0 \arrow[]{d}{\cong} & & 0 \arrow[]{d}{\cong} \\
H_{k+1}(X, X \setminus (A \cap K_{r+1};R) \arrow[]{r}{\partial} & H_k(X, X \setminus (A \cup K_{r+1});R) \arrow[]{r}{} & H_k(X, X \setminus A;R) \oplus H_k(X, X \setminus K_{r+1};R) \arrow[]{r}{\nabla} 
\end{tikzcd}
\end{displaymath}

here the vertical isomorphisms are given by assumpition

thus we are done by exactly sandwhiched by isomorphisms and zero object
