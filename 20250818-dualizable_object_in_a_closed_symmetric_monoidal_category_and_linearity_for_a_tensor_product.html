dualizable object in a closed symmetric monoidal category and linearity for a tensor product

Proposition

Let $\mathcal{C}, \otimes, \mathbbm{1}$ be a closed symmetric monoidal category and $A$ a dualizable object. Then there exists a natural equivalence

\begin{align*} \underline{\mathrm{map}}(A,- \otimes -) \simeq \underline{\mathrm{map}}(A,-) \otimes - \end{align*}

Proof

note that by tensoring with left dualizable object induces left adjoint we get an adjunction

\begin{align*} - \otimes A \dashv \underline{\mathrm{map}}(A,1) \otimes - \end{align*}

(cf. dualizable object in a closed symmetric monoidal category as inner hom )

But

\begin{align*} - \otimes A \dashv \underline{\mathrm{map}}(A,-) \end{align*}

so by right adjoint unique up to contractible choice we get a natural equivalence:

\begin{align*} \underline{\mathrm{map}}(A,-) \simeq \underline{\mathrm{map}}(A,1) \otimes - \end{align*}

Now fix (for notation) some $X,Y$, then we get (using associativity)

\begin{align*} \underline{\mathrm{map}}(A,X \otimes Y) \simeq& \underline{\mathrm{map}}(A,1) \otimes (X \otimes Y) \\ \simeq& \underline{\mathrm{map}}(A,X) \otimes Y \end{align*}

which shows the claim

should be natural ?
