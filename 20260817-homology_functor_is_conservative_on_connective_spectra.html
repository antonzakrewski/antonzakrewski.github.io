homology functor is conservative on connective spectra

Proposition

The homology functor

\begin{align*} H_*(-,\mathbb{Z}): \mathrm{Sp}_{\geq } \rightarrow \mathrm{Gr}(\mathrm{Ab}) \end{align*}

is a conservative functor when restricted to bounded below spectra

Proof

use that a map $f: X \rightarrow Y$ between spectra is an equivalence if and only if $\mathrm{cofib}(f)$ vanishes. Moreover, $\mathrm{cofib}(f)$ is also bounded below and hence $\mathrm{cofib}(f)$ vanishes if and only if $H_*(\mathrm{cofib}(f),\mathbb{Z})$ vanishes (cf. stable hurewicz theorem). But the long exact sequence of homology shows that $H_*(\mathrm{cofib}(f),\mathbb{Z})$ vanishes if and only if $H_*(f, \mathbb{Z})$ is an isomorphism (cf. 5-Lemma for quasi isomorphisms or so).
