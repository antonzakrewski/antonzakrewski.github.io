kernel model structure on ChA - better name

Definition / Proposition

Let $\mathcal{A}$ be an abelian category and $\mathrm{Ch_*}(\mathcal{A})$ be the category of chain complexes Then the cokernel model structure is defined by

  1. quasi-isomorphisms as weak equivalence
  2. chain maps which are monomorphisms in each positive (!) degree as cofibration
  3. kernel injective fibrations as fibration
