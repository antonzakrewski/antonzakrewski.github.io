Proposition

Let \(R\) be a ring and $\mathrm{RMod}$ the category RMod and $\mathfrak{m}$ a maximal ideal. Then there exists a functor

\begin{align*} \mathfrak{m}: \mathrm{RMod} \rightarrow& R/\mathfrak{m}-\mathrm{Vec} \\d N \mapsto& N/\mathfrak{m}N \\ (f: N_1 \rightarrow N_2) \mapsto& (f/\mathfrak{m}: N_1/\mathfrak{m}N_1 \rightarrow N_2/\mathfrak{m}N_2) \end{align*}

where $N/\mathfrak{m}N$ is the quotient module with respect to the module ideal $\mathfrak{m}N$

Proof

Note that $N/\mathfrak{m}N$ is naturally equipped with an abelian group structure.

Let $r + \mathfrak{m} \in R/\mathfrak{m}$ and $n + \mathfrak{m}N \in N/\mathfrak{m}N$ Then define

Note that distributivity and linearity is inherited, if this is welldefined

welldefined

This is welldefined: Let $r + m = r', n + m' \cdot \tilde{n} = n'$ for $r,r' \in R, n,n', \tilde{n} \in N$. Then it follows that

\begin{align*} ((r + m) + \mathfrak{m}) ((n + m' \tilde{n}) + \mathfrak{m}N) =& (r + m) (n + m' \tilde{n}) + \mathfrak{m}N \\ =& rn + mn + r m' \tilde{n} + \mathfrak{m}N \\ =& rn + (mn + r m' \tilde{n}) + \mathfrak{m}N \end{align*}

since $(mn + r m' \tilde{n}) \in \mathfrak{m}N$ we conclude that

\begin{align*} rn + (mn + r m' \tilde{n}) + \mathfrak{m}N =& rn + \mathfrak{m}N \end{align*}
