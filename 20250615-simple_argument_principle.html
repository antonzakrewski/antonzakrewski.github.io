simple argument principle

Proposition

Let $f: U \rightarrow \mathbb{C}$ be a meromorphic function with at most finitely many poles and $D \subseteq U$ a closed disk. Assume that $f$ has no poles and zeros on $C = \partial D$

Then

\begin{align*} \frac{1}{2\pi \mathrm{i}} \int_{C} \frac{f'(z)}{f(z)} \mathrm{d}z = # \text{ of zeros inside } C - #\text{ of poles inside C} \end{align*}

where both sides are counted with multiplicities

Proof

Note that $\frac{f'(z)}{f(z)}$ is also holomorphic on $\mathrm{dom}(f) \setminus f^{-1}[0]$ by quotient of holomorphic functions as holomorphic function.

Now let $z_0$ be a pole resp. zero. Then

\begin{align*} f(z) = (z - z_0)^{\pm n} g(z) \end{align*}

for some locally defined, holomorphic $g(z)$.

Using the <product rule> we get

\begin{align*} f'(z) = \pm n(z - z_0)^{\pm n - 1} g(z) + (z - z_0)^{\pm n} g'(z) \end{align*}

so

\begin{align*} \frac{f'(z)}{f(z)} = \pm \frac{n}{z - z_0} + \frac{g'(z)}{g(z)} \end{align*}

so the residue is given by $\pm n$

Hence apply the residue formula
