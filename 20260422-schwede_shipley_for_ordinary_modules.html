schwede-shipley for ordinary modules

Proposition

Let $\mathcal{A}$ be an abelian category. Suppose $\mathcal{C}$ is presentable, there exists a compact projective object $C$ in $\mathcal{C}$ which generates $\mathcal{C}$ in the following sense: if $D$ in $\mathcal{C}$ is an object such that $\mathrm{map}_{\mathcal{C}}(C,D)$ is the zero spectrum, then $D$ is the zero object in $\mathcal{C}$.

Then $\mathcal{A} \simeq \mathrm{Mod}(\mathrm{End}(C))$ is an equivalence
