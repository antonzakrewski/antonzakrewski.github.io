factorial as alternating sum of binomials

Proposition

Let $n \in \mathbb{N}$. Then

\begin{align*} n! =& \sum_{k=1}^n (-1)^{n-k} \binom{n}{k} k^n \end{align*}

Proof

using the inverse inclusion-exclusion principle: Then

\begin{align*} \vert \bigcap_{i=1}^n A_i \vert =& \sum_{k=1}^n (-1)^{n-k} \binom{n}{k} \vert \bigcap_{j =1}^k A_{i_j} \vert \end{align*}

where we define

\begin{align*} A_i = \{(x_1,...,x_n) \in [n]^n \vert \exists j : x_j = i\} \end{align*}

Then we get

  1. $\bigcap_{i =1}^n A_i \simeq \mathrm{Aut}([n])$
  2. $\vert \bigcap_{i=1}^n A_i \vert = n!$
  3. $\vert A_i \vert = \vert [n]^n \setminus [n-1]^n \vert = n^n - (n-1)^n$
  4. $\vert \bigcap_{i=1}^k A_i \vert = \vert [n]^n \setminus [n-k]^n \vert = n^n - (n-k)^n$
  5. $\vert \bigcup_{i=1}^n A_i \vert = n^n$

so we may apply inclusion / exclusion
