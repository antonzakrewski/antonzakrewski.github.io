bounded below module descends along a pi_0 isomorphism

Proposition

Let $S,R$ be connective $\mathbb{E}_{\infty}$-ring spectra and $\varphi: S \rightarrow R$ a map of ring spectra, which is an isomorphism on $\pi_0(-)$. Let $M$ be a bounded below \(S\)-module spectrum, then $M$ descends along $\varphi$.

Proof
