separable hilbert space and countable orthonormal basis

Proposition

Let $X \neq 0$ be Hilbert space. TFAE:

  1. $X$ admits a countable Orthonormalbasis
  2. $X$ is separable

Proof

1) $\implies$ 2)

normed space with schauder basis is separable

2) $\implies$ 1)

Let $D = \{x_n\}$ be a dense in $X$. We then construct a orthonormal basis using the Gram-Schmidtsches Orthogonalisierungsverfahren. We define inductively $\{e_n\}$

  1. choose an $x_l \in D$ with $x_l \not\in \mathrm{span}(e_1,...,e_m)$ and $l$ minimal.
  2. using gram-schmidt to extend this to an ortonormal set $e_1,...,e_{m+1}$

and continuing this process (which only terminates if $\mathrm{dim}(X) < \infty$.

We claim that $e_n$ is an orthonormal set (see: gram schmidt) and $\mathrm{span}( \{e_n \vert n \in \mathbb{N}\})$ is dense in $x$.

For this it suffices to observe that each $x_n$ lies in $\mathrm{span}(e_1,...,e_m)$ for some $m$ (e.g. $m = n$).

It remains to show that $\{e_n\}^{\bot} = \{0\}$. For this it suffices to use orthogonal complement of the closure of the generated subspace.
