some p-local homotopy groups of a sphere

Proposition

Let $n \geq 3$, then

\begin{align*} \pi_k(S^n)_{(p)} \cong& \begin{cases} \mathbb{Z}_{(p)} & \mbox{if } k = n, k=2n-1, n \textrm{ even} \\ \mathbb{F}_p & \mbox{if } k = 2p - 3 + n \\ 0 & \mbox{if } k <2p - 3 + n, k \neq n \\ \end{cases} \end{align*}

Proof

$n$ odd

consider the fiber sequence

\begin{align*} \mathrm{fib} \rightarrow S^n_{(p)} \rightarrow K(\mathbb{Z}_{(p)},n) \end{align*}

where the second map is a generator of $H^n(S^k_{(p)}, \mathbb{Z}_{(p)})$

Now using the long exact sequence of homotopy groups we want to show that $\mathrm{fib}$ is $2p- 3 + n-1$ n-connected anima and $\pi_{2p-3+n}(\mathrm{fib}) \cong \mathbb{F}_p$. By relative Hurewicz theorem this amounts to

\begin{align*} \tilde{H}_*(\mathrm{fib}, \mathbb{Z}_{(p)} \begin{cases} 0 & \mbox{if } * < 2p - 3 + n \\ \mathbb{F}_p & \mbox{if } * = 2p - 3 + n \\ \end{cases} \end{align*}

Now using universal coefficient Theorem for cohomology / ucthomology

\begin{align*} H_{2p-2+n}(K(\mathbb{Z}_{(p)}, \mathbb{Z}_{(p)}) \cong \mathbb{F}_p \end{align*}

$n$ even
