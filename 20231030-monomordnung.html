monomial order

Definition

Sei $R$ ein kommutativer ring, $R[X_1,...,X_n]$ der Polynomring. Dann ist eine Monomordnung auf $R[X_1,...,X_n]$ eine Wohlordnung auf $\mathbb{N}_{0}^{n}$, so dass für $\alpha, \beta, \gamma \in \mathbb{N}_{0}^n$ gilt

\begin{align*} \alpha > \beta \Rightarrow \alpha + \gamma > \beta + \gamma \end{align*}
