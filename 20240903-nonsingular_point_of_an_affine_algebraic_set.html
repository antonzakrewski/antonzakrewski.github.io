nonsingular point of an affine algebraic set

Definition

Let $X \subseteq \mathbb{A}_K^n$ be an algebraic set and $P \in X$. Then $P$ is nonsingular, if $P$ lies in only one irreducible component $X_i$ with

\begin{align*} \mathrm{dim}_k(T_p(X_i)) = \mathrm{dim} X_i \end{align*}
