mapping spectrum out of a compact object in a stable infinity category preserves colimits

Proposition

Let $\mathcal{C}$ be a cocomplete stable infinity category and $x \in \mathcal{C}$ an object TFAE:

  1. $x$ is a compact object
  2. $\mathrm{map}_{\mathcal{C}}(x,-)$ preserves colimits

Proof

1) $\implies$ 2)

Let $x$ be compact.

we need to show that $\mathrm{map}_{\mathcal{C}}(x,-): \mathcal{C} \rightarrow \mathrm{Sp}$ preserves filtered and finite colimits. It preserves finite colimits since $\mathrm{map}_{\mathcal{C}}(x,-)$ is an exact functor (cf. left / right and exact functor between stable infinity categories, mapping spectrum functor is exact in both variables).

So we need to show that it preserves filtered colimits, i.e., for any filtered diagram $I \rightarrow \mathcal{C}$, the canonical map $\mathrm{colim} \mathrm{map}_{\mathcal{C}}(x,c_i) \rightarrow \mathrm{map}_{\mathcal{C}}(x,\mathrm{colim} c_i)$ is an equivalence. Using whitehead it suffices to show that $\pi_n(\mathrm{colim} \mathrm{map}_{\mathcal{C}}(x,c_i)) \rightarrow \pi_n(\mathrm{map}_{\mathcal{C}}(x,\mathrm{colim} c_i))$ is an equivalence for $n \in \mathbb{Z}$. we know that we can detect the connective part on the underlying anima, so this map is in particular an equivalence for $n \in \mathbb{N}_0$.
