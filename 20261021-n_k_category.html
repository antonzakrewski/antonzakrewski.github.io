(n,m)-category

Idea

An $(\infty,0)$ category is an anima An $(n,0)$ category is an n-truncated anima An $(n,m)$ category is ought to be a category suitably enriched in $(n-1,m-1)$ categories

An $(\infty,\infty)$ category ought to be the limit of $(\infty,n)$ categories.

This defines a6 $(n,m)$ category for $-2 \leq n \leq \infty$ and $k \leq n + 2$.

Example

  • $(0,0)-cat$ is sets
  • $(0,1)$ categories are posets (categories enriched in truth values)
  • $(1,2)$ categories are categories enriched in posets

Remark

The classical convention says that an $n$ category is an $(n,n)$ category including $n = \infty$. The modern convention says that an $n$ category is an $(\infty,n)$ category and a category is an $(\infty,1)$ category. Luries convention says that an $\infty$ category is an $(\infty,1)$ category.
