nonsingular point of a quasi-projective algebraic set

Definition

Let $K$ be a field, $\mathbb{P}_{K}^n$ the projective space and $X \subseteq \mathbb{P}_{K}^n$ a quasi-projective algebraic set. Then a point $P \in X$ is said to be nonsingular if

  1. it lies in exactly one irreducible component $X_i$
  2. $\mathrm{dim} T_p(X_i) = \mathrm{dim}(X_i)$
