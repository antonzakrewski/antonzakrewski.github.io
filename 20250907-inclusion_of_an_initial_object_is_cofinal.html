Proposition

Let $\mathcal{C}, \mathcal{D}$ be categories and $\mathcal{F}: \mathcal{C} \rightarrow \mathcal{D}$ an fully faithful functor where $\mathcal{D}$ contains an initial object which already lies in $\mathcal{C}$. Then the functor $\mathcal{F}$ is cofinal
