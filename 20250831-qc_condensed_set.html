qc condensed set

Definition

Let $X$ be a condensed set. Then $X$ is said to be quasicompact if for any collection $\{X_i \rightarrow X\}_{i \in I}$ such that $\coprod_{i} X_i \rightarrow X$ is surjective, there exists a finite subset $J \subseteq I$ such that $\coprod_{j =1}^n X_j \rightarrow X$ is also surjective.
