f2 homology group of a lens space

Proposition

Proof

using the universal coefficient formula for singular homology and homology of a 3 dimensional lens space results in

\[H^n(L(p,2), \mathbb{F}_2) = \begin{cases} \mathbb{F}_2 & \mbox{if } n = 0 \\ 0 & \mbox{if } n =1 \\ \mathbb{F}_2 & \mbox{if } n = 2 \\ \mathbb{F}_2 & \mbox{if } n =3 \\ 0 & \mbox{else } \\ \end{cases} \\ H^n(L(p,p), \mathbb{F}_2) = \begin{cases} \mathbb{F}_2 & \mbox{if } n = 0 \\ 0 & \mbox{if } n =1 \\ 0 & \mbox{if } n =2 \\ \mathbb{F}_2 & \mbox{if } n = 3 \\ 0 & \mbox{else } \\ \end{cases}\]
