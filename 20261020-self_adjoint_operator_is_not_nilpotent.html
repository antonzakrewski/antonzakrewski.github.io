nonzero self-adjoint operator is not nilpotent

Proposition

Any nonzero self-adjoint operator $T: \mathcal{H} \rightarrow \mathcal{H}$ is not nilpotent.

Proof

observe that $H^n$ is still self-adjoint for any $n$. So let $n$ be such that $(H^n)^2 = 0$ but $H^n \neq 0$. Then the star-identity implies

\begin{align*} 0 =& \| (H^n)^2 \| \\ =& \| H^n \|^2 >& 0 \end{align*}

which is a contradiction
