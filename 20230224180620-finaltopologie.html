final topology

Definition

Let $X$ be a set and $(X_i, \mathcal{T}_i)$ a family (or even a class) of topological spaces with set-theoretic maps $f_i: X_i \rightarrow X$ Then the final topology $\mathcal{T}_F$ on $X$ is defined by following universal property: Given a topological space $(Y, \mathcal{T}_Y)$ and a set theoretic map $g: X \rightarrow Y$, $g$ is continuous if and only if $g \circ f_i: X_i \rightarrow Y$ is continuous for all $i \in I$
