square of an element in the first cohomology as zero element

Proposition

Let $X$ be a topological space, $x \in H^1(X, \mathbb{Z})$. Then the cup product is

\begin{align*} x^2 = 0 \end{align*}

Proof

Any set valued natural transformation

\begin{align*} H^1(-,\mathbb{Z}) \rightarrow H^n(-,A) \end{align*}

for $n \geq 2$ is zero, as it is given by $H^n(S^1, A)$
