Set of Relatives (Relation)

Definition

Let $X$ be a set and $R \subseteq X \times X$ a relation on $X$. Then for $a \in X$ or $A \subseteq X$ the set of relatives is $R[a], R[A]$ is defined as:

\begin{align*} R[A] :=& \{y \in X \vert \exists a \in A : aRy\} \\ R[a] :=& \{y \in X \vert aRy\} \end{align*}
