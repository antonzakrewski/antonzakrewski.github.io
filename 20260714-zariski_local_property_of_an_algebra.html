zariski local property of an algebra

Definition

Let $P$ be a property of the category Alg_R. Then $P$ is said to be local, if the following holds

  1. if an R-Algebra $S$ has the property and $f \in R$, then so does $R_{f}$.
  2. if $(f_1,...,f_n) = R$ and each $R_{f}$ has the property $P$, then so does $R$.
