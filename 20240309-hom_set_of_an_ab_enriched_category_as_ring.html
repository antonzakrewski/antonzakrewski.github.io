endomorphism set of an ab-enriched category as ring

Proposition

Let $\mathcal{A}$ be an Ab-enriched category, $X \in \mathcal{A}$, then

\begin{align*} \mathrm{Hom}_{\mathcal{A}}(X,X) = \mathrm{End}_{\mathcal{A}}(X) \end{align*}

is a ring with

  1. usual addition
  2. composition as multiplication
  3. $0$ as additive neutral element
  4. $\mathrm{id}_{X} = 1$ as multiplicative neutral element
