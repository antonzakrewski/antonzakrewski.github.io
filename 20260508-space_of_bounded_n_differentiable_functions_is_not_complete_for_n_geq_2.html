Proof

Let $I \subseteq \mathbb{R}^n$ be an intervall. Take a connected component, which is of the form $(a,b)$. w.l.o.g. - after scaling - we may assume that $(a,b) = (-1,1)$ Then consider the map

\begin{align*} g_m: I \rightarrow& \mathbb{R} \\ x \mapsto& \begin{cases} 0 & \mbox{if } x \not\in (-1,1) \\ \sqrt{x^2 + \frac{1}{m}} & \mbox{else } \\ \end{cases} \end{align*}

Then this converges pointwise to $\sqrt{x^2} = \vert x \vert$ on $(-1,1)$, where we use that $\lim$ commutes with continuous functions.

We claim that $g_m$ is also a smooth function where the \(i\)-th derivative is bounded for each $i \in \mathbb{N}$: Observe that $g_m$ is the constant zero map outside of $(-1,1)$, so in particular smooth with zero differential. So it suffices to show that $g_m$ is smooth with bounded derivative when restricted to $(-1,1)$.

Here it is smooth as $\sqrt{-}: \mathbb{R} \setminus \{0\} \rightarrow \mathbb{R}$ is smooth and $x^2 + \frac{1}{m}$ is also smooth, where $0$ does not lie in the image of $x^2 + \frac{1}{m}$. Moreover, we can smoothly extend the function $\sqrt{x^2 + \frac{1}{m}}: (-1,1) \rightarrow \mathbb{R}$ to

\begin{align*} \sqrt{x^2 + \frac{1}{m}}: \mathbb{R} \rightarrow& \mathbb{R} \\ x \mapsto& \sqrt{x^2 + \frac{1}{m}} \end{align*}

so in particular, the \(i\)-th derivative can be restricted to a function

\begin{align*} (g_m)^{(i)}: [-1,1] \rightarrow \mathbb{R} \end{align*}

now $[-1,1]$ is compact, so $g_m^{(i)}$ is bounded.

Hence $g_m$ lies in $C_b^n$.

Moreover, it is cauchy, as we can estimate

\begin{align*} \sqrt{x^2} \leq \sqrt{x^2 + \frac{1}{m}} \leq \sqrt{x^2} + \frac{1}{m} \end{align*}

so in particular (again, we don't need to consider $I \setminus (-1,1)$ for stupid reasons),

\begin{align*} \| g_m - g_{m'} \|_{\infty} \leq \frac{1}{m} \end{align*}

which is cauchy.

but we claim that $g_m$ does not converge to an element in $C_b^n$: Recall that

\begin{align*} \mathrm{ev}_{x}: C_b^n \rightarrow& \mathbb{R} \\ f \mapsto& f(x) \end{align*}

is \(1\)-lipschitz with respect to $\| - \|_{\infty}$, so in particular continuous. Hence any convergent sequence $g_m$ would have to converge to it's pointwise limit.

But the pointwise limit is - by the estimate $\sqrt{x^2} \leq \sqrt{x^2 + \frac{1}{m}} \leq \sqrt{x^2} + \frac{1}{m}$ - given - when restricted to $(-1,1)$ - by $\sqrt{x^2} = \mathrm{abs}(x)$, which is not differentiable at $x = 0$.
