complete orthonormal set is an orthonormal basis

Proposition

Let $A \subseteq V$ be an orthonormal set of a prehilbert space. TFAE:

  1. $A$ is a basis.
  2. $A$ is a complete set, i.e., for all $v \in V$, if $\langle a,v\rangle = 0$ for all $a \in A$, then $v = 0$.

Proof

1) $\implies$ 2)

Let $x = \sum_{i=1}^n \alpha_i a_i$. Then $\langle a_i, x\rangle = \alpha_i$ and hence $\langle a_i,x\rangle$ is zero for all $a_i \in A$ if and only if $\alpha_i = 0$ for all $i$. Hence $x = 0$.

2) $\implies$ 1)

using Äquivalenz von Basis, minimales Erzeugendensystem und maximal linear unabhängige Teilmenge it suffices to show that $A$ is maximally linearly independent. So assume that $A \cup \{x\}$ is linearly independent, then by Gram-Schmidtsches we may w.l.o.g. assume that $A \cup \{x\}$ is orthonormal. But this shows $\langle a,x\rangle = 1$, contradiction to our assumption
