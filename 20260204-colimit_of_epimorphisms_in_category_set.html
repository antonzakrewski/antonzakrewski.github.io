filtered colimit of epimorphisms in category set

Proposition

Let $\mathcal{I} \rightarrow \mathrm{Set}$ be a filtered diagram in category set and $\mathrm{colim} \mathcal{I}$ its colimit Suppose each morphism of the diagram is an epimorphism, then each coprojection $\mathcal{I}(i) \rightarrow \mathrm{colim}(\mathcal{I})$ is also an epimorphism.

Proof

use the explicit description of colimits in category set: Let $x \in \mathrm{colim} \mathcal{I}$ be an element and $\mathcal{I}(i)$ be an object. Then $x$ is represented by some $\mathcal{I}(i')$, so choose a common upper bound $\mathcal{I}(i'')$ and take a preimage of the image $\overline{x} \in \mathcal{I}(i'')$ in $\mathcal{I}(i)$.

This maps to $x \in \mathrm{colim} \mathcal{I}$
