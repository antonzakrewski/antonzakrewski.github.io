S-local module spectrum

Definition

Let $R$ be an \(\mathbb{E}_1\)-ring spectrum, $S \subesteq \pi_*(R)$ be a homogeneous subset. Then a module spectrum $M$ is said to be \(S\)-local if for every element $s \in S, s \in \pi_n(R)$ the map

is an isomorphism

i.e. multiplication with $s$ is an iso on the underlying graded ring
