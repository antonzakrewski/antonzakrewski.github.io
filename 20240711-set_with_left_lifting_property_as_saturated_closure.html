saturated closure of a set of morphisms of simplicial sets with compact domain

Proposition

Let $\mathrm{sSet}$ be the category sSet, $S = \{A_i \rightarrow B_i\} \subseteq \mathrm{Mor}(\mathcal{C})$ a subset where each $A_i$ is a compact simplicial set, $\chi_R(S)$ the set with right lifting property against $S$. Then the set

\begin{align*} \overline{S} = \chi_{L}(\chi_R(S)) \end{align*}

is the saturated closure of $S$
