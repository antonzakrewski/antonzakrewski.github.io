projective space is not an affine scheme

Proposition

Let $S = \mathrm{Spec}(A)$ Then the projective space $\mathbb{P}^n$ is not an affine scheme

Proof

The terminal morphism $\mathbb{P}^n \rightarrow \mathrm{Spec}(A)$ would induce an A-Algebra map $\Gamma(\mathbb{P}^n) \rightarrow \Gamma(\mathrm{Spec}(A)) \cong A$. AS $\mathrm{Spec}(A)$ is an initial object, this would have to be an isomorphism, since $\mathrm{End}_{A}(A) = \mathrm{id}$.

If $\mathbb{P}^n$ were affine, then it would be isomorphic to $\mathrm{Spec}(A)$. But these spaces differ, e.g. by looking at topological spaces we can conclude that $\mathbb{P}^n$ contains an $\mathbb{A}^n$ as open subscheme / open subset
