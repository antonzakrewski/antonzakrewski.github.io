torsion-freeness is a zariski local property

Proposition

Being a torsion-free module is a zariski-local property of modules.

Proof

Observe that a module $M$ is torsion free if and only if the map

\begin{align*} M \xrightarrow{\cdot r} M \end{align*}

is an injection for all non-zero divisors $r$.

hence this follows from injectivity of a map is a zariski local property_
