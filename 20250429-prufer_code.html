prüfer code

Definition

Let $G = (V,E)$ be a tree with $V = \{1,...,n\}$ Then the prüfer code is inductively defined as

  1. for $\vert V \vert \leq 2$ define $\mathrm{PC}(G) = ()$ as empty list.
  2. for $\vert V \vert \geq 3$ choose the leaf $l$ with smallest index and denote its unique neighbour $k$.

Then set

\begin{align*} \mathrm{PC}(G) = (k, \mathrm{PC}(G \setminus \{k\})) \end{align*}
