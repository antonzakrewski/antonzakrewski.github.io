Ring Object

Definition

Let $\mathcal{C}$ be a cartesian monoidal category. Then an object $R \in \mathrm{Ob}(\mathcal{C})$ is said to be a ring object, if there exist morphisms

  1. $a: R \times R \rightarrow R$ (addition)
  2. $m: R \times R \rightarrow R$ (multiplication)
  3. $0: 1 \rightarrow R$ (zero)
  4. $1: 1 \rightarrow R$ (multiplicative identity)
  5. $-: R \rightarrow R$ (additive inversion)
