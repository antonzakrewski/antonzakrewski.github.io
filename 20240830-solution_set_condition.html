initial solution set condition

Definition

Let $\mathcal{C}$ be a category. Then $\mathcal{C}$ is said to admit a solution set condition, if there exists a set $I$ and an \(I\) indexed family of objects $k_i \in \mathrm{Ob}(\mathcal{C})$, such that for each object $d \in \mathrm{Ob}(\mathcal{C})$ there exists any morphism

\begin{align*} k_i \rightarrow d \end{align*}
