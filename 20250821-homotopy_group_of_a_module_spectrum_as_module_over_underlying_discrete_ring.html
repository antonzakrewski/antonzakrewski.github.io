homotopy group of a module spectrum as module over underlying discrete ring

Proposition

Let $M$ be a module spectrum over a ring spectrum $R$. Then each homotopy group $\pi_n(M)$ is a module over the underlying discrete ring $\pi_0(R)$

Proof

follows as:

  • underlying graded module functor from module spectra
  • graded Module as R_0-module
  • component of a graded module as R_0-module
