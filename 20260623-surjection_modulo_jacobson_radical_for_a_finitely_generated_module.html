surjection modulo jacobson radical for a finitely generated module

Proposition

Let $f: M \rightarrow N$ be a module-homomorphism between \(A\)-modules, $\mathfrak{a} \subseteq \mathrm{Jac}(A)$ an ideal contained in the Jacobson radical. Suppose that $N$ is finitely generated and that $f \otimes_{A} A/\mathfrak{a}$ is surjective.

Then so is $f$.

Proof

Recall that a module homomorphism is surjective if and only if the cokernel $\mathrm{coker}(f)$ vanishes. Observe that $\mathrm{coker}(f)$ is also finitely generated, as it is the quotient of a finitely generated module. Using the counit of the tensor hom adjunction gives a commutative diagram

Now $- \otimes_{A} A/\mathfrak{a}$ is right exact, hence we may identify $\mathrm{coker}(f) \otimes_A A/\mathfrak{a} \cong \mathrm{coker}(f \otimes_{A} A/\mathfrak{a})$, where the latter vanishes as $f \otimes_{A} A/\mathfrak{a}$ is surjective by assumpiton.

This shows that $\mathfrak{a} \mathrm{coker}(f) \coloneqq \mathrm{coker}(f) \otimes_{A} \mathfrak{a} \rightarrow \mathrm{coker}(f)$ is surjective or equivalently $\mathfrak{a} \mathrm{coker}(f) = \mathrm{coker}(f)$. Hence Nakayama Lemma for Jacobson Radical shows that $\mathrm{coker}(f) = 0$ as $\mathrm{coker}(f)$ is finitely generated as quotient $N$. This shows that $f$ is surjective.
