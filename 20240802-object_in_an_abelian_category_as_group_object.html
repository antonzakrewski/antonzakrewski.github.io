object in an abelian category as group object

Proposition

Let $\mathcal{A}$ be an additive category, $A \in \mathrm{Ob}(\mathcal{A})$ Then $A$ is a group object with respect to

  1. the zero morphism as unit
  2. the codiagonal morphism as composition
