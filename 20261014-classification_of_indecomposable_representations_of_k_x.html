classification of finitely generated $k[t]$

Suppose $V$ is a finite dimensional $k[t]$ representation, so in paritcular also a finitely generated module Then the classification of finitely generated modules over a pid implies that $V$ is isomorphic to $\bigoplus k[t]/(f_i^r) \oplus k[t]^n$ where each $f_i$ is an irreducible element. If $V$ is finite dimensional, then it contains no summmand of the form $k[t]$.

But if $k$ is a algebraically closed, then $f_i$ is of the form $(x - \lambda_i)$. If it is indecomposable, then it contains only one summand, i.e. is of the form $k[t]/(x - \lambda_i)^r$, which corresponds to a jordan block with diagonal $\lambda_i$ and of size $r$.
