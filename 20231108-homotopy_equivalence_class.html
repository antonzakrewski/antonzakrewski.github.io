homotopy equivalence class

Definition

Let $(X,\mathcal{T}_X)$ and $(Y,\mathcal{T}_Y)$ be topological spaces, $A \subseteq X$ and $\varphi: A \rightarrow X$ a continuous map. Then the equivalence class $[X,Y]_{\varphi}$ of homotopic continuous maps relative to $\varphi$ is named the homotopy equivalence class relative to $\varphi$
