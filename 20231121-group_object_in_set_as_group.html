Proposition

Let $\mathcal{Set}$ be category set, then there is a 1-1 correspondence between groups and group object

Proof

monoid object in Set as monoid

group as group object

the canonical inverse map is

\begin{align*} ()^{-1}: G \rightarrow& G \\ g \mapsto& g^{-1} \end{align*}

group object as group

for $g \in G$, let $g^{-1}$ be

\begin{align*} \mathrm{inv}(g) \end{align*}

Then

\begin{align*} g \cdot \mathrm{inv}(g) =& 1 \\ \mathrm{inv}(g) \cdot g =& 1 \\ \end{align*}
