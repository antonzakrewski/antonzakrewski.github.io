I-nilpotent element in a module

Definition

Let $R$ be a commutative ring, $I \subseteq R$ an ideal and $M$ an \(R\)-module. Then an element $m \in M$ is called \(I\)-nilpotent, if for every $f \in I$, there exists an $n \in \mathbb{N}$ such that $f^n m = 0$.

Remark

this only depends on the radical ideal.
