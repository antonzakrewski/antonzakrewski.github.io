exact functor reflecting zero object and conservative

Proposition

Let $\mathcal{C}, \mathcal{C}'$ be stable categories and $\mathcal{F}: \mathcal{C} \rightarrow \mathcal{C}'$ an exact functor. TFAE:

  1. $\mathcal{F}$ detects the zero object
  2. $\mathcal{F}$ is a conservative functor

Proof

1) $\implies$ 2)

Let $f: c \rightarrow c'$ be a map and $\mathrm{fib}$ be the fiber. Then it suffices to show, that $\mathrm{fib} \simeq 0$ if $\mathcal{F}(f)$ is an equivalence (cf. equivalence and trivial fiber/cofiber sequence in a stable category). But $\mathcal{F}$ is exact, so $\mathcal{F}(\mathrm{fib}) \rightarrow \mathcal{F}(c) \xrightarrow{\simeq} \mathcal{F}(c')$ is a fiber sequence and hence $\mathcal{F}(\mathrm{fib}) \simeq 0$ which shows $\mathrm{fib} \simeq 0$.

2) $\implies$ 1)

conservative, reduced functor detects the terminal object.
