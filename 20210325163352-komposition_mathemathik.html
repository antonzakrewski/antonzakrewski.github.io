Komposition (Q11)

Definition

Der Begriff Komposition beschreibt die Verkettung von mehreren Funktionen

\begin{align*} f \circ g: x \mapsto h(x) = f(g(x)) \end{align*}

Definitionslücken

  • Definitionslücken von $g(x)$
  • $W_g \cup \mathbb{D}_f$
  • für jedes Element -> $g^{-1}(x)$ -> vereinigt mit \mathbb{R}\setminus\mathbb{D_f}
