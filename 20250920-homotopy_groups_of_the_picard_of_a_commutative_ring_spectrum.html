homotopy groups of the picard groupoid of a commutative ring spectrum

Proposition

Let $E$ be a $\mathbb{E}_{\infty}$-ring spectrum. Then the homotopy groups of picard groupoid are given by

\begin{align*} \pi_n(\mathrm{Pic}(E)) = \begin{cases} \pi_0(E)^{\times} & \mbox{if } n = 1 \\ \pi_{n-1}(E) & \mbox{if } n \geq 2 \\ \end{cases} \end{align*}

Proof

Note that using the explicit description of a picard groupoid we are interested in

\begin{align*} \pi_{n+1}(\mathrm{Pic}(E)) \simeq& \pi_{n}(\coprod_{\mathrm{inv.\, ob}} \mathrm{BAut}(E)) \end{align*}

where $\pi_1(\mathrm{BAut}(E)) = \pi_1(\mathrm{map}_{E}(E,E))^{\times}$ consists of those path components which are invertible under composition. using $\mathrm{map}_{E}(E,E) \simeq E$ (cf. internal mapping object out of unit object)
