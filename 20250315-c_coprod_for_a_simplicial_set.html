C^coprod for a simplicial set

Definition

Let $C$ be a simplicial set Then $C^{\coprod}$ is defined as as simplicial set with a morphism of simplicial sets

\begin{align*} C^{\coprod} \rightarrow N(\mathrm{Fin}_*) \end{align*}

with with the universal property, that for any simplicial set $K$ and a map

\begin{align*} K \rightarrow N(\mathrm{Fin}_*) \end{align*}

there exists a canonical bijection

\begin{align*} \mathrm{Hom}_{/\mathrm{N}(\mathrm{Fin}_*)}(K, C^{\coprod}) \cong \mathrm{Hom}_{\mathrm{sSet}}(K \times_{N(\mathrm{Fin}_*)} N(\Gamma^*)}, \mathcal{C}) \end{align*}

where

\begin{align*} K \times_{N(\mathrm{Fin}_*)} N(\Gamma^*) \end{align*}

is given by the pullback of $K \rightarrow N(\mathrm{Fin}_*)$ and the forgetful functor from Gamma* to Fin* $N(\Gamma^) \rightarrow N(\mathrm{Fin}_);q
