infinity groupoid core functor as right adjoint

Proposition

Given category sSet and the category of Kan complexes, the infinity groupoid core functor is a right adjoint to the inclusion.

Proof

using infinity-groupoid and Kan complex

It remains to show that for a Kan complex $K$ and a simplicial set $X$

\begin{align*} \mathrm{Hom}_{\mathrm{sSet}}(K, X) \cong \mathrm{Hom}_{\mathrm{Kan}}(K, X^{\cong}) \end{align*}

this follows from

  • equivalence in a simplicial set and morphism

where a morphism $\varphi: K \rightarrow X$ naturally always restricts to $\varphi: K \rightarrow X^{\cong}$
