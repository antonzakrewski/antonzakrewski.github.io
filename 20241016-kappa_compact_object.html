kappa compact object

Definition

Let $\kappa$ be a regular cardinal, $\mathcal{C}$ an infinity category Then $c \in \mathcal{C}_0$ is said to be compact, if the mapping space functor

\begin{align*} \mathrm{map}_{\mathcal{C}}(c,-) \end{align*}

preserves kappa filtered colimits

If $\kappa$ is not specified, then one assumes that $\kappa = \omega$
