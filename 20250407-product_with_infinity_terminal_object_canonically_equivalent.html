product with infinity terminal object canonically equivalent

Proposition

Let $\mathcal{C}$ be an infinity category, $1$ an terminal object and $X$ an object. Then for a set $I$

\begin{align*} (\prod_{i \in I} 1) \times X \simeq X \end{align*}

Proof

reduction to complete category

use the infinity yoneda embedding, which preserves limits in particular it suffices to show that

\begin{align*} \mathrm{map}_{\mathcal{C}}(-,x) \times \mathrm{map}_{\mathcal{C}}(-,1) \simeq \mathrm{map}_{\mathcal{C}}(-,x) \end{align*}

reduction to anima

using

  • pointwise calculation of limits it suffices to show that the canonical map
\begin{align*} \mathrm{map}_{\mathcal{C}}(-,x) \rightarrow \mathrm{map}_{\mathcal{C}}(-,x) \times \mathrm{map}_{\mathcal{C}}(-,1) \\ \simeq& \mathrm{map}_{\mathcal{C}}(y,x) \times \Delta^0 \\ \end{align*}

is an equivalence

anima

here we use that the product of anima is given as categorical product in category sSet where we may chose $\Delta^0$ as terminal object. Thus this follows from product with the terminal object canonically iso

alternatively

use right kan extension formula & associativity of kan extensions
