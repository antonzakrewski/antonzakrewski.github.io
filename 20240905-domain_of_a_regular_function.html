domain of a regular function between affine varieties

Definition

Let $K$ be an algebraically closed field, $\mathbb{A}_{K}^n$ the affine space and $X,Y \subseteq \mathbb{A}_{K}^n$ be affine varieties. Then for a regular function the domain is defined as

\begin{align*} \mathrm{def}(f) = \{P \in X \vert f \textrm{ is regular on } P\} \subseteq X \end{align*}
