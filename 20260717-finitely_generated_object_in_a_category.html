kappa finitely generated object in a category

Definition

Let $\kappa$ be a regular cardinal, $\mathcal{C}$ be a category and $x \in \mathcal{C}$ an object. Then $x$ is said to be a finitely generated object, if $\mathrm{Hom}_{\mathcal{C}}(x,-)$ preserves kappa filtered colimits where each transition morphism is a monomorphism
