holomorphic function with zero divided by zero as holomorphic function

Proposition

Let $f: \Omega \rightarrow \mathbb{C}$ be a holomorphic function for $\Omega \subseteq \mathbb{C}$ open. Suppose $f(z_0) = 0$, then

\begin{align*} \frac{f(z))}{z - z_0} \end{align*}

extends to a holomorphic function on $\Omega$

Proof

follows from:

  • removable singularity theorem
  • maximum modulus principle
