initial object in the comma category for a right adjoint

Proposition

Let $\mathcal{C}, \mathcal{D}$ be categories and $\mathcal{R}: \mathcal{C} \rightarrow \mathcal{D}$ a right adjoint $\mathcal{L} \dashv \mathcal{R}$ Then for the comma category $d/ \mathcal{R}$ the object

\begin{align*} d \rightarrow \mathcal{RL}(d) \end{align*}

given by the unit is an initial object
