LEM and natural numbers as well ordered set

Proposition

TFAE:

  1. Law of the excluded middle
  2. the natural numbers are well-ordered in the sense that inhabited sets contain a

Proof

1) $\implies$ 2)

2) $\implies$ 1)

Let $A$ be a proposition.

Consider

\begin{align*} S = \{1\} \cup \{n \vert n = 0 \land A\} \end{align*}

It is inhabited as $1 \in S$. Furthermore it contains by assumption a minimal element $x$.

Note that it is either $0$ or not $0$ (by induction) If it is $0$, then it follows that $0 \in \{n \vert n = 0 \land A\}$ showing that $A$ holds. Otherwise $0 \not\in \{n \vert n = 0 \land A\}$, as $0 \in \{n \vert n = 0 \land A\}$ would lead to a contradiction since $0 < x \neq 0$.

Similarly if $A$, then $0 \in \{n \vert n = 0 \land A\}$ leading to a contradiction
