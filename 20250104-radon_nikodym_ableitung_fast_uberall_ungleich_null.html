radon nikodym ableitung fast überall ungleich null für absolut stetiges Maß

Proposition

Sei $(X, \mathcal{A})$ ein Messraum, $\nu,\mu$ Maße mit $\mu << \nu$ Angenommen es existiert eine Dichtefunktion $\frac{\mathrm{d}\nu}{\mathrm{d} \mu}$.

Dann gilt

\begin{align*} \frac{\mathrm{d}\nu}{\mathrm{d} \mu} \neq 0 \end{align*}

\(\mu\)-fast überall

Proof

Sei $A = \{ \frac{\mathrm{d}\nu}{\mathrm{d} \mu} =0\}$. Dann gilt $\nu(A) = \int_{A} 0 \mathrm{d} \mu = 0$ und wegen Maß einer Dichtefunktion absolut stetig folgt dann

\begin{align*} \mu(A) = 0 \end{align*}
