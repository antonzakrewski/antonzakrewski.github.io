free object

Definition

Let $\mathcal{C}$ be a concrete category, $\mathrm{Free}: \mathrm{Set} \rightarrow \mathcal{C}$ be a free object functor. Then an object $X \in \mathrm{Ob}(\mathcal{C})$ is said to be free, if there exists a set $Y$ such that

\begin{align*} \mathrm{Free}(Y) = X \end{align*}
