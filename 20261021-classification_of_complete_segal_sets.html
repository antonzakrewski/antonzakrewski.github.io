classification of complete segal sets

Proposition

A complete segal anima which restricts to $\mathrm{Fun}(\Delta^{\mathrm{op}}, \mathrm{Set})$ is precisely an ordinary category without any non-identity isomorphism

Proof

observe that a segal set is equivalently an object in the (1,1)-category of (1,1)-categories. To be complete, it must satisfy that

\begin{align*} X_0 \rightarrow \mathrm{Iso}(X_1) \end{align*}

is a Bijection, so in particular surjective. This implies that any complete segal set is canonically a category without any non-identity isomorphism.

To see the converse, it suffices to see that this map is an epic split mono, hence an isomorphism (cf. epic split mono is an equivalence).
