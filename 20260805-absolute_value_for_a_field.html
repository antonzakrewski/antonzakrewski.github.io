absolute value on a field

Definition

Let $K$ be a field Then an absolute value is a group-homomorphism

\begin{align*} \vert - \vert: K^{\times} \rightarrow \mathbb{R}_{> 0} \end{align*}

satisfying the triangle inequality

\begin{align*} \vert x + y \vert \leq \vert x \vert + \vert y \vert \end{align*}

where we define $\vert 0 \vert = 0$
