hausdorff space with compact exhaustion with interior implies paracompactness

Proposition

Let $M$ be a hausdorff space which admits a compact exhaustion $K_n$ with the property that $K_n \subseteq \mathrm{int}(K_{n+1})$. Then $M$ is paracompact.

Proof

Let $U_i$ be any open cover for $i \in I$ w.l.o.g. assume that $K_0, K_1 = \emptyset$

Now define for $n \geq 2$

\begin{align*} V_{j,n} := U_j \cap \mathrm{int}(K_{n+1}) \cap (M \setminus K_{n-1}) \end{align*}

and then cover $K_n \setminus \mathrm{int}(K_{n-1})$ with finitely many $V_{j,n}, V_{j,n-1}$, where we use that $K_n \setminus \mathrm{int}(K_{n-1})$ is compact (cf. Closure of a Subset, closedness of compact sets in Hausdorff spaces, Komplement einer abgeschlossenen und offenen Menge, closed subset of a compact space is compact set). Then set $\mathcal{V} = \bigcup_{n \in \mathbb{N}} \bigcup_{i=1}^{l_n} V_{i,n}$.

We claim that $\mathcal{V}$ is a locally finite refinement of $U_j$

  1. by definition, each $V_{j,n}$ is a subset of some $U_j$, so in particular each element in $\mathcal{V}$ is a subset of some $U_j$
  2. Let $x \in M$, then there exists an $n \in \mathbb{N}$ with $x \in K_n \setminus \mathrm{int}(K_{n-1})$ since $\bigcup_{\mathbb{N}} \mathrm{int}(K_n) = M$ and $K_0 = \emptyset$, in particular $x \in K_n \setminus \mathrm{int}(K_{n-1}) \supseteq \mathrm{int}(K_{n+1}) \setminus \mathrm{int}(K_{n-1})$. Hence it is covered by some $V_{j,n}$, since the finite set $V_{j,n}$ covers $K_{n+1} \setminus \mathrm{int}(K_{n-1})$
  1. we claim that $V_{j,n}$ already intersects only finitely many elements in $\mathcal{V}$. Here each $V_{j,n} \subseteq K_{n+1} \setminus K_{n-1}$ so it can only intersect $V_{j',m}$ for $m \in \{n-1,n,n+1\}$. But the set of $V_{j',m} \in \mathcal{V}$ with fixed $m$ (or $m \in \{n-1,n,n+1\}$) is finite by construction, so it can only intersect finitely many.
