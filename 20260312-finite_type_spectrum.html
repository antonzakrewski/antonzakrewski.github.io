finite type spectrum

Definition

Let $X$ be a spectrum Then $X$ is said to be of finite type if

  1. $X$ is bounded below spectrum
  2. there exist spectra $X_n$ for $n > n_0$ and maps $X_n \rightarrow X_{n+1}$ such that
  3. $\mathrm{colim}_{n} X_n \simeq X$
  4. each $X_n$ participates in a pullback

where $i_n$ is in particular finite.
