essentially surjective functor

Definition

Let $\mathcal{C}, \mathcal{D}$ be categories and $F: \mathcal{C} \rightarrow \mathcal{D}$ be a functor. Then $F$ is said to be essentially surjective, if for any object $y \in \mathrm{Ob}(\mathcal{D})$ there exists an object $x \in \mathrm{Ob}(\mathcal{C})$ such that $F(x)$ is isomorphic to $y$ see: isomorphism class
