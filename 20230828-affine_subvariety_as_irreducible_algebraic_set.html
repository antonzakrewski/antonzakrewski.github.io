affine subvariety as irreducible algebraic set

Proposition

Let $K$ be a field and $\mathbb{A}_{K}^n$ the affine space and $A \subseteq \mathbb{A}_K^n$. TFAE:

  1. $A = V(\mathfrak{p})$ is an affine subvariety for a prime ideal $\mathfrak{p} \subseteq K[X_1,...,X_n]$
  2. $A$ is an irreducible algebraic set

Proof

corollary of: bijection between prime ideals and irreducible closed subsets
