idempotent completion is an epimorphism in Cat

Proposition

Let $\mathcal{F}: \mathcal{C} \rightarrow \mathcal{D}$ be a functor, such that $\mathcal{F}^{\sharp}$ is an equivalence Then $\mathcal{F}$ is an epimorphisms.

Proof

Observe that $\mathcal{C} \rightarrow \mathcal{D} \rightarrow \mathcal{D}^{\sharp}$ is an idempotent completion of $\mathcal{C}$, so by the cancellation property for epimorphisms it suffices to show that $\mathcal{D} \rightarrow \mathcal{D}^{\sharp}$ is an idempotent completion, as then both the $\mathcal{C} \rightarrow \mathcal{D}^{\sharp}$ and $\mathcal{D} \rightarrow \mathcal{D}^{\sharp}$ will be epimorphisms. let $\mathcal{E}$ be any category, then we need to show that $\mathrm{Hom}_{\mathrm{Cat}}(\mathcal{D}^{\sharp}, \mathcal{E}) \rightarrow \mathrm{Hom}_{\mathrm{Cat}}(\mathcal{D}, \mathcal{E})$ is a monomorphism in anima, i.e. an inclusion of path components. Now $\mathcal{E} \rightarrow \mathcal{E}^{\sharp}$ is fully faithful, hence a monomorphism (cf. monomorphisms in category Cat) and postcomposition with it remains a monomorphism.
