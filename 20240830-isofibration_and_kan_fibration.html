isofibration and kan fibration for the groupoid core

Proposition

Let $p: \mathcal{C} \rightarrow \mathcal{D}$ be an inner fibration between quasicategories

TFAE:

  1. $p: \mathcal{C} \rightarrow \mathcal{D}$ is an isofibration
  2. $p^{\simeq}: \mathcal{C}^{\simeq} \rightarrow \mathcal{D}^{\simeq}$ is a kan fibration, where $^{\simeq}$ is the infinity groupoid core functor

Proof

1) $\implies$ 2)

  • infinity subgroupoid functor sends isofibration to kan-fibration

2) $\implies$ 1)

Given a lifting problem

where $\Delta^1 \rightarrow \mathcal{D}$ represents an equivalence, this gives rise to the lifting problem

This can be solved, as $p^{\simeq}$ is a kan fibration, hence a lift exists.

This lift then also solves the original lifting problem.
