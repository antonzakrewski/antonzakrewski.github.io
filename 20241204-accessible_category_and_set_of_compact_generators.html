accessible category and set of compact generators

Proposition

Let $\kappa$ be a regular cardinal, $\mathcal{D}$ an kappa accessible infinity category

Then $\mathcal{D}$ has a set of kappa compact generators

Proof

using accessible category and Ind we may assume that $\mathcal{D} \cong \mathrm{Ind}_{\kappa}(\mathcal{C})$ for some small infinity category $\mathcal{C}$ Then the set of representables $\mathrm{map}_{\mathcal{C}}(c,-)$ form a compact set of generators:

  • representable functor as kappa compact object
  • representables as collection of generators
