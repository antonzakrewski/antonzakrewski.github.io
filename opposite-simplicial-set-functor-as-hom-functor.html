opposite simplicial set functor as hom functor

Proposition

The opposite simplicial set functor is given by

\begin{align*} (-)^(\mathrm{op}): \mathrm{sSet} \rightarrow& \mathrm{sSet} \\ \mathcal{C} \mapsto& \mathrm{Hom}_{\mathrm{sSet}}((\Delta^{(-)})^{\mathrm{op}}, -) \\ \end{align*}
