Definition / Proposition

Let $X$ be a topological space, $C_n(X)$ be the abelian group of singular n-simplices and $d_n$ the singular boundary map. Then

is a chain complex i.e.

is the zero morphism

Proof

It suffices to show it for an arbitrary generator of $C_n(X) = \mathbb{Z}[\mathrm{Hom}_{\mathrm{Top}}(\Delta_{\mathrm{Top}}^n,X)$: Let $(\sigma: \Delta^n \rightarrow X) \in C_n$.

Then

\begin{align*} d_{n} \circ d_{n+1}(\sigma) =& d_n \left(\sum_{i=0}^{n+1} (-1)^i \sigma \circ \delta_i \right) \\ =& \sum_{j=0}^{n} \sum_{i=0}^{n+1} (-1)^{i+j} \sigma \delta_i \delta_j \end{align*}

By a case distinction and simplicial identity of commuting face maps it holds, that

\begin{align*} \sum_{j=0}^{n} \sum_{i=0}^{n+1} (-1)^{i+j} \sigma \delta_i \delta_j =& \sum_{0 \leq i \leq j \leq n} (-1)^{i+j} \sigma \delta_i \delta_j + \sum_{0 \leq j < i \leq n+1} (-1)^{i+j} \\ =& \sum_{0 \leq i \leq j \leq n} (-1)^{i+j} \sigma \delta_{j+1} \delta_i + \sum_{0 \leq j < i \leq n+1} (-1)^{i+j} \end{align*}

By an index shift of $j$ and changing $0 \leq i \leq j \leq n$ to $i < j$, we get

\begin{align*} \sum_{0 \leq i \leq j \leq n} (-1)^{i+j} \sigma \delta_{j+1} \delta_i + \sum_{0 \leq j < i \leq n+1} (-1)^{i+j} =& \sum_{0 \leq i < j \leq n+1} (-1)^{i+j+1} \sigma \delta_{j+1} \delta_i + \sum_{0 \leq j < i \leq n+1} (-1)^{i+j} \\ =& \sum_{0 \leq i < j \leq n+1} \left( (-1)^{i+j+1} + (-1)^{i+j} \right) \sigma \delta_{j+1} \delta_i \\ =& 0 \end{align*}
