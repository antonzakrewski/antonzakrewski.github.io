class functions is a commutative subalgebra for the convolution product

Proposition

Let $G$ be a finite group. Then the set of class function $\mathrm{Cl}(G, \mathbb{C}) \subseteq \mathrm{Fun}(G,\mathbb{C})$ is a subalgebra

Proof

observe that $\partial_{e}, 0$ are class functions. Now let $f_1,f_2$ be class functions. Then

\begin{align*} (f_1 \star f_2)(g) =& \sum_{xy = g} f_1(x) f_2(y) \\ =& \sum_{xy = g} f_1(h xh^{-1}) f_2(h y h^{-1}) \\ =& \sum_{h x h^{-1} h y h^{-1} = h g h^{-1}} f_1(h xh^{-1}) f_2(h y h^{-1}) \\ =& \sum_{x' y' = h g h^{-1} } f_1(x') f_2(y') \\ =& (f_1 \star f_2)(h g h^{-1}) \end{align*}
