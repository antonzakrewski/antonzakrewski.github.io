finite product of locally path connected spaces as locally path connected space

Proposition

Let $X_$ be locally path connected topological spaces. Then the finite product $\prod X_i$ is also locally path connected.

Proof

Let $(x_i) \in \prod X_i$ and $U_1 \times ... \times U_n$ a neighbourhood. Then there exists path connected neighbourhoods $V_i \subseteq U_i$ and thus

\begin{align*} V_1 \times ... \times V_n \end{align*}

is a path connected subset (cf. product of path connected spaces as path connected space)
