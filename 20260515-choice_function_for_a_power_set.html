choice function for a power set

Definition

Let $X$ be a set, $\mathcal{P}(X)$ the power set. Then a choice function on $\mathcal{P}(X)$ is a map

\begin{align*} f \colon \mathcal{P}(X) \rightarrow& \mathcal{P}(X) \\ \end{align*}

such that

  1. $f(S) \subseteq S$ for all $S \subseteq X$.
  2. $f(S) \neq \emptyset$ for all $S \neq \emptyset$,
  3. $f \circ f = f$

Remark

$f(S) \neq \emptyset$ presupposes, that there exists a "best choice" which might be to strong (e.g. moral dillemas)
