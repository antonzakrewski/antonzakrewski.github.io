connecting a forest to a tree

Proposition

Let $F = (V,E)$ be a forest. Then there exists a tree $T$ with $F \subseteq T$, $V_F = V_G$ and $E_F = E_G$ if and only if $F$ is already a tree

Proof

$F$ a tree

Then choose $F = T$

$F$ not a tree

Then there exist at least 2 connected components $T_1,T_2$. Choose two vertices $v_1 \in T_1,v_2 \in T_2$ and connect them via an edge. Note that the new graph is still acyclic: Assume otherwise, then there exists a path $v_1 \rightarrow ... \rightarrow v_n \rightarrow v_i$. It can't lie fully in one original connected component $T_i$ since $F$ is acyclic. hence it must switch the connected components at least twice. But by construction there exists only one edge between $T_1$ and $T_2$, which can be choosen only once.

Repeat this procedure until the new graph $G'$ is connected. Then $G'$ is still acyclic (by the reasons above) so $T = G$ satisfies the assumptions.
