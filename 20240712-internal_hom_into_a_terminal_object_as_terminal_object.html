internal hom into a terminal object as terminal object

Proposition

Let $(\mathcal{V}, \otimes_{\mathcal{V}}, \mathds{1}_{\mathcal{V}})$ be a closed monoidal category. Then the internal hom of the terminal object $1$ is the terminal object

\begin{align*} \underline{\mathrm{Hom}}(X,1) = 1 \end{align*}

Proof

corollary of

  • internal hom as right adjoint
  • terminal object as empty limit
  • right adjoint preserves limits
