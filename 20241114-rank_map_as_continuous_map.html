rank map as continuous map

Proposition

the rank map

\begin{align*} \mathrm{rk}_{(-)}(P): \mathrm{Spec}(R) \rightarrow \mathbb{N}_0 \end{align*}

for a commutative ring $R$ and a finitely generated projective module $P$

is continuous with respect to the Zariski topology and the discrete topology on $\mathbb{N}$

Proof

corollary of:

  • locally constant map as continuous map
  • rank map as locally constant map
