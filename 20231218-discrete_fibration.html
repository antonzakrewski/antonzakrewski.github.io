discrete fibration

Definition

Let $\mathcal{C}, \mathcal{D}$ be categories and $\mathcal{F}: \mathcal{C} \rightarrow \mathcal{D}$ Abe a functor.

Then $\mathcal{F}$ is said to be a discrete fibration, if for each object $C \in \mathrm{Ob}(\mathcal{C})$, $b \in \mathrm{Ob}(\mathcal{D})$ and each morphism

\begin{align*} g: b \rightarrow \mathcal{F}(c) \end{align*}

there exists an object $d \in \mathrm{Ob}(\mathcal{D})$ and a morphism $h: d \rightarrow c$ such that

\begin{align*} \mathcal{F}(h) = g \end{align*}
