derivation in differential geometry is an element in the zariski tagent space

Proposition

Let $M$ be a smooth manifold (complex manifold), $m \in M$ a point and $\mathcal{O}_{M,m}$ the stalk with maximal ideal $\mathfrak{m}$. Then a derivation at $m$ is the same as an $\mathbb{R}$ linear map $\mathfrak{m}/\mathfrak{m}^2 \rightarrow \mathbb{R}$

Proof

R-derivation is Z-derivation with kernel first observe that $\mathbb{R}$ lies in the kernel of the / any $\mathbb{R}$ derivation.

Now <todo: at $m$> and leibniz rule imply that for $f,g \in \mathcal{O}_{M,m}$ with $f(m) = g(m) = 0$ (or $f,g \in \mathfrak{m})$, we have the identity

\begin{align*} (f g)'(m) =& f(m) g'(m) + g(m) f'(m) \\ =& 0 g'(m) + 0 f'(m) \\ =& 0 \end{align*}

implies that this vanishes.

So an $\mathbb{R}$ derivation induces a linear function $\mathfrak{m}/\mathfrak{m}^2 \rightarrow \mathbb{R}$.

Now assume we have an $\mathbb{R}$ linear function $\mathfrak{m}/\mathfrak{m}^2 \rightarrow \mathbb{R}$. Then we define $\partial$ to be the composite $\mathcal{O}_{M,m} \simeq \mathfrak{m} \oplus \mathbb{R} \rightarrow \mathfrak{m} \rightarrow \mathfrak{m}/\mathfrak{m}^2 \rightarrow \mathbb{R}$.

This is $\mathbb{R}$ linear and we claim that this is a derivation: Suppose we have $(f_1 + c_1), (f_2 + c_2) \in \mathfrak{m} \oplus \mathbb{R}$. Then

\begin{align*} \partial((f_1 + c_1) \cdot (f_2 + c_2)) =& c_1 \partial(f_2) + c_2 \partial(f_1) + \partial(f_1 f_2) + \partial(c_1 c_2) \\ =& (c_1 + f_1) \partial(f_2 + c_2) + (c_2 + f_2) \partial(f_1 + c_1) \end{align*}

where we have used $f_j \partial(f_i) = 0$ as $f_j \in \mathfrak{m}$
