Translations-Invarianz (Anordnung)

Satz

\begin{align*} x < y \land y < z \Rightarrow x < z \end{align*}

Beweis

  • aus:
  • Definition: Relationen
  • Abgeschlossenheit gegenüber Addition (Axiom)
\begin{align*} x - y < 0 \Rightarrow y - x > 0 \\ y - z < 0 \Rightarrow z - y > 0 \\ (y - x) + (z - y) > 0 \\ z - x > 0 \Rightarrow z > x \end{align*}
