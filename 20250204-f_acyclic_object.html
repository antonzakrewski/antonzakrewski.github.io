F-acyclic object for an exact functor between stable categories

Definition

Let $\mathcal{F}: \mathcal{C} \rightarrow \mathcal{D}$ be a exact infinity functor in category cat stable Then an object $C \in \mathcal{C}$ is said to be \(\mathcal{F}\)-acyclic, if

\begin{align*} \mathcal{F}(c) \simeq 0 \end{align*}

is a zero object
