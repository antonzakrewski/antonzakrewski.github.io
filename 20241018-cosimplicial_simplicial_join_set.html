join cosimplicial set

Definition / Proposition

The join cosimplicial set is defined as cosimplicial simplicial set given by

\begin{align*} [-] \star: \Delta \rightarrow& \mathrm{Set} \\ [n] \mapsto& \Delta^n \star (\Delta^n)^{\mathrm{op}} \\ (f: [n] \rightarrow [m]) \mapsto& (f \star f^{\mathrm{op}}: \Delta^n \star (\Delta^n)^{\mathrm{op}} \rightarrow \Delta^m \star (\Delta^m)^{\mathrm{op}} \end{align*}

where

  1. $\Delta$ is the represented simplicial set
  2. $\star$ is the join
  3. $(-)^\mathrm{op}$ is the opposite simplicial set

note that it is a cosimplicial simplicial set, as it is a functor

\begin{align*} [-] \star: \Delta \rightarrow \mathrm{sSet} \end{align*}
