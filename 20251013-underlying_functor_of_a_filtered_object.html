underlying object functor of a filtered object

Definition

Let $\mathcal{C}, \otimes, \mathbbm{1}$ be a (nice ?) symmetric monoidal category with sequential colimits, $(\mathbb{Z}, \geq)$ the sum symmetric monoidal structure on the integers. Then the underlying object functor is defined as colimit functor

\begin{align*} \mathrm{colim}_{n \rightarrow - \infty}: \mathrm{Fil}(\mathcal{C}) \rightarrow \mathcal{C} \end{align*}
