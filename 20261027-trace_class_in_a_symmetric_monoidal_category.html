trace class morphism in a symmetric monoidal category

Definition

Let $\mathcal{C}$ be a symmetric monoidal category with unit $\mathbbm{1}_\mathcal{C}$. A morphsim $f: X \rightarrow Y$ in $\mathcal{C}$ is called trace-class if there exists an object $Z$ and a map $\alpha: \mathbbm{1}_{\mathcal{C}} \rightarrow Z, \beta: Z \otimes X \rightarrow \mathbbm{1}$ such that the diagram 

\begin{displaymath}
\begin{tikzcd}
& Y \otimes Z \otimez X \arrow[]{rd}{\beta}& \\
X \arrow[]{rr}{f} \arrow[]{ru}{\alpha}& & Y 
\end{tikzcd}
\end{displaymath}

commutes.
