convergent filtered object

Definition

Let $\mathcal{F} \in \mathrm{Fun}(\mathbb{Z}, \mathcal{C})$ be a filtered object for a pointed category $\mathcal{C}$. Then $\mathcal{F}$ is said to be convergent if both the sequential limit and sequential colimit exist and

\begin{align*} \mathrm{lim}_{n \in \mathbb{Z}} \mathcal{F}(n) = 0 \end{align*}

In that case we say that $\mathcal{F}$ converges to $\mathrm{colim} \mathcal{F}(n)$
