path component functor from top commutes with products

Proposition

Given category Top and the functor from Top to the set of path components it commutes with the categorical product, i.e.

\begin{align*} \prod_{i \in I} \pi_0(X_i) = \pi_0(\prod_{i \in I} X_i) \end{align*}

Proof

$\prod_{i \in I} \pi(X_i) \subseteq \pi(\prod_{i \in I} X_i)$
