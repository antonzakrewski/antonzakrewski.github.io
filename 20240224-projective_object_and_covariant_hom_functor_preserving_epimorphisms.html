projective object and covariant hom functor preserving epimorphisms

Proposition

Let $\mathcal{C}$ be a category, $P \in \mathrm{Ob}(\mathcal{C})$ an object.

TFAE:

  1. $A$ is an projective object
  2. the covariant hom functor $\mathrm{Hom}_{\mathcal{C}}(P,-): \mathrm{\mathcal{C}} \rightarrow \mathrm{Set}$ preserves epimorphisms
  3. the covariant hom functor $\mathrm{Hom}_{\mathcal{C}}(P,-): \mathrm{\mathcal{C}} \rightarrow \mathrm{Set}$ sends epimorphisms to surjections

Proof

1) $\implies$ 2)

Let

\begin{align*} f: M \twoheadrightarrow N \end{align*}

be an epimorphism

Then it remains to show, that

\begin{align*} f^{ \leftarrow}: \mathrm{Hom}_{\mathcal{C}}(P,M) \twoheadrightarrow \mathrm{Hom}_{\mathcal{C}}(P,N) \arrow[]{r}{} \end{align*}

is an epimorphism in set resp. a surjection (cf. epimorphism in set as surjective map)

and thus by assumption a morphism

hence

\begin{align*} f^{ \leftarrow}(h) =& f \circ h \\ =& g \end{align*}
