groupoid core functor preserves and detects fully faithful exact functors between stable categories

Proposition

Let $\mathcal{F}: \mathcal{C} \rightarrow \mathcal{D}$ be an exact functor between stable categories TFAE:

  1. $\mathcal{F}$ is fully faithful
  2. $\mathcal{F}^{\simeq}$ is fully faithful

Proof

1) $\implies$ 2)

follows from groupoid core functor preserves fully faithful functors

2) $\implies$ 1)

We need to show that for every pair $x,y \in \mathcal{C}$, the map

\begin{align*} \mathcal{F}_{x,y}: \mathrm{Hom}_{\mathcal{C}}(x,y) \rightarrow \mathrm{Hom}_{\mathcal{D}}(\mathcal{F}(x),\mathcal{F}(y)) \end{align*}

is an equivalence

Here we have maps

\begin{align*} \mathrm{Hom}_{\mathcal{C}}(x,y) \rightarrow& \mathrm{Hom}_{\mathcal{C}}(x,y) \times \{\mathrm{id}_{x \oplus y\} \\ \rightarrow& \mathrm{Hom}_{\mathcal{C}}(x \oplus x \oplus y, y \oplus x \oplus y ) \xrightarrow& \mathrm{Hom}_{\mathcal{C}}(x \oplus y, x \oplus y) \end{align*}

where the last step is given by pre/post composition with the codiagonal/diagonal.

Furthermore this map is a section with retract given by precopmosition with $x \rightarrow x \oplus y$ and postcomposition with $x \oplus y \rightarrow y$

\begin{align*} \mathrm{Hom}_{\mathcal{C}}(x \oplus y, x \oplus y) \rightarrow \mathrm{Hom}_{\mathcal{C}}(x,y) \end{align*}

Now this map lands in $\mathrm{Aut}_{\mathcal{C}}(x \oplus y)$ since any morphism of the form $\begin{pNiceMatrix} 1 & 0 \\ f & 1 \end{pNiceMatrix}$ is invertible. Any step in this map is invariant under additive functors, so we have a diagram

which shows that the map $\mathrm{Hom}_{\mathcal{C}}(x,y) \rightarrow \mathrm{Hom}_{\mathcal{D}}(\mathcal{F}(x), \mathcal{F}(y))$ is a retract of the map $\mathrm{Aut}(x \oplus y) \rightarrow \mathrm{Aut}(\mathcal{F}(x) \oplus \mathcal{F}(y) )$.

Equivalences are closed under retracts and therefore $\mathrm{Hom}_{\mathcal{C}}(x,y) \rightarrow \mathrm{Hom}_{\mathcal{D}}(\mathcal{F}(x), \mathcal{F}(y))$ is an equivalence since $\mathrm{Aut}(x \oplus y) \rightarrow \mathrm{Aut}(\mathcal{F}(x) \oplus \mathcal{F}(y))$ is.
