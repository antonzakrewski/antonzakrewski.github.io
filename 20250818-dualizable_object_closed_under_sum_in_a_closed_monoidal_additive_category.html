dualizable object closed under sum in a preadditively symmetric monoidal category

Proposition

Let $\mathcal{C}$ be a preadditively symmetric monoidal category. Then left resp. right dualizable objects are closed under finite sums

Proof - should work

Note that

\begin{align*} X^{\vee} = \underline{\mathrm{map}}(X_1 \oplus X_2,\mathbbm{1}) \simeq X_1^{\vee} \oplus X_2^\vee \end{align*}

Thus define

\begin{align*} (\mathrm{ev}_1, \mathrm{ev}_2, 0,0): \mathbbm{1} \rightarrow X_1 \otimes X_1^{\vee} \oplus X_2 \otimes X_2^{\vee} \oplus X_1 \otimes X_2^{\vee} \oplus X_2 \otimes X_2^{\vee} \\ (\mathrm{coev}_1, \mathrm{coev}_2, 0,0): X_1 \otimes X_1^{\vee} \oplus X_2 \otimes X_2^{\vee} \oplus X_1 \otimes X_2^{\vee} \oplus X_2 \otimes X_2^{\vee} \rightarrow \mathbbm{1} \end{align*}

then note that

\begin{align*} 0 \otimes f = 0 \end{align*}

is the zero morphism by functor preserving zero morphism and preserving zero object (since $- \otimes X$ preserves the zero object).
