clique number as chromatic number of an interval graph

Proposition

Let $G = (V,E)$ be an interval graph. Then the clique number is the independence number

Proof

Let $V = \{[a_i,b_i]\}$. Then consider the lexicographic order on $V$ with $(a_i,b_i)$.

Then use the greedy coloring: Suppose the color $k$ appears at some step $[a_{i_k},b_{i_k}].

it suffices to construct a clique in the greedy coloring after adding $[a_{i_k},b_{i_k}]$.

Then it is connected to some amount of vertices with color $k-1,...,1$. choose the vertices $[a_{i_{l}},b_{i_l}]$ where $b_l$ is maximal - in particular it is the vertex with maximal $b_{i_l}$ amount color $l$ (since $a_{i_k} > a_{i_{l}}$ by the deglex order so that the vertex with maximal $b_{i_l}$ has to intersect $a_{i_k}$ since $a_{i_k} < b_{i_l}$ ) We claim that $[a_{i_1},b_{i_1}],...,[a_{i_k},b_{i_k}]$ forms a clique.

Suppose they dont form a clique, so assume

\begin{align*} a_{i_j} > b_{i_l} \end{align*}

for some distinct colors $j,l$

$j > l$

then we would have assigned color $l$ to $j$ since it does not intersect the maximal interval with color $j$ since it lies to the right.

$l > j$

but by deglex order we have

\begin{align*} b_{i_l} < a_{i_j} < a_{i_k} \end{align*}

so $[a_{i_k},b_{i_k}]$ does not intersect $[a_{i_l},b_{i_l}]$, contradiction the the construction
