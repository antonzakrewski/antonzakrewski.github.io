(infinity,1) category

Definition

Let $X$ be a simplicial set. Then $X$ is said to be an \(\infty\)-category if it has the extension property for all inner horn inclusions

\begin{align*} \Lambda_j^n \rightarrow \Delta^n \end{align*}

for $n \geq 2, 0 < j < n$

Remark

It seems reasonable to name $X$ as

  1. infinity category, if one thinks about it in the context of the infinity category of infinity categories
  2. quasicategory, if one thinks about it in the \(1\)-category category of Quasicategories

But I'm not consistent :/
