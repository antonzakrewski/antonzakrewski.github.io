pi_0 of a simplicial set

Definition

Let $X: \Delta^{\mathrm{op}} \rightarrow \mathrm{Set}$ be a simplicial set and $\sim$ the generated equivalence relation by

\begin{align*} x \sim y :\Leftrightarrow \exists f \in X_1 : d_0(f) = x, d_1(f) = y \end{align*}

for the n-simplices $X_0, X_1$

Then $\pi_0^{\Delta}(X)$ is defined as

\begin{align*} \pi_0^{\Delta}(X) \coloneqq X_0/\sim \end{align*}
