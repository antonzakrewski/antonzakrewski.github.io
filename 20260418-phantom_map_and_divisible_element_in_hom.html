phantom map into spectrum with finitely generated homotopy groups and divisible element in hom

Proposition

Let $\varphi: X \rightarrow Z$ be map of spectra TFAE:

  1. $\varphi$ is a phantom map.
  2. $\varphi \in \pi_0(\mathrm{Hom}_{\mathrm{Sp}}(X,Z))$ is a divisible element

Proof

1) $\implies$ 2)

2) $\implies$ 1)
