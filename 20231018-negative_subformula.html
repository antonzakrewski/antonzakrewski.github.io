negative subformula

Definition

Sei $A$ eine Formel. Dann ist eine negative Teilformel von $A$ definiert durch

  1. Falls $B \lor C$ oder $B \land C$ eine negative Teilformel von $A$ ist, so auch $B,C$
  2. Wenn $\forall_x B(x), \exists_x B(x)$ eine negative Teilformel von $A$ ist, so auch $B$
  3. Wenn $B \rightarrow C$ eine negative Teilformel ist, so ist $C$ eine negative Teilformel
  4. Wenn $B \rightarrow C$ eine positive Teilformel von $A$ ist, so ist $B$ eine negative Teilformel
