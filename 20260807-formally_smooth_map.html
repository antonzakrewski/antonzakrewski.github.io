formally smooth map

Definition

Let $f: X \rightarrow Y$ be a map of algebraic functors. Then $f$ is said to be formally smooth, if for every commutative ring $R$, every first order thickening $\tau$ of $R$ and every R-point $y \in Y(R)$, the induced map

\begin{align*} \{\tau- \textrm{tangential data at} y \textrm{ in } Y \} \rightarrow \{\tau-\textrm{ tangential data at} f(y) in X\} \end{align*}

is a surjection.

In other words, $f: X \rightarrow Y$ has the left / right (?) lifting property against thickenings
