projective object in a stable category

Proposition

Let $\mathcal{C}$ be a stable category Then the only projective object is the zero object

Proof

Let $X$ be projective. Then as usual $\Sigma \Omega X \simeq X$ and the suspension of an object is also a simplicial colimit (cf. suspension in a pointed category is a simplicial colimit) of objects of the form $\bigoplus_{i_n} \Omega X$ together with products/coproducts of identity morphisms. Hence Hence by projective object as sifted object and retract it follows that the identity of $X$ factors through some $\bigoplus_{i_n} \Omega X$. But each map $\bigoplus_{i_n} \Omega X \rightarrow \Sigma \Omega X$ comes from a map $\bigcoprod_{i} * \rightarrow S^1$ in $\mathrm{An}_*$, so in particular the left map is nullhomotopic and the finitely cocomplete category is tensored over finite anima preserves zero morphism (cf. functor preserving zero morphism and preserving zero object). Hence the identity factors through the zero morphism, which shows that $X$ must be the zero object
