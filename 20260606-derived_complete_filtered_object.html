derived complete filtered object

Definition

Let $X: \mathbb{Z}^{\mathrm{op}} \rightarrow \mathcal{C}$ be a filtered object in a complete stable category. Then it is called derived complete, if

\begin{align*} \lim_{\mathbb{Z}^{\mathrm{op}}} X \simeq 0 \end{align*}

Remark

If $\mathcal{C}$ is an abelian category, then we pass to the derived category
