n-fold suspension is trivial in a pointed n-truncated category

Proposition

Let $\mathcal{C}$ be an n-truncated pointed category with and pushouts. Then the functor $\Sigma^n: \mathcal{C} \rightarrow \mathcal{C}$ is equivalent to $\mathrm{const}_*$

Proof

observe that $\{*\} \subseteq \mathcal{C}$ is a full subcategory and $\{*\}$ is the terminal object in category Cat so it suffices to show that $\Sigma^n$ factors through $\{*\} \hookrightarrow \mathcal{C}$ on objects.

Furthermore we can then pass to $\mathcal{C}^{\mathrm{op}}$ and compute the loop space functor for the zero object $*$. There we can use that the yoneda embedding preserves limits - i.e. also loop spaces since $\mathcal{C}$ is by assumption pointed.

There it factors through $\mathrm{Fun}(\mathcal{C},\mathrm{An}_{\leq n-1}) \subseteq \mathrm{Fun}(\mathcal{C}, \mathrm{An})$, where the subcategory is closed under limits. Using pointwise calculation of limits, it finally suffices to see that $\Omega^n X \cong *$ for an n-truncated anima (here it is nonempty by definition by the definition of the loop space as pullback in $\mathrm{An}$).
