local object

Definition

Let $\mathcal{C}$ be a locally small category, $C \in \mathrm{Ob}(\mathcal{C})$ an object and $S \subseteq \mathrm{Mor}(\mathcal{C})$ a collection of morphisms.

Then $C$ is said to be \(S\)-local, if the contravariant hom-functor

\begin{align*} \mathrm{Hom}_{\mathcal{C}}(-,C): \mathcal{C} \rightarrow \mathrm{Set} \end{align*}

sends each morphism $s: A \rightarrow B$ to an isomorphism in category set

\begin{align*} \mathrm{Hom}_{\mathcal{C}}(s,C): \mathrm{Hom}_{\mathcal{C}}(B,C) \cong \mathrm{Hom}_{\mathcal{C}}(A,C) \end{align*}
