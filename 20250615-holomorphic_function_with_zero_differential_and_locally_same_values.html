holomorphic function with zero differential and locally same values

Proposition

Let $f: \Omega \rightarrow \mathbb{C}$ be holomorphic and assume that

\begin{align*} f^{(1)}(z_0) =& f^{(2)}(z_0) = ... = f^{(k-1)}(z_0) = 0 \\ f^{(k)}(z_0) \neq& 0 \end{align*}

Then there exist $\varepsilon > 0, \delta > 0$ such that for all $w \in D_{\varepsilon}(f(z_0)) \setminus \{f(z_0)\}$ there are exactly $k$ many $z_1,...,z_n \in D_{\delta}(z_0)$ such that

\begin{align*} f(z) = w \end{align*}
