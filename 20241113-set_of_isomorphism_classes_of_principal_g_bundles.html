set of isomorphism classes of principal g-bundles

Proposition

Let $B$ be a topological space and $G$ a topological group, then the set of isomorphism classes of principal g-bundles is a proper set

Proof

Let $p: E \rightarrow B$ be a principal g-bundle Note that by fiber of a principal g-bundle as g-torsor there exists a set-theoretic bijection

\begin{align*} E \cong B \times G \end{align*}

But the class of pairs containing

  1. topologies on $B \times G$
  2. \(G\)-actions, i.e. certain maps $G \times B \rightarrow B$

is a set. Hence especially the subset of pairs satisfying some conditions for a principal g-bundle is also a set.
