product of quasicategories is a quasicategory

Proposition

Let $X_i$ be infinity categories, then so is $\prod X_i$.

Proof

using:

  • quasicategory and terminal morphism as inner fibration

follows as

  • product with the terminal object canonically iso and
\begin{align*} \prod X_i \rightarrow \prod * \cong * \end{align*}

as well as:

  • set with right lifting property as cosaturated set
  • cosaturated set
