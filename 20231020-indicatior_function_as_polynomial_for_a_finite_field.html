indicatior function as polynomial for a finite field

Proposition

Let $\mathbb{F}_q$ be a finite field for $q = p^m$ and $f \in F$. Then the map

\begin{align*} \chi: F \rightarrow& \{0,1\} \\ x \mapsto \begin{cases} 1 & \mbox{if } f = x \\ 0 & \mbox{else } \\ \end{cases} \end{align*}

is a polynomial

Proof

follows from Satz von Fermat (Gruppentheorie)
