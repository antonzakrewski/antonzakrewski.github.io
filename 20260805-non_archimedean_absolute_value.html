non-archimedean absolute value

Definition

Let $\vert - \vert: K^{\times} \rightarrow \mathbb{R}_{> 0}$ be an absolute value for a field $K$. Then it is called non-archimedean, if it satisfies the ultrametric inequality, i.e.

\begin{align*} \vert x + y \vert \leq \mathrm{max}(\vert x \vert, \vert y \vert) \end{align*}
