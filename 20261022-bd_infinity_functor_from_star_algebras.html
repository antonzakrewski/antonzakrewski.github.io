Bd infinity functor from star algebras

Proposition

Define

\begin{align*} \mathrm{Bd}^{\infty}: \mathrm{*Alg} \rightarrow& \mathrm{pre-C*Alg} \\ \end{align*}

which is given on objects by transfinite induction where we define

  1. $\mathrm{Bd}^{\alpha+1} \coloneqq \mathrm{Bd}(\mathrm{Bd}^{\alpha})$
  2. for limit ordinals $\mathrm{Bd}^{\alpha} \coloneqq \bigcap_{\beta < \alpha} \mathrm{Bd}^{\beta}$

Then $\mathrm{Bd}^{\infty}$ is a right adjoint to the inclusion.

Proof

observe that this $\mathrm{Bd}^{\infty}$ construction stabilizes objectwise, since the set of any algebra has a fixed cardinality. Moreover by construction $\mathrm{Bd}(\mathrm{Bd}^{\infty}(A)) = \mathrm{Bd}^{\infty}(A)$, so it maps to pre-*-algebras.

Furtermore, for any pre C-* algebra $T$ we need to show that

\begin{align*} \mathrm{Hom}_{\mathrm{pre-C-*Alg}}(T,\mathrm{Bd}^{\infty}(A)) \rightarrow \mathrm{Hom}_{*Alg}(T, A) \end{align*}

is an equivalence. But for this we may use that $\mathrm{Hom}_{\mathrm{pre-C-*Alg}}(T, \mathrm{Bd}(A)) \cong \mathrm{Hom}_{\mathrm{*Alg}}(T, A)$ and use that $\mathrm{Bd}^{\infty}(A)$ is the sequential limit, so we may pull it out and it becomes a constant, sequential limit.
