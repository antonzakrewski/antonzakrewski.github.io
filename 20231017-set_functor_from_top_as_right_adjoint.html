set functor from Top as right adjoint

Proposition

Given category set and category Top, the underlying-set functor is a right adjoint to the functor from Set to the discrete topology

Proof

Follows from

\begin{align*} \eta: \mathrm{Hom}_{\mathrm{Top}}(\mathrm{disc}(-),-) \rightarrow& \mathrm{Hom}_{\mathrm{Set}}(-, \mathrm{Set}(-)) \\ (f: (X, \mathcal{P}(X)) \rightarrow (Y, \mathcal{T})) \mapsto& (f: X \rightarrow Y) \end{align*}
