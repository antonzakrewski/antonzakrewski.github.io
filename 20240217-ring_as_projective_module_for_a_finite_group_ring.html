ring as projective module for a group ring with cardinality as unit

Proposition

Let $R$ be a ring, $G$ a finite group and $R[G]$ the group ring. Suppose $\vert G \vert \in R^{\times}$ is a unit.

Then $R$ as module over $R[G]$ via the augmentation map is a projective module

Proof

Note that $R[G]$ is trivially a projective module. But since retract of a projective object as projective object it suffices to show that $R$ is a retract.
