Proposition

The map

\begin{align*} \mathrm{PC}: \mathrm{Tree}(n) \rightarrow& \{1,...,n\}^{n-2} \\ G \mapsto& \mathrm{PC}(G) \end{align*}

is a Bijection, where $\mathrm{Tree}(n)$ denotes the set of trees with $n$ many vertices.

Proof

$n = 1,2$

Then there exists only one tree and only one empty list.

$n \geq 2$
