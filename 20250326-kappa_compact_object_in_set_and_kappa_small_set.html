kappa compact object in set and kappa small set

Proposition

Let $X \in \mathrm{Set}$ be a set, $\kappa$ a regular cardinal

TFAE:

  1. $X$ is a kappa compact object
  2. $\vert X \vert < \kappa$ is kappa-small

Proof

1) $\implies$ 2)

kappa small colimit of kappa compact objects

2) $\implies$ 1)

follows from:

  • compact object as filtered colimit and retract

as any set is the union of $\kappa$ small subsets.

hence a compact object is a retract of a \(\kappa\)-small subset, i.e. itself \(\kappa\)-small
