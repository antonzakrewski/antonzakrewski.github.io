whitehead theorem for model categories

Proposition

Let $(\mathcal{C}, \mathcal{W}, \mathrm{Cof}, \mathrm{Fib})$ be a model category. Let $X_1,X_2$ be cofibrant objects, $Y_1,Y_2$ fibrant objects and $f: X_1 \rightarrow X_2, g: Y_1 \rightarrow Y_2$ morphisms.

a)

TFAE:

  1. $g$ is a homotopy equivalence
  2. $\mathrm{Hom}_{\mathrm{ho}(\mathcal{C})}(X,Y_1) \rightarrow \mathrm{Hom}_{\mathrm{ho}(\mathcal{C})}(X,Y_2)$ is a Bijection for each cofibrant object $X$

a)

TFAE:

  1. $f$ is a homotopy equivalence
  2. $\mathrm{Hom}_{\mathrm{ho}(\mathcal{C})}(X_2,Y) \rightarrow \mathrm{Hom}_{\mathrm{ho}(\mathcal{C})}(X_1,Y)$ is a Bijection for each cofibrant object $X$
