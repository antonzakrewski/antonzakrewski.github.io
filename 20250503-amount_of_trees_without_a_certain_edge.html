amount of trees without a certain edge

Proposition

Let $n \in \mathbb{N}$, then there exist ? many trees with $\{1,...,n\}$ as vertices and without the edge $\{1,2\}$

Proof

consider the prüfer code as bijection resp. the inverse construction. Here we add an edge $1-2$ iff one of the following cases appear

  1. the Prüfer code starts with $2$ and then does not contain any $1$
  2. the Prüfer code starts with $1$ and then does not contain any $2$
  3. the prüfer code contains a sequence $1,2$ and then does not contain any $1$
  4. the prüfer code contains a sequence $2,1$ and then does not contain any $2$

Note that we never add an edge $1-2$ as last step, since in the case of a graph with $3$ vertices $1,2,n$ we always remove $1$ or $2$ (graph contains at least 2 leafs)

Furthermore the four cases are distinct and we have

  1. $(n-1)^{n-3}$
  2. $(n-1)^{n-3}$
  3. $\sum_{a=0}^{n-4} n^a \cdot (n-1)^{n-4-a}$
  4. $\sum_{a=0}^{n-4} n^a \cdot (n-1)^{n-4-a}$

Hence we have

\begin{align*} n^{n-2} - 2 \cdot (n-1)^{n-3} - 2 \cdot \sum_{a=0}^{n-4} n^a (n-1)^{n-4-a} \end{align*}

many trees without the edge $1,2$
