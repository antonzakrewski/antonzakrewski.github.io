adding initial objects to a diagram

Definition

Let $\mathcal{C}$ be category with initial object and $I$ an indexing category. Suppose we add $v$ via a single map $v \rightarrow i$ and denote this resulting category $I_v$ Then

\begin{align*} \mathrm{Fun}(I, \mathcal{C}) \subseteq \mathrm{Fun}(I_v, \mathcal{C}) \end{align*}
