functor categories of large cardinals in general not a large category

Proposition

Let $\lambda_1,\lambda_2$ be two inaccessible cardinal. Let $\mathcal{C}, \mathcal{D}$ be large infinity categories with respect to $\lambda_1$. Then the functor category

\begin{align*} \mathrm{Fun}(\mathcal{C}, \mathcal{D}) \end{align*}

is in general not \(\lambda_1\)-large but only \(\lambda_2\)-large

see:

  • large category

Proof

Let $\mathcal{C}$ be the category containing only identity morphisms and \(\lambda_1\)-many objects. For example take the category containing sets, which are \(\lambda_1\)-small and then remove nontrivial morphisms.

Let $\{0,1\} = \{*\} \coprod \{*\}$ be the similar construction.

Then a functor in $\mathrm{Fun}(\mathcal{C}, \{0,1\})$ corresponds precisely to a set theoretic map

\begin{align*} \mathrm{Obj}(\mathcal{C}) \rightarrow \{0,1\} \end{align*}

which then corresponds to the power set of $\mathcal{P}(\mathrm{Obj}(\mathcal{C}))$.

This has higher cardinality by Satz von Cantor, hence is not \(\lambda_1\)-large
