normal integral domain as point local property

Proposition

Let \(A\) be an Integral domain.

Then being a normal integral domain is a point local property

Proof

Let

\begin{align*} \iota: A \rightarrow A^{\nu} \end{align*}

be the inclusion.

Then $A$ is normal if and only if $\iota$ is surjective As surjectivity as point local property it suffices to show that localization commutes with integral closure.
