P^1 is not an interval object

Proposition

The projective space $\mathbb{P}^1$ is not an interval object.

Proof

use that one can embed $\mathbb{A}^1 \hookrightarrow \mathbb{P}^1$ and use that $\mathbb{P}^1$ is not $\mathbb{A}^1$ contractible (e.g. etale cohomology if there exists an invertible prime, or algebraic k-theory).
