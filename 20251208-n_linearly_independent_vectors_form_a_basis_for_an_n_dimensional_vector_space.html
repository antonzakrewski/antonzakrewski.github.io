n linearly independent vectors form a basis for an n-dimensional vector space

Proposition

Let $V$ be vector space with $\mathrm{dim}(V) = n$ and $v_1,...,v_n$ a linearly independent subset. Then $v_1,...,v_n$ is already a basis.

Proof

Assume that $w_1,...,w_n$ is another basis. Then by possibly adding some $w_i$ to $\{v_1,...,v_n\}$ we get a basis $\mathcal{B} := \{v_1,...,v_n\} \cup \{w_i\}$ (cf. Extension of a linearly dependent set to a basis).

Now since $\mathrm{dim}(V) = n$ we get $\vert \mathcal{B} \vert = n$ and since $\mathcal{B}$ contains $\{v_1,...,v_n\}$ we get $\mathcal{B} = \{v_1,...,v_n\}$. Hence $\mathcal{B}$ is a basis.
