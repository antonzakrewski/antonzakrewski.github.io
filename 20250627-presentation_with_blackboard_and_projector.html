presentation with blackboard and projector

Proposition

One can use both a blackboard and a projector:

Here most of the parts still should be done on the blackboard

Exceptions: when to use projector

  • fancy images, visualiziations
  • recall previously stated definitions
    • when some special part of the definition is needed
  • some reminders of known things
  • use as extra space:
    • when erasing a board
    • project it / a summary of it.
