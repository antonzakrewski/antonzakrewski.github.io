algebraic set of a classical affine line as finite set

Proposition

Let $K$ be a field, $\mathbb{A}_K^1$ the classical affine line and $S \subseteq \mathbb{A}_K^1$ an algebraic set Then $S$ is either $\mathbb{A}_K^1$ or a finite subset

Proof

Let $S = Z(\mathfrak{a}_i)$ be an algebraic set. Then $\mathfrak{a}_i = (f) \subseteq K[X]$, as $K[X]$ is a principal ideal domain (cf. polynomial ring as PID and coefficients as field) Let $f = \prod (g_i)$ be a product of irreducibles, then the zeros are precisely given by the polynomials $g_i = (X - \alpha)$ with degree $1$. (Ausklammern von Nullstellen von Polynomen)
