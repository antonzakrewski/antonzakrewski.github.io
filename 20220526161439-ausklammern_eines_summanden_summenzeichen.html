Ausklammern eines Summanden: Summenzeichen

Satz

\begin{align*} \sum_{i=m}^{n} \left( c + a_i\right) =& c \cdot (n + 1 - m) + \sum_{i=m}^{n} a_i \end{align*}

Beweis

über den Beweis durch vollständige Induktion

Induktionsanfang

über die Leere Summe

\begin{align*} \sum_{i=n}^{n-1} \left(c + a_i\right) =& 0 \\ =& 0 \cdot c + \cdot\sum_{i=n}^{n-1} a_i \\ =& (n - 1 + 1 - n) \cdot c + \cdot\sum_{i=n}^{n-1} a_i \end{align*}

Induktionsschritt

\begin{align*} \sum_{i=m}^{n+1} \left(c + a_i\right) =& \sum_{i=m}^n \left( c + a_i\right) + c + a_{n+1} \\ =& (n + 1 - m) \cdot c + \sum_{i=m}^n a_i + c + a_{n+1}\\ =& \left((n + 1) + 1 - m\right) \cdot c + \sum_{i=m}^{n+1} a_i \end{align*}
