connected simplicial set and 1 simplices

Proposition

Let $X$ be a simplicial set. TFAE:

  1. $X$ is a connected simplicial set
  2. for $x,y \in X_0$ there exists a \(1\)-simplex connecting both.

Proof

Proof by contraposition

1) $\implies$ 2)

Let $[x]$ be the simplicial set with

\begin{align*} [x]_0 = \{y \vert \exists 1-\textrm{simplex connecting} x,y \} \end{align*}

and $[x]_n$ as set of simplices $\sigma$, such that each vertex lies in $[x]_0$.

Then

\begin{align*} X \cong \coprod_{[x]} [x] \end{align*}

where $[x] = [y]$ are only counted once.
