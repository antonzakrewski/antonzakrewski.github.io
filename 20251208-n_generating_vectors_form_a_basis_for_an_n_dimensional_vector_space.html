n generating vectors form a basis for an n-dimensional vector space

Proposition

Let $V$ be vector space with $\mathrm{dim}(V) = n$ and $v_1,...,v_n$ a generating set. Then $v_1,...,v_n$ is already a basis.

Proof - I think this might be more complicated than it needs to be ?

Consider the subset $\mathcal{A}$ of the powerset $\mathcal{P}( \{v_1,...,v_n\})$ containing generating sets. Then it is nonempty, since $\{v_1,...,v_n\}$ is by assumption a generating set.

Since the subset $\mathcal{A}$ is a subset of a finite set, namely $\mathcal{P}( \{v_1,...,v_n\})$, it contains a minimal element with respect to $\subseteq$. This subset $\{v_i \vert i \in I\}$ (for some fixed $I \subseteq \{1,...,n\}$) is a minimal generating set, so in particular a basis by equivalence of basis, minimal generating system and maximal linearly independent subset

Then by $\mathrm{dim}(V) = n$ we get that $\vert \{v_i \vert i \in I\} \vert = n$, so in particular since $\{v_i \vert i \in I\} \subseteq \{v_1,...,v_n\}$ we get the equality.
