everywhere defined map and nondegenerate map on C_0

Proposition

Let $f: X \rightarrow Y$ be a map in category LCH_+. TFAE:

  1. $f$ is everywhere defined
  2. $f^*: C_0(Y) \rightarrow C_0(X)$ is a non-degenerate map

Proof

1) $\implies$ 2)

Assume $U \neq X$ with $x \in X \setminus U$. Then choosing an element $f \in C_0(X)$ with $f(x) \neq 0$ suffices.

2) $\implies$ 1)

Assume $U = X$, then choose a $\varphi \in C_c(X) \subseteq C_0(X)$.
