rank decomposition of spec for a finite projective module

Definition / Proposition

Let \(R\) be a commutative ring and $P$ a finite projective module. Then there exist finitely many affine schemes $\mathcal{O}_{X_i}$ with

\begin{align*} \mathrm{Spec}(R) = \coprod_{\mathcal{O}_{X_i}} \end{align*}

Proof

consider the rank map

\begin{align*} \mathrm{Spec}(R) \rightarrow \mathbb{N} \end{align*}

it is continuous map and $\mathbb{N}$ is endowed with the discrete topology. Furhtermore the rank map is bounded, thus the underlying topological space decomposes into finitely many components $A_i$ (which are in general not connected !)

\begin{align*} \mathrm{Spec}(R) = \coprod_{i =1}^n A_i \end{align*}
