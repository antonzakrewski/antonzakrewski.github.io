equivalent absolute values and equivalent topologies

Proposition

Let $\vert - \vert_1, \vert - \vert_2$ be two absolute values on a field $K$. TFAE:

  1. both absolute values ar equivalent
  2. both absolute values define the same topology on $K$
  3. for any $x$, $\vert x \vert_1 < 1$ if and only if $\vert x_2 \vert < 1$

Proof

1) $\implies$ 2)

special case

2) $\implies$ 3)

observe that $\vert x^n \vert_i = \vert x \vert_i^n$ and hence $x^n \rightarrow 0$ in the $\vert - \vert_i$ topology if and only if $\vert x \vert_i < 1$.

3) $\implies$ 1)

Suppose one is the trivial valuation, then so is the other (since $\vert x \vert_1 = 1$ implies $\vert x \vert_2 \geq 1$ and $\vert x^{-1} \vert = 1$ implies $\frac{1}{\vert x \vert_1} \geq 1$). So let $y \in K^{\times}$ with $\vert y \vert_1 \neq 1$, w.l.o.g. $\vert y \vert_1 > 1$ and hence $\vert y \vert_2 > 1$. Let $a \coloneqq \mathrm{log}_{\vert y \vert_2}( \vert y \vert_1)$ so that $\vert y \vert_2 = \vert y \vert_1^a$. In particular, $a > 0$.

Now let $x \in K^{\times}$, then there exists a nonzero $b$ such that $\vert x \vert_1 = \vert y \vert_1^b$. Suppose $b < m/n$ with $n > 0$ and $m$ integers. Then

\begin{align*} \vert x \vert_1 = \vert y \vert_1^b < \vert y \vert_1^{\frac{m}{n}} \Leftrightarrow \vert x^n \vert_1 < \vert y^m \vert_1 \Leftrightarrow \vert x^n / y^m \vert_1 < 1 \end{align*}

which by assumption only happens if and only if

\begin{align*} \vert x^n / y^m \vert_2 < 1 \Leftrightarrow \vert x^n \vert_2 < \vert y^m \vert_2 \Leftrightarrow \vert x \vert_2 < \vert y^m \vert_2 \Leftrightarrow \vert x \vert_2 < \vert y \vert_2^{\frac{m}{n} \end{align*}

hence $\vert x \vert_2 \leq \vert y \vert^{b}_2$. A symmetric argument also shows $\vert x \vert_2 \geq \vert y \vert_2^b$ so

\begin{align*} \vert x \vert_2 = \vert y \vert_2^b = \vert y \vert_1^{ab} = \vert x \vert_1^a \end{align*}
