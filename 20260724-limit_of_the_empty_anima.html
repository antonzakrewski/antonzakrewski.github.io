limit of the empty anima is empty

Proposition

Let $X_{-}: \mathcal{I} \rightarrow \mathrm{An}$ be a diagram, such that there exists an object $i \in \mathcal{I}$ with $X_{i} = \emptyset$. Then $\lim_{\mathcal{I}} X_{i} = \emptyset$.

Proof

special case:

  • limit containing the empty category is empty
