treppenapproximierbarkeit von stetigen Funktionen

Satz

Eine stetige Funktion $f$ ist treppenapproximierbar

Beweis

Da die Einschränkung auf ein Kompaktes Intervall gleichmäßig stetig ist (vgl. Gleichmäßige Stetigkeit einer stetigen Funktion von einer Kompakten Menge) gilt:

\begin{align*} \forall \varepsilon > 0 \exists \delta = \delta(\varepsilon) > 0 \end{align*}

so dass für jede Unterteilung vom kompakten Intervall mit Feinheit $\delta$ die Werte sich auf jedem Teilintervall um weniger als $\varepsilon$ unterscheiden
