graded object of a filtered object

Definition

Let $\mathcal{C}$ be a pointed, finitely cocomplete category and $\mathcal{F}: \mathbb{Z}^{\mathrm{op}} \rightarrow \mathcal{C}$ a filtered object. Then the \(n\)-th graded object is defined as $\mathrm{cofib}(\mathcal{F}(s+1) \rightarrow \mathcal{F}(s))$.
