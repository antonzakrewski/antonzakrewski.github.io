typesetting spectral sequences

Some problems i encountered + some fixes (so that I remember them)

  • for some reasons use "{stuff}" so no runaway argument
  • use clip=false
  • use y axis gap
  • use xscale =
  • consider different font sizes:
    • \class["{H_1(B,H_2(F,R))}"{font=\footnotesize} ](0,0)
    • \class["{H_1(B,H_2(F,R))}"{font=\small} ](1,0)
