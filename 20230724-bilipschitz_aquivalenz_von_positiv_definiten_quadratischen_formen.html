bilipschitz äquivalenz von positiv definiten quadratischen Formen auf endlich dimensionalen Vektorräumen

Satz

Seien $q,q'$ positiv definite quadratische Formen auf einem endlich dimensionalen reellen Vektorraum. Dann existiert ein $C \geq 0$, so dass gilt:

\begin{align*} \frac{1}{C} q \leq q' \leq C \cdot q \end{align*}

Beweis

folgt aus der bilipschitzäquivalenz von Normen auf endlich dimensionalen Vektorräumen
