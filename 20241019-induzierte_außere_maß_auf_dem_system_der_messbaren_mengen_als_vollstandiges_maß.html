induzierte äußere Maß auf dem System der messbaren Mengen als vollständiges Maß

Proposition

Sei $\mu$ ein inhalt auf einem Mengenring $\mathcal{R}$. Das induzierte äußere Maß $\mu^*$ auf dem system der messbaren Mengen ist ein vollständiges Maß

Proof

Sei $N \in \mathcal{A}$ eine Nullmenge, $A \subseteq N$ eine Teilmenge Dann ist eine abzählbare Überdeckung von $N$ auch stets eine abzählbare Überdeckung von $A$. Somit folgt $\mu^*(N) \leq 0$ bzw. $\mu^*(N) = 0$.

Für eine Menge $Q \subseteq X$ folgt aus einem Analogen Argument auch

\begin{align*} \mu^*(A) =& 0 \\ =& 0 + 0 \\ =& \mu^*(Q \cap A) + \mu^*(A \setminus Q) \end{align*}

da $Q \cap A, A \setminus Q \subseteq A$ gilt mit $\mu^*(A) = 0$ so dass $A$ sich abzählbar von Nullmengen in $\mathcal{R}$ überdecken lässt.
