spectral radius is infimum/limit of norms

Proposition

Let $T \in \mathrm{BL}(X,X)$ be an bounded endomorphism. Then $r(T) = \lim_{n \rightarrow \infty} \| T^n \|^{\frac{1}{n}} = \mathrm{inf}_{n \in \mathbb{N}} \| T^n \|^{\frac{1}{n}}$

Proof

observe that $\| T^n \|^{\frac{1}{n}}$ is bounded below, so the infimum exists. We show that $\lim_{n \rightarrow \infty} \| T^n \|^{\frac{1}{n}} = \mathrm{inf}_{n \in \mathbb{N}} \| T^n \|^{\frac{1}{n}}$.

w.l.o.g. assume that that $T^n \neq 0$ for all $n$ (otherwise any eigenvalue would have to be $0$ - and there exists an eigenvalue, aka element in the kernel (by induction) ).

Set $a_n = \mathrm{ln}(\| T^n \|$, then $a_{n_1 + n_2} \leq a_{n_1} + a_{n_2}$ for all $n_1,n_2 \in \mathbb{N}$.
