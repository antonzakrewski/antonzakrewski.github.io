Proposition

Let $A,B$ be abelian groups. TFAE:

  1. $A \sim B$ have the same acyclicity
  2. $\langle \mathbb{S}_{A}\rangle = \langle \mathbb{S}_{B}\rangle$ have the same bousfield class of a spectrum
  3. $\langle A\rangle = \langle B\rangle$ have the same bousfield class
