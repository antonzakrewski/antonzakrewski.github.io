slice category for a terminal object is canonically equivalent

Proposition

Let $\mathcal{C}$ be a category, $1 \in \mathcal{C}$ the terminal object. Then the forgetful functor from the slice category

\begin{align*} \mathcal{C}_{/1} \rightarrow \mathcal{C} \end{align*}

is an equivalence

Proof

follows from right kan extension, right kan extension along a fully faithful functor is fully faithful 

\begin{displaymath}
\begin{tikzcd}
[0] \dar \rar& \mathcal{C} \\
[1] \arrow[]{ru}{}& \\
\end{tikzcd}
\end{displaymath}

which induces a functor

\begin{align*} \mathcal{C} \rightarrow \mathrm{Fun}([1], \mathcal{C}) \end{align*}

where we may identify the essential image with the full subcategory $\mathcal{C}_{/1}$.

Here we use that $\mathrm{map}_{\mathcal{C}}(1,1) = *$ and hence the right dashed map is fully faithful

So in particular the left dashed map is also fully faithful (cf. pullback reflects fully faithful infinity functor).

Hence we can both identify $\mathcal{C}$ and $\mathcal{C}_{/*}$ as the same subcategory of $\mathrm{Ar}(\mathcal{C})$.
