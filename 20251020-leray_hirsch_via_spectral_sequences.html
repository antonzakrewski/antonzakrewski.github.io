Leray-Hirsch via serre spectral sequences

Proposition

Let

\begin{align*} F \rightarrow E \rightarrow B \end{align*}

be a fiber sequence in category of Anima.

Let $R$ be a commutative ring and assume that $H^*(F,R)$ is degrewise finitely generated free. Furhtermore assume that the induced map $H^*(E,R) \twoheadrightarrow H^*(H^*(F,R)$ is surjective.

Then there exists an additive isomorphism

\begin{align*} H^*(F,R) \otimes H^*(B,R) \rightarrow H^*(E,R) \end{align*}

Proof

w.l.o.g. assume that $B$ is connected, otherwise argue for each connected component. 

\begin{sseqpage}[cohomological Serre grading, classes = { draw = none } ]
\class["H^0(B,H^0(F,R))"](0,0)
\class["H^1(B,H^0(F,R))"](1,0)
\class["H^2(B,H^0(F,R))"](2,0)
\class["H^0(B,H^1(F,R))"](0,1)
\class["H^1(B,H^1(F,R))"](1,1)
\class["H^2(B,H^1(F,R))"](2,1)
\class["H^0(B,H^2(F,R))"](0,2)
\class["H^1(B,H^2(F,R))"](1,2)
\class["H^2(B,H^2(F,R))"](2,2)
\end{sseqpage}
\begin{sseqpage}[cohomological Serre grading, classes = { draw = none } ]
\class["H^0(B,H^0(F,R))"](0,0)
\end{sseqpage}
