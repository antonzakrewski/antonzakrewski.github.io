functor preserving zero morphism and preserving zero object

Proposition

Let $\mathcal{C}, \mathcal{D}$ be pointed categories and $\mathcal{F}: \mathcal{C} \rightarrow \mathcal{D}$ be a functor TFAE:

  1. $\mathcal{F}$ preserves zero morphism
  2. $\mathcal{F}$ preserves the zero object

Proof

1) $\implies$ 2)

Note that $\mathrm{id}_{0}: 0 \rightarrow 0$ is the zero morphism $0 \in \mathrm{Hom}_{\mathcal{C}}(0,0)$ and is thus preserved. Therefore $\mathcal{F}(\mathrm{id}_{0}) = 0_{\mathcal{F}(0)}$ is the zero morphism and furthermore, factors throgh the zero object

\begin{align*} \mathcal{F}(0) \rightarrow 0 \rightarrow \mathcal{F}(0) \end{align*}

here $0: 0 \rightarrow \mathcal{F}(0)$ is split epi and a monomorphism, thus an isomorphism (cf. monic split epi as isomorphism).
