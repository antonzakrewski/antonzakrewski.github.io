Neutrales Element - Addition (komplexe Zahlen)

Satz

Das neutrale Element für die Addition komplexe Zahlen ist:

\begin{align*} e \coloneqq (0,0) = 0 \end{align*}

Beweis

Sei $z =& a + b \mathrm{i}$ eine komplexe Zahl mit $a,b \in \mathbb{R}$. Dann gilt

\begin{align*} z + 0 =& a + b \mathrm{i} + 0 \\ =& a + b \mathrm{i} \\ =& z \end{align*}
