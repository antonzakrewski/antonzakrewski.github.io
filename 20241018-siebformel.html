siebformel

Proposition

Sei $(\Omega, \mathcal{F}, \mathbb{P})$ ein Wahrscheinlichkeitsraum, $n \in \mathbb{N}$. Dann gilt für $A_i \in \mathcal{F}$

\begin{align*} \mathbb{P}(\bigcup_{i=1}^n A_i) =& \sum_{r=1}^n (-1)^{r+1} ( \sum_{1 \leq i_1 < ... < i_r \leq n} \mathbb{P}(A_{i_i} \cap ... \cap A_{i_r}) \end{align*}

Proof

Proof by induction

induction basis

für $n = 1$ gilt

\begin{align*} \mathbb{P}(\bigcup_{i=1}^1 A_i) = \mathbb{P}(A_i) =& \sum_{r=1}^1 \mathbb{P}(A_i) \end{align*}

induction step

es gilt

\begin{align*} \mathbb{P}(\bigcup_{i =1}^n A_i \cup A_{n+1}) =& \mathbb{P}(\bigcup_{i=1}^n A_i \coprod A_{n+1} \setminus (\bigcup_{i=1}^n A_i)) \\ =& \mathbb{P}(\bigcup_{i=1}^n A_i) + \mathbb{P}(A_{n+1} \setminus (\bigcup A_i)) \\ =& \mathbb{P}(\bigcup_{i=1}^n A_i) + \mathbb{P}(A_{n+1}) - \mathbb{P}(A_{n+1} \cap (\bigcup A_i)) \\ =& \sum_{r=1}^n (-1)^{r+1} ( \sum_{1 \leq i_1 < ... < i_r \leq n} \mathbb{P}(A_{i_i} \cap ... \cap A_{i_r}) )+ \mathbb{P}(A_{n+1}) - \mathbb{P}(\bigcup A_{n+1} \cap A_i) \\ =& \sum_{r=1}^n (-1)^{r+1} ( \sum_{1 \leq i_1 < ... < i_r \leq n} \mathbb{P}(A_{i_i} \cap ... \cap A_{i_r}) ) + \mathbb{P}(A_{n+1}) - \sum_{r=1}^n (-1)^{r+1} ( \sum_{1 \leq i_1 < ... < i_r \leq n} \mathbb{P}(A_{i_i} \cap ... \cap A_{i_r} \cap A_{n+1})) \\ =& \sum_{r=1}^{n+1} (-1)^{r+1} ( \sum_{1 \leq i_1 < ... < i_r \leq n} \mathbb{P}(A_{i_i} \cap ... \cap A_{i_r}) ) \end{align*}

wobei beim letzten Schritt $- (-1)^{r+1} \mathbb{P}(A_{i_1} \cap ... \cap A_{i_r} \cap A_{n+1})$ bei $r' = r+1$ einsortiert wird.
