underlying graded object functor of a filtered object

Definition

Let $\mathcal{D}$ be a (nice) category Then the underlying graded object functor is defined as

\begin{align*} \mathrm{gr}^*: \mathrm{Fil}(\mathcal{D}) \rightarrow& \mathrm{Gr}(\mathcal{D}) \\ (X_*) \mapsto& (\mathrm{cofib}(X_n \rightarrow X_{n-1}))_{n \in \mathbb{Z}} \end{align*}
