monomorphism in category top

Proposition

Let $f: X \rightarrow Y$ be a continuous map. TFAE:

  1. $f$ is a monomorphism in category Top
  2. $f$ is an injection

Proof

1) $\implies$ 2)

  • injective map as monomorphism

2) $\implies$ 1)

consider the

  • forgetful functor from top to set
  • forgetful functor from Top to Set as left adjoint
  • forgetful functor from Top to Set admits left adjoints
  • right adjoint preserves monomorphisms
