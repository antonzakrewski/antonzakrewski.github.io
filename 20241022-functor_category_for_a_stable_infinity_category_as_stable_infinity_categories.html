functor category for a stable infinity category as stable infinity categories

Proposition

Let $\mathcal{C}$ be a stable infinity category, $K$ a simplicial set Then the infinity functor category

\begin{align*} \mathrm{Fun}(K,\mathcal{C}) \end{align*}

is also a stable category

Proof

follows from:

  • colimit in an infinity functor category
  • limit in an infinity functor category

since stable categories are determined by statements about limits / colimits
