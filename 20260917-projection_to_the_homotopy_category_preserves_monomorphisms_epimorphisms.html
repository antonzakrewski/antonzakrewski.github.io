projection to the homotopy category preserves monomorphisms / epimorphisms

Proposition

Let $\mathcal{C}$ be a category, then the projection $\mathcal{C} \rightarrow h \mathcal{C}$ preserves monomorphisms / epimorphisms

Proof

monomorphisms

Recall that a morphism $f: x \rightarrow y$ is a monomorphism if and only if for each object $z \in \mathcal{C}$, the map $\mathrm{Hom}_{\mathcal{C}}(z,x) \rightarrow \mathrm{Hom}_{\mathcal{C}}(z,y)$ is a monomorphism (cf. monomorphism and Hom). Now monomorphisms in Anima are the inclusions of path components, so in particular $\pi_0(-)$ is an injection or a monomorphism in category set

epimorphism

follows dually
