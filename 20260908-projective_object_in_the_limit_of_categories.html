projective object in the limit of categories

Proposition

Let $I \rightarrow \mathrm{Cat}$ be a diagram, such that each morphism is preserves simplicial colimit Let $\lim_{I} \mathcal{C}_i$ be the limit and let $(x_i)$ be an object in $\lim_{I} \mathcal{C}_i$, such that each object $x_i$ is projective object in $\mathcal{C}_i$. Then $(x_i)$ is also $\kappa$ compact

Proof
