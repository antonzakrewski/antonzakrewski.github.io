element in a filtered colimit of commutative rings

Proposition

Let $R = \mathrm{colim} R_i$ be a filtered colimit of commutative rings Then an element $(r_i)_{i} \in R$ is w.l.o.g. given by some $r_j \in R_j$:

Proof

For each nonzero $r_i$ - of which there exist only finitely many - choose an upper bound $j$ and moprhisms $\varphi_i: R_i \rightarrow R_j$. Then $r_j = \sum \varphi_i(r_i)$ suffices
