Hüllenoperator

Definition

Sei $X$ eine Menge und $\overline{\phantom{x}}: \mathcal{P}(X) \rightarrow \mathcal{P}(X)$ eine Abbildung. $\overline{\phantom{x}}$ ist ein Hüllenoperator, falls $f$ folgende Eigenschaften erfüllt:

  1. $\overline{\emptyset} = \emptyset$
  2. $\forall A \subseteq X : A \subseteq \overline{A}$
  3. $\forall A \subseteq X : \overline{\overline{A}} = \overline{A}$
  4. $\forall A,B \subseteq X : \overline{A \cup B} = \overline{A} \cup \overline{B}$
