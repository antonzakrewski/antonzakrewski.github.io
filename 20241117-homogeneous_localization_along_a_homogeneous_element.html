homogeneous localization along a homogeneous element

Definition

Let \(R = \bigoplus_{n \in \mathbb{Z}} R_n\) be a Z-graded ring, $f \in R_i$ a homogeneous element Then the homogeneous localization along $f$ is defined as localization along an element with the \(\mathbb{Z}\)-grading of

\begin{align*} \mathrm{deg}(\frac{r}{f^n} ) = \mathrm{deg}(r) - n \end{align*}

for homogeneous $r$
