infinity twisted arrow category

Definition

Let $\mathcal{C}$ be an infinity category then the twisted infinity arrow category is defined as simplicial set

\begin{align*} \mathrm{Tw}(\mathcal{C})_n \coloneqq \mathrm{Hom}_{\mathrm{sSet}}(\Delta^n \star (\Delta^n)^{\mathrm{op}}, \mathcal{C} ) \end{align*}

where

  1. $\Delta^n \star (\Delta^n)^{\mathrm{op}}$ is the join cosimplicial simplicial set
  2. cosimplicial hom construction
