singular simplicial set functor

Definition

Given the category Top $\mathrm{Top}$ resp. $\mathrm{Space}$ as convenient category of spaces and the category sSet, the singular simplicial set functor is defined as functor

\begin{align*} \mathrm{Sing}: \mathrm{Top} \rightarrow& \mathrm{sSet} \\ X \mapsto& \mathrm{Sing}(X) = (f: X \rightarrow Y) \mapsto& (\mathrm{Sing}(f): \mathrm{Sing}(X) \rightarrow \mathrm{Sing}(Y))$ \end{align*}

where

\begin{align*} \mathrm{Sing}(f): \mathrm{Sing}(X) \rightarrow& \mathrm{Sing}(Y) \\ [n] \mapsto& (f^{ \rightarrow}: \mathrm{Hom}_{\mathrm{Top}}(\Delta^n, X) \rightarrow \mathrm{Hom}_{\mathrm{Top}}(\Delta^n, Y)) \end{align*}
