Picardgroup of algebraic line bundles

Definition / Proposition

The set of isomorphism classes of algebraic line bundles forms an abelian group

Proof

inverse element

Let $L^*$ denote the dual algebraic line bundle. Then we want to show that

\begin{align*} L^* \otimes_R L \cong R \end{align*}

by isomorphism as point local property it suffices to show that we have a map

\begin{align*} L^* \otimes_R L \rightarrow& R \\ f \otimes x \mapsto& f(x) \end{align*}

which is for each point an iso

For all $\mathfrak{p} \in \mathrm{Spec}(R)$ we have

\begin{align*} (L^* \otimes_R L)_{\mathfrak{p}} =& (L_{\mathfrak{p}})^* \otimes_{R_\mathfrak{p}} L_{\mathfrak{p}} \\ \cong& R_{\mathfrak{p}} \otimes_{R_{\mathfrak{p}}} R_{\mathfrak{p}} \\ \cong& R_{\mathfrak{p}} \end{align*}

neutral element

consider $R$
