object in an abelian category as cogroup object

Proposition

Let $\mathcal{A}$ be an abelian category and $A$ an object. Then $A$ is an cogroup with

\begin{align*} \Delta: A \rightarrow A \oplus A \end{align*}

as comultiplication

Proof

follows from:

  • object in an abelian category as group object
  • opposite category of an abelian category as abelian category
