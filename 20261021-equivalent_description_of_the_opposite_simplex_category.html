equivalent description of the opposite simplex category

Proposition

The ordinary category $\mathcal{C}$ which contains

  1. finite, linearly ordered sets
  2. $\mathrm{Hom}([n],[m])$ is given by ordered maps $[n] \rightarrow [m] \cup \{\pm \infty\}$ where $[n] = \{1 < ... < n\}$.

is equivalent to the simplex category $\Delta^{\mathrm{op}}$.

Proof

Let the functor $\Delta^{\mathrm{op}} \rightarrow \mathcal{C}$$ be constant on objects and map a linear, order preserving functor $f: [n] \rightarrow [m]$ (i.e., an element in $\Delta$)$ to the map

\begin{align*} \tilde{f}: [m] \rightarrow& [n] \cup \{\pm \infty\} \\ i \mapsto& \mathrm{inf} f^{-1}[[i, \infty)] = \lim_{f^{-1}[i, \infty)} \end{align*}
