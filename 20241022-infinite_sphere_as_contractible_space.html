infinite sphere as contractible space

Proposition

The infinite sphere is a contractible space

Proof

a)

using inductive homotopy out of a cw complex:

Note that

\begin{align*} S^{\infty} = \mathrm{colim}_{n \in \mathbb{N}} S^n \end{align*}

So we want to define a map

\begin{align*} [0,1] \times S^{\infty} \cong& [0,1] \times \mathrm{colim}_{n \in \mathbb{N}} S^n \\ \cong& \mathrm{colim}_{n \in \mathbb{N}} S^n \times [0,1] \end{align*}

so we give a map

\begin{align*} \overline{\varphi_n}: S^n \times [0,1] \rightarrow& \mathbb{R}^{n+2} \setminus \{0\} \\ ((x_1,...,x_{n+1}), t) \mapsto& (1 -t) \cdot \sum_{i=0}^n e_i \mathrm{pr}_i + t \sum_{i=0}^n e_{i+1} \cdot \mathrm{pr}_{i} \end{align*}

which

  1. welldefined (if $\varphi_n(x,t) = 0$ with wlog $t \neq 0$, then the last coordinate (i.e. n+2) must be zero, so the $n+1$ coordinate of $x$ is zero which shows that the $n$-th coordinate must be zero and so one.
  2. continous as it uses only addition, multiplication and projections
  3. the restriction of $\overline{\varphi_n}$ to $S^{n-1}$ gives $\overline{\varphi_{n-1}}$

now define

\begin{align*} \varphi_n \coloneqq \frac{\overline{\varphi_n}(-)}{\| \overline{\varphi}_n(-) \|}: S^n \times [0,1] \rightarrow S^{\infty} \end{align*}

and observe that it is again welldefined and continuous.

Furthermore $\varphi_{n}$ restricting to $S^{n-1}$ gives $\varphi_{n-1}$ since $\overline{\varphi_n}$ restricts appropriately.

So $\varphi_n$ by we have a homotopy from the identity to the shift map.

so up to homotopy we may precompose with the shift map and then map from the subspace containing the image.

Here the image of the shift map restricts to $S^{\infty} \setminus \{(1,0...)\}$ so we want define the map

\begin{align*} \psi: S^\infty \times [0,1] \setminus {(1,0,0,...)} \rightarrow& \mathbb{R}^{\infty} \rightarrow S^{\infty} \\ ((x_i),t) \mapsto& (t,\alpha_n(1-t)(x_n)) \mapsto& \frac{(t,\alpha_n(1-t)(x_n))}{\| (t,\alpha_n(1-t)(x_n)) \|} \end{align*}

where we appeal to homotopy stacking for showing that this map is continouous

  1. using cellular approximation we get
\begin{align*} \pi_n(S^{\infty}) \cong \pi_n(S^{n+1}) = 0 \end{align*}

so apply weak homotopy equivalence between CW complexes as homotopy equivalence for the homotopy equivalence
