dichotomy of nice object and nice category

Thesis

(Often) You can either have:

  1. a nice category (complete / cocomplete etc.)
  2. nice objects (nice properties)

The reason behind it, is that colimits / limits destroy those (nice) properties

for example:

  • Category Field
  • category Ring
