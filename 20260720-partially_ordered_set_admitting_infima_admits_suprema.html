poset admitting infima admits suprema

Proposition

Let $(X, \leq)$ be a partially ordered set TFAE:

  1. $X$ admits all suprema
  2. $X$ admits all infima

Proof

1) $\implies$ 2)

Let $\{x_i\}$ be a family, then we need to show that this family admits an infimum. Then consider the set $\{y_j \vert y_j \leq x_i \forall i \in I \}$ and let $y_0$ be the supremum. We claim that this $y_0$ is the infimum of $\{x_i\}$: It holds that $y_0 \leq x_i$ for all $i$ since $y_j \leq x_i$ for all $y_j$. Moreover let $y_0'$ be another element such that $y_0' \leq x_i$ for all $i \in I$. Then $y_0' = y_j$ for some $j$ and hence $y_0' = y_j \leq y_0$ as $y_0$ is the supremum.

2) $\implies$ 1)
