set with left lifting property

Definition

Let $\mathcal{C}$ be a category, $S \subseteq \mathrm{Mor}(\mathcal{C})$ a subcollection Then

\begin{align*} \chi_{L}(S) \end{align*}

is defined as subcollection of morphism $f: A \rightarrow B$ such that

admits a solution for all $s: X \rightarrow Y \in S$
