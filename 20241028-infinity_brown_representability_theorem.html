infinity brown representability theorem

Proposition

Let $\mathcal{C}$ be an presentable infinity category containing a set of objects $\{S_{\alpha}\}_{\alpha \in A}$ such that

  1. each object $S_{\alpha}$ is a cogroup object in the homotopy category
  2. each object $S_{\alpha}$ is a compact object in $\mathcal{C}$
  3. $\mathcal{C}$ is generated by $S_{\alpha}$ under small infinity colimits

Let

\begin{align*} \mathcal{F}: h \mathcal{C}^{\mathrm{op}} \rightarrow \mathrm{Set} \end{align*}

be a functor

TFAE:

  1. $\mathcal{F}$ is a contravariant representable functor
  2. $\mathcal{F}$ dualizes coproducts to products and for every pushout

the induced map

\begin{align*} \mathcal{F}(D') \rightarrow \mathcal{F}(C') \times_{\mathcal{F}(C)} \mathcal{F}(D) \end{align*}

is a surjection
