category of pointed object lies fully faithfully in the arrow category

Proposition

Let $\mathcal{C}$ be a category with terminal object Then the category of pointed objects lies fully faithfully in the arrow category $\mathrm{Ar}(\mathcal{C})$

Proof

By definition the category of pointed objects is given by the coslice category, resp. the pullback

but the bottom map is fully faithful (cf. inclusion of a terminal/initial object is fully faithful), hence also the top map (cf. pullback reflects fully faithful infinity functor)
