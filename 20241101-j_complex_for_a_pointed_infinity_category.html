J-complex for a pointed infinity category

Definition

Let $J$ be a linearly ordered set, $J^{[1]} \coloneqq J \times J$ the categorical product (e.g. in Category Cat by partially ordered set as category) Then a \(J\)-complex in a pointed category $\mathcal{C}$ is an infinity functor

\begin{align*} \mathcal{F}: N(J^{[1]}) \rightarrow \mathcal{C} \end{align*}

such that

  1. for each $i \in J$ $\mathcal{F}(i,i)$ is the zero object
  2. for each $i < j < k$ the diagram

is an pushout
