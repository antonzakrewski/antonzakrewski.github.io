algebra of cofinite sets

Proposition

Sei $X$ eine (abzählbare ?) Menge, dann ist die Mengenalgebra der coendlichen Mengen definiert durch

\begin{align*} \mathcal{A} \coloneqq \{A \subesteq X \vert \vert X \setminus A \vert < \infty \lor \vert A \vert < \infty\} \end{align*}

Proof

$X \in \mathcal{A}$

folgt aus $\vert X \setminus X \vert = 0$

endliche vereinigung

die endliche vereinigung von endlichen Mengen ist endlich. Falls aber mind. eine koendliche Menge dabei ist, so ist eine obermenge erst recht koendlich

komplement

für eine endliche Menge $A$ ist $A \setminus A'$ eine teilmenge, also erst recht endlich Für eine koendliche Menge $C = X \setminus A$ ist

  1. $C \setminus A'$ für eine endliche Menge $A'$ koendlich da $C \setminus A' = X \setminus (A \cup A')$
  2. $C \setminus C' \subseteq A'$ für $C' = X \setminus A'$ endlich
