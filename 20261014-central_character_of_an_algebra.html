central character of an irreducible, finite dimensional representation

Definition / Proposition

Let $V$ be a finite dimensional irreducible representation of a K-Algebra $A$ over an algebraically closed field $k$. Then the central character is defined as \(k\)-algebra homomomorphism

\begin{align*} f: Z(A) \rightarrow& k \\ a \mapsto \lambda_a \end{align*}

where each $a$ acts by multiplication with $\lambda_a$.

Proof

Observe that if each $a$ acts by some scalar coming from $k$, then each matrix $p(a) \in \mathrm{GL}_n(k)$ identifies with a diagonal matrix with common diagonal. This subset is isomorphic as k-algebra with the field $k$ itself, hence then the map $p: Z(A) \rightarrow \mathrm{GL}_n(k)$ restricts to $k \subseteq \mathrm{GL}_n(k)$.

To show that it acts by multiplication with some scalar, it suffices to use schur lemma over algebraically closed fields where multiplication with $Z(A)$ is a natural transformation on $\mathrm{Mod}_{A}$.
