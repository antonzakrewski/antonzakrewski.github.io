hom out of a cogroup object as group valued functor

Proposition

Let $\mathcal{C}$ be a category, $X$ a cogroup object Then for each $C \in \mathcal{C}$,

\begin{align*} \mathrm{Hom}_{\mathcal{C}}(X,C) \end{align*}

carries a natural group object structure in category set

Proof

functor preserving limits preserves group objects where $X$ has by definition a group object structure in $\mathcal{C}^{\mathrm{op}}$
