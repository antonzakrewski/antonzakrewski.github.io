k-continuous function

Definition

Let $(X,\mathcal{T})$ and $(Y,\mathcal{T}_Y)$ be topological spaces and $f: X \rightarrow Y$ a map. Then $f$ is said to be \(k\)-continuous, if for all compact Hausdorff-Spaces $C$ and continuous maps $g: Y \rightarrow C$ the composition

\begin{align*} f \circ g: X \rightarrow C \end{align*}

is continuous
