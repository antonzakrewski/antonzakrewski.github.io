retract of a terminal object is terminal

Proposition

Let $x$ be a retract of a terminal object $1$. Then $x$ is already a terminal object.

Proof

note that a terminal object is characterized by

\begin{align*} \mathrm{map}_{\mathcal{C}}(c,1) = * \end{align*}

for $c \in \mathcal{C}$, so since $\mathrm{map}_{\mathcal{C}}(c,-)$ preserves retracts (its a functor) it suffices to show this for Anima Now assume we have some retract in anima, then in particular we can argue using homotopy groups in Anima and whitehead, that the terminal morphism $x \rightarrow 1$ must be an equivalence.
