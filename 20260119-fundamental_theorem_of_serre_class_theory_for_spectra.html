fundamental theorem of serre class theory for bounded below spectra

Proposition

Let $A$ be a bounded below spectrum. TFAE:

  1. $A$ has finitely generated homotopy groups.
  2. $\mathbb{Z} \otimes_{\mathbb{S}} A$ has finitely generated homotopy groups.

Proof

at least 1) $\Rightarrow$ 2) should be correct

cheap proof

Let $m > 0$ be arbitrary. Then there exists a map $\tilde{\mathbb{S}}[X] \rightarrow A[n]$ for $n >> 0$ such that

  1. this map is $n + m$ connective (cf. bounded spectrum and connective map from a reduced suspension spectrum).
  2. $H_{n+m+2}(X)$ (todo) and above vanish and $H_{n+m+1}(X)$ is finitely generated if $H_{n+m}(X)$ is finitely generated.

Then this reduces to fundamental theorem of serre class theory, where we can use the stabel range.
