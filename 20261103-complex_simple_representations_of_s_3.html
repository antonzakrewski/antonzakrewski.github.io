complex, simple representations of S_3

Proposition

Let $S_3$ be the symmetric group. Then there exist three representations

  1. the constant representation
  2. the sign representation

Proof

using: see: 1 dimensional representations of S_n + read of the characters of these representations. Observe / Compute that the conjugacy classes are given by $[1],[(1,2)], [(1,2,3)]$ with multiplicity given by $1,3,2$ (e.g. conjugacy classes don't change the sign).

Then the sum of squares formula for a group implies that there exists a third, 2 dimensional representation.

To find this, consider the canonical action of $S_3$ on $\mathbb{C}^3$, which comes from the free $\mathbb{C}$ vector space functor. Then consider the unique map $\{1,2,3\} \rightarrow \{*\}$ which induces a map $\mathbb{C}^3 \rightarrow \mathbb{C}$, which is compatible with the canonical action on $\mathbb{C}^3$ and the constant action on $\mathbb{C}$. The kernel, which is the span of $V_{\mathrm{std}} = (1, - 1, 0), (0, 1, - 1)$ is a G-representation and 2 dimensional. Now assume that any element $(\alpha_1,\alpha_2,\alpha_3) \in V_{\mathrm{std}}$ spans a 1-dimensional representation: Then it does not span an the sign action, since it being an eigenvector to the eigenvalue of $-1$ of $(1,2)/(1,3),(2,3)$ implies that $\alpha_3 = \alpha_2 = \alpha_1 = 0$. Now assume that it is an eigenvector to the eigenvalue $1$ for all transpositions: Then this implies $(\alpha_1,\alpha_2, \alpha_3) = (\alpha_2,\alpha_1,\alpha_3)$ and similarly $\alpha_1 = \alpha_2 = \alpha_3$. Since $\sum \alpha_i = 0$ this implies $\alpha_1 = \alpha_2 = \alpha_3 = 0$, so no vector generates a subrepresentation.

Now the character table can be computed by orthogonality.
