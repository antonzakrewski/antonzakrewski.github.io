Kan-quillen Model structure on sSet

Definition

The Kan-quillen model structure is defined as model structure on category sSet

  1. monomorphisms as cofibrations
  2. kan fibrations as fibrations
  3. weak equivalences between simplicial sets between simplicial sets

Proof

factorization

  • small object argument in sSet

cofibration + trivial fibration

for

  1. $I$ as $\partial \Delta^n \rightarrow \Delta^n$ (cf. trivial fibration)
  2. $\mathrm{Sat}(I) = \mathrm{monomorphisms}$

trivial cofibration + fibraiton

  • RLP(J) = kan fibration
  • $J$ as horn inclusion, ~> $\mathrm{Sat}(J) = \mathrm{anodyne}$
