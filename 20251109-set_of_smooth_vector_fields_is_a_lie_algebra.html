Proposition

The set of smooth vector fields for a smooth manifold is a Lie-Algebra

Proof

vector space

use pointwise addition & pointwise scalar multiplication

lie bracket

use the commutator pairing:

\begin{align*} [\cdot, \cdot]: \mathfrak{X}(M) \times \mathfrak{M} \rightarrow& \mathfrak{X}(M) \\ (X,Y) \mapsto [X,Y] = X(Y(f)) - Y(X(f)) \end{align*}

follows from the definition
