terminal object and trivial fibration

Proposition

Let $\mathcal{C}$ be an infinity category and $x \in \mathcal{C}_0$ an object.

TFAE:

  1. $x$ is an terminal object
  2. the forgetful functor from the infinity slice category
\begin{align*} \mathcal{C}_{/x} \rightarrow \mathcal{C} \end{align*}

is a trivial fibration

Proof

1) $\implies$ 2)

2) $\implies$ 1)
