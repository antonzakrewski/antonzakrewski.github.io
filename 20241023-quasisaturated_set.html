quasisaturated set

Definition

Let $\mathcal{C}$ be an infinity category admitting pushouts Then a collection $S \subseteq \mathcal{C}_1$ is said to be quasisaturated, if

  1. each equivalence lies in $S$
  2. $S$ satisfies infinity two out of three
  3. given an pushout

with $f \in S$ then $f' \in S$
