chromatic number of a 3-regular connected non bipartite graph

Proposition

Let $G$ be a 3-regular, connected non bipartite graph. Then

\begin{align*} \chi(G) = \begin{cases} 4 & \mbox{if } G \cong K_4 \\ 3 & \mbox{else } \\ \end{cases} \end{align*}

Proof

using brooks theorem for chromatic number we get the cases $\chi(G) \leq 3$ and $G = K_n$ or $G = C_n$. But $C_n$ is only 2 regular, not 3 regular.

$G \cong K_4$

Here only $K_4$ is 3 regular. Then each vertex is connected, hence only $4$ works.

$\chi(G) \geq 3$

Suppose there exists a 2-coloring. Then this is precisely a bipartiton. (cf.2-coloring as bipartition)
