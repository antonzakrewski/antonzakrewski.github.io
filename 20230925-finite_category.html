strictly finite 1-category

Definition

Let $\mathcal{C}$ be a category. Then $\mathcal{C}$ is said to be finite, if

  1. the class of objects $\mathrm{Ob}(\mathcal{C})$
  2. each hom-set $\mathrm{Hom}(\mathcal{C})$ is finite

Alternatively it is equivalent ot require $\mathrm{Mor}(\mathcal{C})$ to be finite
