choice function for a relation

Definition

Let $R = \leq$ be a (nice) Relation on a set $X$. Then one can define

  1. $c(S) = \{x \in S \vert \forall y \in S x \leq y\}$
  2. $c(S) = \{x \in S \vert \lnot \exists y \in S y<x\}$

a) it is at least as good as everything else $O(S)$ b) there does not exist better $M(S)$

Remark

  • difference:
    • if two elements $a,b$ are not comparable then a) $c(\{a,b\})$ would be empty b) $c( \{a,b\})$ would be $\{a,b\}$
  • (under mild assumptions ?)
    • should be $O(S) \subseteq M(S)$
