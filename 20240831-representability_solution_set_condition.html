representability solution set condition

Definition

Let $\mathcal{D}$ be categories, $\mathcal{F}: \mathcal{D} \rightarrow \mathrm{Set}$ a functor Then representability solution set condition is defined as existence of a small set $S$ of objects of $D$ such that for any $d \in \mathrm{Ob}(\mathcal{D})$ and $x \in \mathcal{K}(d)$ there exists an $s \in S$, an element $y \in \mathcal{K}(s)$ and a morphism

\begin{align*} f: s \rightarrow d \end{align*}

such that

\begin{align*} \mathcal{F}(f)(y) = x \end{align*}
