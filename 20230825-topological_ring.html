topological ring

Definition

Let $(R,+,\cdot)$ be a ring and $\mathcal{T}$ be a topology on the set $R$. Then $R$ is said to be a topological ring, if $(R,+,\mathcal{T})$ / $(R,\cdot,\mathcal{T})$ is a topological group resp. a topological monoid
