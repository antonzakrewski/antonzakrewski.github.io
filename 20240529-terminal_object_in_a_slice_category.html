terminal object in a slice category

Proposition

Let $\mathcal{C}$ be a category, $C \in \mathrm{Ob}(\mathcal{C})$ an object and $\mathcal{C} \uparrow C$ the slice category Then the initial object exists and is given by

\begin{align*} \mathrm{id}: C \rightarrow C \end{align*}
