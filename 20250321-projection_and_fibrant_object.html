projection out of a fibrant object

Proposition

Let $(\mathcal{C}, \mathcal{W}, \mathrm{Cof}, \mathrm{Fib})$ be a model category. Suppose $X \in \mathcal{C}$ where $X$ is a fibrant object

Then for any object $Y$ the projection

\begin{align*} \pi_Y: X \times Y \rightarrow Y \end{align*}

is a fibration
