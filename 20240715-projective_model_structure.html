projective model structure

Definition

Let $\mathcal{C}$ be a model category, $I$ a small category Then the projective model structure, if it exists, on the functor category

\begin{align*} \mathrm{Fun}(I, \mathcal{C}) \end{align*}

is defined as following:

  1. weak equivalences as natural transformations, which are objectwise weak equivalences
  2. fibrations as natural transformations, which are objectwise fibrations.
  3. cofibrations determined by the previous maps

Warning:

  • the projective model structure need not exists
