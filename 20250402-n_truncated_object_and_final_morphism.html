n-truncated object and terminal morphism

Proposition

Let $\mathcal{C}$ be an infinity category with terminal object $*$, $X \in \mathcal{C}$ an object

TFAE:

  1. $X$ is n-truncated object
  2. the terminal morphism $X \rightarrow *$ is an n-truncated morphism

proof

Follows from the fiber sequence

\begin{align*} X \simeq X \rightarrow * \end{align*}

consider the pullback sequence (cf. square with parallel equivalences as infinity pullback)

Then apply the infinity yoneda embedding, which preserves small limits to get the fiber sequence

\begin{align*} \mathrm{map}_{\mathcal{C}}(-,X) \simeq \mathrm{map}_{\mathcal{C}}(-,X) \rightarrow \mathrm{map}_{\mathcal{C}}(-,*) \end{align*}

where the fiber $\mathrm{map}_{\mathcal{C}}(-,X)$ is precisely as truncated as $\mathrm{map}_{\mathcal{C}}(-,X)$.
