terminal locale

Proposition

The terminal locale is given by $\mathrm{Open}(*)$

Proof

Let $\mathcal{O}$ be a locale. Then any morphism of locales $f: \mathcal{O} \rightarrow \mathrm{Open}(*)$ is a map of partially ordered sets $\mathrm{Open}(*) \rightarrow \mathcal{O}$ which preserves colimits and finite limits, hence in particular initial objects and terminal objects in the partially ordered set as category.
