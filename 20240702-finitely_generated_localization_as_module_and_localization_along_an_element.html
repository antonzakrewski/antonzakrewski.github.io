finite type localization and localization along an element

Proposition

Let $A$ be an commutative ring, $S \subseteq A$ a multiplicatively closed subset containing only regular elements

TFAE:

  1. the localization $S^{-1}A$ is a finite type A-Algebra

Then there exists an element $f \in S$ such that

\begin{align*} S^{-1}A = A_{f} \end{align*}

see: localization along an element
