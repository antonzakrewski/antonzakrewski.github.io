terminal object in a quotient category

Proposition

Let $\mathcal{C}$ be a category, $\sim$ a composition compatible Relation and $\mathcal{C}/\sim$ the quotient category. Then the quotient functor

\begin{align*} \pi: \mathcal{C} \rightarrow \mathcal{C}/\sim \end{align*}

preserves the terminal object

Proof

follows as the terminal object is characterized by

\begin{align*} \mathrm{Hom}_{\mathcal{C}}(-,*) \cong \mathrm{const}_* \end{align*}

where taking a quotient does not change the hom-set
