delta dg category

Definition

Let $n \in \mathbb{N}$, then the $\Delta$ dg category is defined as dg category containing

  1. $\{0,...,n\} = \mathrm{Ob}(\Delta^n)$ as objects

2)

\begin{align*} \mathrm{Hom}_{\Delta^n}(k,l) = \begin{cases} 0 & \mbox{if } l \leq k \\ I^{l-k} & \mbox{else } \\ \end{cases} \end{align*}

where $I^j$ for $j \geq 1$ is defined as chain complex

\begin{align*} (I^j)_l = I^{\binom{j}{l-1}} \end{align*}

with differential given by

\begin{align*} 1_{S} \mapsto& \sum_{\alpha \in S} (-1)^{?? \alpha} 1_{S \setminus \{\alpha\}} \end{align*}

for $S \subesteq \{1,...,j\}$ with $\vert S \vert = l-1$, where $\{1_{S} \vert S \subseteq \{1,...,j\}, \vert S \vert = l-1 \}$ is seen as \(R\)-basis of $R^{\binom{j}{l-1}}$

and composition given by

\begin{align*} 1_{ i_1 < ... < i_l} \otimes 1_{ j_1 < ... < j_{k}} \mapsto \begin{cases} 1_{i_1 < ... < i_l = j_1 < ... < j_k} & \mbox{if } i_l = j_1 \\ 0 & \mbox{else } \\ \end{cases} \end{align*}
