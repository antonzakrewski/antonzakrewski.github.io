point and irreducible component

Proposition

Let $(X, \mathcal{T})$ be a topological space, $x \in X$ a point. Then there exists an irreducible component $A$ such that

\begin{align*} x \in A \end{align*}

Proof

corollary of:

  • point as irreducible set
  • irreducible set as subset of an irreducible component
