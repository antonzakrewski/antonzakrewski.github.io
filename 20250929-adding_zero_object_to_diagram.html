adding terminal objects to a diagram

Definition

Let $\mathcal{C}$ be category with terminal object and $I$ an indexing category. Suppose we add $v$ via a single map $i \rightarrow v$ and denote this resulting category $I_v$ Then

\begin{align*} \mathrm{Fun}(I, \mathcal{C}) \subseteq \mathrm{Fun}(I_v, \mathcal{C}) \end{align*}

is a left bousfield localization

Proof

  • right kan extension: right kan extension formula
  • right kan extension along a fully faithful functor is fully faithful
