finite set and compact in the discrete topology

Proposition

Let $X$ be a set and $X^{\delta}$ the set equipped with the discrete topology and $A \subseteq X$.

TFAE:

  1. $A$ is finite
  2. $A$ is compact

Proof

1) $\implies$ 2)

corollary of finite set as compact set

2) $\implies$ 1)

Consider the open covering

\begin{align*} \{ \{x\} \vert x \in A\} \end{align*}

Then there exists a finite subcover, hence $A$ is finite
