universal colimit (old)

Definition

Let $\mathcal{C}$ be an infinity category with pullbacks and colimits and let $D$ a simplicial set Then a functor $\mathcal{G}: D \rightarrow \mathcal{C}$ admits a universal colimit if for every map $f: Y \rightarrow Z$ and each pullback

the canonical map

\begin{align*} \mathrm{colim}_D(\mathcal{G}(d) \times_{Z} Y) \rightarrow (\mathrm{colim}_{D} \mathcal{G}(d)) \times_Z Y \end{align*}

is an equivalence
