weakly terminal set

Definition

Let $\mathcal{C}$ be an infinity category, $S \subseteq \mathcal{C}_0$ a nonempty subset of objects Then $S$ is said to be weakly initial, if for each $x \in \mathcal{C}_0$ there exists some $s \in S$ such that

\begin{align*} \mathrm{map}_{\mathcal{C}}(s,x) \end{align*}

is nonempty
