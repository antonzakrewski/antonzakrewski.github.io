contractible simplicial set and opposite simplicial set

Proposition

Let $\mathrm{sSet}$ be the category sSet and $X \in \mathrm{Ob}(\mathrm{sSet})$ an object

TFAE:

  1. $X$ is a contractible simplicial set
  2. the opposite simplicial set $X^{\mathrm{op}}$ is contractible

Proof

1) $\implies$ 2)

2) $\implies$ 1)
