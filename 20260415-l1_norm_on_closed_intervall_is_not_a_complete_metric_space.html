L1 norm on closed intervall is not a complete metric space

Proposition

Let $[0,1]$ be the closed interval, $(C([0,1]), d_1)$ the L1 Norm. Then it is not complete.

Proof

Consider for $n \geq 2$ the functions

\begin{align*} f_n: [0,1] \rightarrow& \mathbb{R} \\ x \mapsto \begin{cases} 0 & \mbox{if } x < 0.5 \\ n \cdot (x - 0.5) & \mbox{if } 0.5 \leq x \leq 0.5 + \frac{1}{n} \\ 1 & \mbox{else } \\ \end{cases} \end{align*}

which are continuous.

We claim that this is cauchy, but does not converge.

cauchy

Let $n > m$, then

\begin{align*} (f_n - f_m)(x) \begin{cases} \leq 1 & \mbox{if } x \in [0.5,0.5 + \frac{1}{m}] \\ = 0 & \mbox{else } \\ \end{cases} \end{align*}

so we may estimate

\begin{align*} \int_{[0,1]} \vert f_n - f_m \vert \mathrm{d}x \leq& \int_{[0.5,0.5+ \frac{1}{m}]} 1 \mathrm{d}x \\ =& \frac{1}{m} \end{align*}

not convergent

Let $A = (\alpha, \beta) \subseteq [0,1]$ be an interval. Then observe that the map

\begin{align*} (C([0,1]),d_1) \rightarrow (C(A),d_1) f \mapsto f_{\vert A} \end{align*}

is 1-lipschitz, so in particular continuous.

Moreover, $(f_n)_{\vert [0,0.5]}$ evidently converges to $x \mapsto 0$ as it is a constant sequence. Furthermore, $(f_{n})_{\vert [0.5,1]}$ converges to $\mathrm{const}_{1}: x \mapsto 1$ as

\begin{align*} \int_{[0.5,1]} \vert f_n - \mathrm{const}_1 \vert \mathrm{d} x \leq \frac{1}{n} \end{align*}

So suppose $f_n$ converges to $g$, then

  1. $g_{\vert [0,0.5]} = \mathrm{const}_0$
  2. $g_{\vert [0.5,1]} = \mathrm{const}_1$

which is evidently not continuous.
