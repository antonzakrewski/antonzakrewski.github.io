weierstrass theorem about entire functions

Proposition

Let $a_n \in \mathbb{C}$ with $\vert a_n \vert \rightarrow \infty$. Then there exists an entire function $f$ with zeros at $a_n$ (counting multiplicities).

Furthermore this function is unique up to multiplication with

\begin{align*} \mathrm{e}^{g} \end{align*}

for some entire function $g$
