functor preserving limits preserves module objects

Proposition

Let $\mathcal{C}, \mathcal{D}$ be categories, $R$ a Ring Object and $M$ a module object over a ring in $\mathcal{C}$. Suppose $\mathcal{F}: \mathcal{C} \rightarrow \mathcal{D}$ is a functor which preserves finite limits.

Then $\mathcal{F}(M)$ is a module object over $\mathcal{F}(R)$
