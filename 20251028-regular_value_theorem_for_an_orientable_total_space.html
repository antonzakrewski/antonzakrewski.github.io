regular value theorem for an orientable total space

Proposition

Let $f: M \rightarrow N$ be a smooth map between smooth manifolds. Suppose $M$ is an orientable manifold and $n \in N$ a regular value.

Then the smooth submanifold $f^{-1}[n]$ defined by the regular value theorem is also orientable

Proof

use regular value of a smooth map to get a smooth manifold $f^{-1}[p]$.

Then choose an orientation of $N$. Then for each point $m \in f^{-1}[p] \subseteq M$ take a complement $T_{m}M = Q \oplus T_{m}f^{-1}[p]$ where $T_{m}f^{-1}[p]$ denotes the image of $f^{-1}[p] \rightarrow M$. Then it follows that $D_{f(m)}: Q \rightarrow T_{f(m)}N$ is a vectorspace-isomorphism since $\mathrm{ker}(D_{f(m)}) = T_{m}f^{-1}[p]$: This follows from dimensions reasons, as $\mathrm{dim}_{\mathbb{R}}(\mathrm{ker}(D_{f(m)}) = \mathrm{dim}_{\textrm{manifold}}(f^{-1}[p]) = \mathrm{dim} T_{m}(f^{-1}[p]$ and $T_{m}f^{-1}[p]$ lies in the kernel. (alternatively some mittelwertsatz argument should work - it is a regular value ?)

Now the isomorphism $D_{f(m)}: Q \rightarrow T_{f(m)}N$ gives us for each fiber a preferred orientation.
